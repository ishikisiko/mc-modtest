# 衣甲动态作者输入

`catalogue.js` 按完整设计ID声明各套动效，是唯一数据源。坐标为模型像素，动画目标为现有组件ID，不能用名称前缀推测组件归属。

- `flows`：沿模型空间折线路径流动的方粒、星点、叶光或中空敕印；可选短尾迹。
- `motions`：明确列出的组件共用一个枢轴，作微幅摆动或浮沉。
- `glows`：只克隆目标组件的材质作局部明灭；纹理仍借用模型资源。
- `arcs`：固定折线路径上的短弧，按较长周期平滑亮灭。

`core/effects.js` 校验目标、数量、幅度、周期及有限坐标。它不拥有模型的纹理，不修改设计JSON，不建立定时器；页面统一驱动时间与释放。关闭时完整恢复原来的父子结构、变换和材质。粒子及光尾单独置于场景，不进入模型几何统计和OBJ。

检查入口：`node art/immortal-armor-atlas/core/test/test_effects.js`。画面检查与录屏分别由 `checks/dynamic.js`、`checks/record_effects.js` 执行，证据需记录输入HTML散列。实际画面、资源检查和玩家验收分开报告。
