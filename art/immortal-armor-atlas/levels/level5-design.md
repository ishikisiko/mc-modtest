# 化神：太虚无相、玄极天尊、大日归墟

本境交付的是三套独立的真实三维设计数据，每套包括头、胸、腿、靴与独立低扁锭。坐标沿用冻结接口：Y 向上，Z 正向为正面，人体足底在零附近；不进入 Minecraft 模型、装备数值或合成系统。几何来自本境作者脚本，未使用图像生成。

## 本境的设计判断

化神不能只是把元婴的宝石放大、把衣裾切碎，再加一个更大的发光圈。它应让人看到一种超越普通装备的完整秩序：冠与背构相互让位，胸背有可以近看的曲面，衣摆与靴保持身体的落点，主面、细缘、内里有清楚的分工。三套都有悬浮或超凡部位，但它们不取代衣甲主体。关闭发光仍应读得出三种身份。

| 设计 | 第一眼身份 | 主体节奏 | 冠与背构 | 下半身组织 |
|---|---|---|---|---|
| 太虚无相 | 超然仙人 | 修长、回旋、非对称留白 | 空心璇冠，两条各自独立走势的回帛 | 淡紫实裤、前开后合深裾、长短不同的两幅云襟 |
| 玄极天尊 | 沉静帝君 | 紧实、轴向、金玉法度 | 空窗冕冠，实体长圭框与回接支座 | 实体裤甲、正前一幅玄紫长绶、连续后氅、高靴 |
| 大日归墟 | 光明神祇 | 温润、放射、向上聚合 | 整铸莲焰主冠，宽面实体日轮 | 暖白实裤、两幅大莲襟、中央朱绶、侧后合裾 |

这三种结构不能互换配色替代。太虚没有帝君的低展肩盖和中轴悬圭；玄极没有日轮、莲襟与白珀圣衣；大日没有太虚的非对称长回帛。每套的下装、冠、后背和纹样也分别编写。

## 太虚无相：以留白承载仙气

### 整体与四件

太虚的关键是一身安静而完整的衣。凝虚瓷金从胸、背、肋部连续包覆到腰，肩部沿实际人体向下圆转，不立出巨肩。长杏形护襟由真正弯曲的局部 loft 生成，侧缘进入胸衣的大曲面，避免一张平板悬在胸前。交领像两笔向下收的水线，胸心另有两枚克制的回云纹，靠薄浮雕建立近看层次。

**无相璇冠**由后脑壳、完整顶壳、额箍、鬓缘、空心冠骨、单枚冠心叶与小紫晶构成。后脑和鬓部被真实包住，正面让出眉眼。冠骨留出的窄长空白，比更大的宝石更重要；内叶略偏置，打破机械镜像。冠的曲线向内收回，不长成兽角。

**凝虚天衣**的两袖从肩到腕各自形成完整管状曲面，肩端封合，袖口只稍微放宽。袖下短尖与手保持距离，青银边在袖背绕行，而不在手臂上重复成一串甲片。胸衣归属的两条回帛一垂一展：左带从肩后向外舒展，再落向左下；右带在肩外形成低位开弧，提前渐窄，细尾落向后腰上方。右弧不再升到冠顶，冠骨保留唯一的头顶重心。二者的路径、宽度与重心均独立，转身后不会变成同一个圆环的两半。

**不系云裳**在腰胯有完整内衬，左右裤腿分别包覆大腿、膝与踝；淡紫内裳在开裾中显现，给浅色外衣以层次。外裾不是整圈直筒，而是前开后合的连续曲面，从窄腰渐渐展开。背腰段按双裤腿的联合外包络留出厚度和缝隙，淡紫裤层只在有意开放的前裾内显现。两幅完整长裁面在正面落下，一幅略长，一幅略短，中间的空隙让脚和腿仍有存在。后裾的长水纹与末端回云有各自的曲率，沿展开衣面舒展。

**步寂仙履**有暗蓝薄底、完整足壳、踝口细边和足背回云，足趾向前，足跟不空缺。足背的曲线从踝口下行至微翘的靴尖，侧面有厚度，底面有承重感。这里保留落地的人形，避免仙衣最后变成漂浮的无脚筒。

### 材质与锭

| 材质角色 | 视觉工作 |
|---|---|
| 凝虚瓷金 | 不透明完整护面；浅青乳光与柔和金属反射共同存在 |
| 月雾灵绫 | 实袖、后裾的活动衣面；更粗糙、更安静 |
| 青银 | 冠骨、衣缘、流纹与细小连接；只在轮廓上抓光 |
| 空青内绡 | 后领、腰胯与履底；承托浅色，给开口深度 |
| 无相回帛 | 仅背部两条薄带半透明；不让整套隐形 |
| 暮紫虚晶 | 额心与锭中的微小内含物；低亮、低面积 |
| 凝虚金母材 | 独立锭体，具有比成衣更明显的金属性 |
| 空脉 | 锭中深蓝的连续细脉；构成材料识别 |
| 淡紫内裳 | 裤腿与贴体腰绫；从开裾中分出内外层 |

**无相凝虚锭**尺寸为 `.38 × .066 × .215`，高宽比约 `.174`。削角母体保持低扁锭家族轮廓，冷银侧缘、乳青顶面、深蓝细脉、两枚长短不同的紫晶与三道水纹分别建模。水纹不与玄极的方折铭、日珀的放射纹共用一份图案。它是一块含着寂静水光的金属材料，而非装满浮空宝石的托盘。

### 升级与分片

相对总纲中元婴的星体、琉光和生机，本套把异象收进材料与空隙：曲面更整，悬帛更有秩序，冠、肩、腰、后裾的线条贯通。这里没有通过堆护甲片提高境界。胸背、实袖、实裤、后裾为完整曲面；冠心单叶、袖口独立收边仅是局部辅层。两幅云襟是大裁面衣料，不能视作鳞甲。后续精修空间在流动垂坠、表面细纹和晶体质感，不能再靠扩大冠饰或增加光圈。

## 玄极天尊：以法度形成威仪

### 整体与四件

玄极的主形是一件包住身体的深靛收腰礼甲。它并未把躯干铺满鳞片，也不把帝君想象成巨肩骑士。肩盖只比人体稍宽，胸弧向腰部干净收束，前臂、裤腿和高靴都保持明确的站立方向。正前方窄圭章与一整幅玄紫长绶建立中轴，古金细线围住大曲面，让深色有可读的边界。

**万象悬衡冕**有完整后脑与顶盖、古金额箍、两根向内收的冠柱和一条冠梁。冠柱之间保留空窗，头顶上方仍看得到空气。额前五条细旒由一根真正回接到冠柱的弧梁承接，小玉只收在旒端，终点在额上，不遮住眼睛。后脑的一条寒玉中脊继续引向高后领；鬓边金线沿壳体收回耳后，不向外生角。

**玄极御宸甲**的胸背由连续 loft 构成，有胸峰、肋部和腰部不同的截面。中央圭章刻意收小，避免一块巨盾盖掉胸甲；寒玉内嵌也只占小面积。左右胸弧的玄篆各有主纹与内折，靠细线的不同金属性和微亮度说明工艺。高后领为后半包围，前方仍开放呼吸。左右肩各一枚低展后收的护盖，肩—锁骨—上胸通过宽整曲面衔接；上臂在肘部内收，前臂按肘腕改变截面与方向，避免整段直筒。套甲背面有一条随腕脊转折的完整玉脊。

胸件背后是一片完整玄氅与一座实体悬圭。长氅从肩胛收向腰，再向下展开，开口边、底缘和背部三道铭弧分别成立。悬圭由左右两条厚实连续框身合成，上尖下敛，中间留空；两个弯曲支座回接肩胛，并非把环凭空画在背景上。它有局部厚度、法线、背面和古金中脊，能从侧面看出与身体的间距。背框下枢才放一枚小墨玉章，避免胸口、后背同时出现大宝石。

**镇象玄绶裳**有连续髋衬和两条独立裤甲，膝部只保留一笔承力弧铭。中央长绶是一幅有厚度的整裁面，略随曲线前凸，到踝上结束，左右金缘从腰到末端连续。下端一枚小玉章与胸圭相呼应，不把整条绶画成碎片拼布。

**定极承天靴**为高靴，真实足壳连接到小腿中段。铅灰薄底、玄金靴筒、古金口缘、足背玉线与后跟金线各司其职。足背的玉线随脚踝折向足尖，仍保持片带宽度，正侧背都有可读结构。它是这套威仪的落点，不用夸大的鞋底或尖趾追加重量。

### 材质与锭

沉曜玄金负责完整外甲；玄紫天缎负责长绶与后氅；古金只沿结构和法度线抓光；寒玉用于冠旒、窄章与背脊；铅灰内绫藏在关节与靴底；寒碧细铭只发出极低的玉光；紫曜金为冠内、锭顶和圭章提供冷紫反射；墨玉承担后枢小章与锭内暗含物。八种材质均有几何引用，没有只为凑数列入色表。

**玄极沉曜锭**尺寸为 `.375 × .075 × .215`，高宽比 `.20`。主体深靛，顶面带紫曜光，削角边缘露出古金。青玉斜脉、不对称的两枚内含物与两组方折两仪铭独立建模。铭线以折方回转为主，仍有圆润细管的实体厚度，不冒充可读的汉字刻字。侧面规整基线强调其金属锭身份，不把它改成法印、砖或石碑。

### 升级与分片

与元婴的异象外显相比，玄极把超凡纳为可穿的仪制：实体胸背、真实套袖、深色明暗和窄长悬圭先成立，细旒与悬构才负责越出凡俗。局部分片仅用于左右各一层小护肩搭接上臂和前臂口圈，胸腹、长氅、裤腿和靴筒都不分解为小甲片。冠柱与背框属于仪式构件，并未在身体上重复铺满。后续提升应落在深色金属层次、铭文工艺和冠旒动态上，不能再加宽肩或增加漂浮碎片。

## 大日归墟：以实体光明保留深处

### 整体与四件

大日的圣洁首先来自温润的白珀主体与收敛的朱金层次。躯干是一件完整磨出的白珀曲壳，胸心没有悬起的大平板；莲纹直接附着在曲面上，细小日纹在莲心收光。肩部低矮圆转，高腰以下两幅宽莲襟向内收尖，后裾完整合围；中间的朱色长绶让大量浅色有温度。暗红归墟石只在背后出现，回应“归墟”而非把整套变成炽红战甲。

**日莲照神冠**以一块整铸三起伏莲焰主冠建立正面，中央高、两侧回向内侧，曲线不向外长成西幻巨角。主冠有真实厚度和倒角，白珀内面是完整嵌面，微型日纹贴在冠面。完整顶壳与后脑壳包住头部，金色额箍和鬓边细线回到耳后；后脑另有成对莲纹，冠背不留成一块无内容的金板。

**大日光明衣**由胸背曲壳、前半莲领与完整后领构成，躯干不靠披帛遮盖。左右各一枚小云盖与实袖相接；前臂朱金套腕上的白珀长面承接胸甲，让袖内色与白色主体有真实层差。胸前以莲心、外莲脉和细窄日纹组织，避免一块巨宝石支配全身。

背部短后披独立成立，肩胛莲线向一枚小型赤曜暗核收束。日轮在它后方留出空间：一个闭合宽面的连续金属环、一条较细内环、两个弯曲肩胛支座，以及八枚少量莲焰构成实体器物。轮有前后表面与厚度，低亮度只使金色略有内辉；轮心不铺光幕，不使用满屏粒子。去掉背轮，后披、肩胛与暗核仍是一件完整的衣。

**归一莲华裳**内层为两条真实暖白裤腿，髋部有连续衬层，外部后裾包到两侧。正面左右莲襟各由一幅宽曲面裁出，路径、宽度和末端收尖沿身体安排。莲襟中间露出窄朱绶，金脉沿裁面行走，后方另有两条收合莲脉与完整底缘。它表现莲花的整瓣体量，不靠许多片叶子重复堆叠。

**金莲承曦履**以完整足壳包住脚跟、足背和踝下，暗赭薄底承担落点。赤金口缘和足背莲脉在脚踝转弯，前掌微翘，靴尖比例克制。后跟另有短金线，照应后裾。全身再神圣，脚仍要站住，不能变成背轮托着的一件空衣服。

### 材质与锭

白日珀负责胸衣、冠、履壳和两幅大莲襟；曦白天绫负责实袖、裤腿与后裾；赤日金负责细缘、冠与结构线；朱砂天缎用于内里、中绶与套腕；归墟赤曜石用于后心及偏侧锭内含物；日心琥晶只用于锭心；低辉日金用于背轮的实体宽面；赭暗内衬用于开口与履底；日珀金母材为锭顶提供专门的金属反射。九种材质的粗糙度、金属度与透明度有实际分工，只有日核小晶体透光。

**归墟日珀锭**尺寸为 `.39 × .073 × .23`，高宽比约 `.187`。削角母体低而宽，温白顶面与赤金侧缘承接成衣材料。很小的蜂蜜色日核、六道独立放射纹、两道朱色莲弧和一枚偏侧暗红石各自建模；侧缘还有一条朱色沉积线。中心日核只占小面积，材料仍是一块锭，不是圆饼太阳或宝石砖。

### 升级与分片

本套与元婴总纲中的多色琉光有明确区别：异象不再零散外溢，而凝成主衣、莲襟、前冠与背日的稳定体量关系。它作为圣洁方向的化神终点，依赖前侧背一致的秩序，而非单纯提高亮度。肩部各一枚云盖、日轮边缘八枚莲焰属于少量局部辅层；胸腹、双袖、双腿、后裾和两幅大莲襟均连续成面，背轮主体也是闭合实体宽环。未来精修应增强金属錾刻、温玉收光与衣料细纹，不能把日轮继续扩大或把衣摆改成多层鳞片。

### 可复跑的最小检查

```bash
python3 art/immortal-armor-atlas/authors/level5.py --check
python3 art/immortal-armor-atlas/authors/level5.py --check --engine-check
```

第一条不依赖 core：校验恰好三套、唯一 id、有限数值、已知 shape、合法材质引用、路径与宽度长度、非自交 panel、四种 role、低扁锭、说明长度与作者源同一性。每套 JSON 实质中文说明分别为 1320、1322、1349 汉字。

第二条只调用已经存在的真实 `core/engine.js`，预置本仓 `tools/web/three.min.js`。已验证 `validateDesign`、不带人台的 `buildDesign`、带人台的 `buildDesign`、`buildIngot`、`meshStats`、`exportOBJ` 和 `dispose`。检查了所有顶点属性的有限性、索引范围、Mesh 元数据与整套包围盒；穿戴与锭的 OBJ 均有真实顶点和三角面，不包含 NaN 或 Infinity。
