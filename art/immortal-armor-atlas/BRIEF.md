# 五境十五套锭与防具 · 本轮设计总纲

用户要求整夜自主完成最终交付，不等逐项凹细节。目标是完整、精致、风格变化明显的修仙/玄幻防具设计系列。
本轮只做设计及 HTML 三维交付，不落入 Minecraft，不涉及工具、玩法数值、合成或注册。
独立分支 `art/immortal-armor-atlas-20261028`；不要合并 main，不要修改其他 agent 的设计。

## 必须理解的批评

旧稿被否决的原因不是像素数不够：它像武侠农夫的补丁衣服，缺乏平面构图、立体体积和仙神气质。
禁止十五套同一个方盒人台换色，也禁止靠大光圈掩盖贫乏的衣甲主体。
采用完整真实三维设计，人体可使用更修长的概念人台，不受 Minecraft 方块人比例或立方体格式限制。
高阶的贵重、玄幻与神性必须体现在轮廓、裁切、冠饰、材质、负空间和装饰组织，而不只是发光值。

## 最新分片规则

整套不能整体全部由分片构成，允许小部分分片提高层次感。横向纹理接缝允许。
少量护肩、叠甲、装饰羽叶可以作为局部辅层；不得把所有层次抹平，不得擅自泛化禁令。

## 五境与三种样式

| 层级 | 境界 | 三个差异化方向 | 该层应传达的气质 |
|---|---|---|---|
| 1 | 炼气 | 墨青巡霄 / 青铜听雨 / 赤霞护道 | 初入仙门，有讲究的仪容与器物感，绝不是破布武侠农装 |
| 2 | 筑基 | 白青凌云 / 玉衡仪装 / 乌曜夜阙 | 人间精工进入灵材，造型更清贵，出现少量超凡细节 |
| 3 | 金丹 | 金乌曜阳 / 太阴霜华 / 紫霄雷宸 | 日、月、雷三种强识别气质；成熟灵器、华丽但受控 |
| 4 | 元婴 | 星河天衣 / 九色琉光 / 青帝长生 | 星体、琉璃与神木三种异质美；轻盈、透明、空间与生命感 |
| 5 | 化神 | 太虚无相 / 玄极天尊 / 大日归墟 | 超越普通铠甲：空灵、威仪与神圣三条极致方向，神仙气质明确 |

名字可以在同一方向内推敲得更好，但三款不能互相换色替代。不要把风格压成三个重复流派一直升级；允许跨层级演化和反差。
锭应有十五种独立材质和可见细节，但都保持低扁锭家族识别轮廓。

## 交付内容

每套必须包含：独立锭模型与材质、头/胸/腿/靴四件的完整三维造型、整体穿戴前后侧、中文详细设计说明、配色和主要材质、相对前境的升级依据、局部分片的使用说明。
最终 HTML 要能选境界与样式、旋转/缩放、看单件、看锭、看材料、查看十五套总览和完整说明。
平面美感通过轮廓、节奏、主次、留白来做；立体感通过真实厚度、曲面、肩腰比例、冠饰和衣摆结构来做。
不得使用 imagegen，不得用截图或简单色块代替实际模型。

## 协作边界

多个 agent 并行工作，各自只写分配的文件，不回退、覆盖他人的改动。不要创建子代理，不要做 Git 分支切换、提交、推送或 main 合并。
主代理会整合、审稿、验证并提交设计分支。未观察的玩家审美认可和游戏运行均保持 not_verified。
