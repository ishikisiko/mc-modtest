# 玄罡完整模型草案

此目录是用户要求的完整三维建模草案，不是二维物品图标。
包含玄罡锭、锄、镐、斧，以及盔、胸甲、护腿、靴子的独立实体几何、UV、贴图与 OBJ 导出。
防具复用 `tools/equipment` 编译、骨骼挂接、标准／细臂适配与 OBJ 导出；未进入正式 `equipment/` 注册目录。

## 设计边界

- 用户明确禁用分片、拼甲、叠片式设计。采用连续护面、连体盔壳和整体工具头；相连的实体倒角只是连续表面造型，不是叠放的装饰片。
- 玄罡仅比现有玄铁系列精炼一档。灰青钢、窄倒角、整根乌木柄、少量浅刻；保留未来更高阶装备的质感空间。
- 锭的顶面来源为 `tools/ingot_shape.py` 的血灵同族扁锭顶面多边形，按原斜俯视方向还原实体，保持低扁锭的参考造型。它现在是三维实体，不能用旧二维图标的逐像素 alpha 检查冒充任意视角一致。
- HTML 中的穿戴、单件、素模、旋转和缩略图全部读取同一模型。玄铁对照从当前 authored 输入编译，使用同一相机与光照，不重新画一套对照图。
- 不使用图像生成，不改已有装备，不添加属性、配方、注册、套装效果。`enabled: false`；占位铁甲字段只用于已有编译器校验，不代表玄罡的数值方案。

## 来源与构建

- `model.py`：唯一 authored 形状与材质来源。
- `build.py`：调用既有装备编译器，绘制对应 UV 图集，生成完整实体工具／锭网格，回读 OBJ，打包自包含预览。
- `viewer.html`：无外部脚本依赖的 WebGL 试衣间；支持八件单独查看、工具总览、宽／细臂、四种姿态、正侧背视角、拖动、缩放、素模、自动旋转和玄铁同光照对照。

在仓库根目录使用已装 numpy/Pillow 的预览 Python：

```bash
/path/to/preview-python art/equipment/xuangang/build.py --out out/preview/xuangang-model-study
```

产物只写入 `--out`。`assets/` 内有真实防具 JSON、8 套 OBJ/MTL/模型 JSON 与图集；`authored/` 保留输入。
`xuangang-model-study.zip` 是模型设计包，不是可安装模组或经过运行时验证的资源包。

## 实际检查

构建时检查 schema、图集分配、UV 界限、有限坐标、非退化面、三轴实体厚度，以及八件 OBJ 的逐顶点回读。
浏览器检查需覆盖八件、四视角、宽／细臂与站立／行走／蹲下／举手姿态，记录实际选择和绘制结果。

人工外观认可、真实玩家动作、穿戴遮挡、兼容性、音效与 FPS 均保持 `not_verified`。
可旋转离线模型不等于已完成游戏实装，也不能替代玩家审美确认。
