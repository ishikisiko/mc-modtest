# 行尸与骸弓素材

沿用已确认的原版比例、连续衣着和八洲主题。两套素材来自 Codex 内置 imagegen 的 UV 编辑候选，参考图展示行尸与骸弓的待机／攻击方向；候选严格按填充 mask 回贴，最近邻缩小至 64×32，量化为 32 色。原始候选与临时概念图不提交。

`corpse/`、`archer/` 的 `material_tones.png` 是实际生成器输入，`uv_islands_mask.png` 仅约束这份素材原图，`provenance.json` 保存来源与哈希。新几何不沿用素材图的 UV：`uv_truth.json`、`model_uv_islands_mask.png` 由 beastgen 导出，分别对应当前通用款的模型与填充 UV；各地域款在自己的真实模型上独立打包 UV。生成器只取原素材的有限明暗分布，再按三维位置绘制，因此图案可跨 UV 接缝延续。最终外观仍需用户确认。

本轮造型保留原版 8×8 头与硬边比例。源几何按两倍单位导出，再以 `scale=0.5` 渲染，半单位厚度能够拥有独立像素。行尸采用连续收腰衣型、凹眼眶、鼻梁、下颌、牙齿与分开的手指；骸弓采用中空头骨、独立上下颌、真实肋骨空隙、脊柱、肩胛、骨盆和双前臂骨。肋骨是解剖结构，不是分片式盔甲。

`tools/undead_roster/appearance.json` 为 18 款逐个声明轮廓参数、地域构件、材质与中文说明；`tools/beastgen/undead.py` 是共同解剖结构、UV、像素绘制和动作的作者源。布巾、盐壳、菌体、薄霜、藤根、浅浮雕与贴骨血纹均为有厚度的连接体，不以拼片、鳞甲、分段金属板、堆叠护肩或悬浮碎片增加层次。本轮复用已采用的明暗素材，没有重新调用图像生成。

没有新增 GeckoLib 或其他运行时渲染依赖。可运行 `python3 -m unittest tools.tests.test_undead_geometry tools.tests.test_undead_roster` 检查每款几何差异、眼眶与鼻腔深度、胸腔贯通、前臂骨分离、落地位置、腰腿连接及放箭姿态；这些检查不能代替外观验收。
