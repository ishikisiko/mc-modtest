# 行尸与骸弓素材

沿用已确认的原版比例、连续衣着和八洲主题。两套素材来自 Codex 内置 imagegen 的 UV 编辑候选，参考图展示行尸与骸弓的待机／攻击方向；候选严格按填充 mask 回贴，最近邻缩小至 64×32，量化为 32 色。原始候选与临时概念图不提交。

`corpse/`、`archer/` 的 `material_tones.png` 是实际生成器输入；`provenance.json` 保存来源与哈希。`uv_truth.json`、`uv_islands_mask.png` 是 beastgen 输出。最终外观仍需人工确认。

概念与 atlas 提示要求：原版 8×8 头、完整矩形躯干、自然连续四肢；行尸灰绿皮肤、褐灰旧衣与深色裤；骸弓自然骨白、暗色腰布和木弓；硬边像素、受控明暗簇。禁止拼片、叠片、鳞片甲、分段金属板、护肩堆叠、悬浮碎片。atlas 只编辑已存在 UV 岛，不移动、旋转、缩放或增删岛；禁止文字、水印、透视、场景、投影、摄影噪点、平滑渐变及抗锯齿。脸、眼、嘴、衣纹与地域标记在 native 像素坐标确定性重绘。

生成器用该素材控制衣料、骨与弓等大面的有界明暗；区域主题、面部方向与关键边界由 `tools/beastgen/undead.py` 保持。没有新增 GeckoLib 或其他运行时渲染依赖。
