# 云山巨城 · Voxel Cloud-Mountain City

一座可在浏览器中自由游览的三维体素山水城池。所有地形、城墙、街巷、楼阁、树木均由 **0.2 米边长的体素** 构成：
宏伟的中式古城沿山谷层层叠叠而上，溪流化作七级跌水穿城而过；城北百米绝壁上 **飞云瀑** 倾泻入潭，
瀑布一侧石柱之巅立着五重檐的 **观瀑阁**；最高峰顶是重檐六角的 **揽云亭**。城外云海翻涌，
石峰如笋破云而出。从云海中的石阶、正阳门、御街、宫城一路到山顶，道路彼此连通，可一键沿路漫游。
二十四小时昼夜连续流转，日月星辰、天色、光影、云海色调与满城灯火随时间协同变化。

## 快速开始

需要支持 **WebGL2** 的现代浏览器（Chrome / Edge / Firefox / Safari 最新版），推荐独立显卡或 Apple 芯片。

| 方式 | 步骤 |
|---|---|
| 单文件版（最简单） | 直接双击打开 `dist/yunshan-city.html`（已预先构建，无需服务器与网络；修改源码后可用 `npm install && npm run build` 重新生成） |
| 源码版（开发） | 在本目录运行 `npm start`（零依赖 Node 静态服务器），浏览器访问 <http://localhost:8080/> |
| 无 Node 环境 | 在本目录运行 `python3 -m http.server 8080`，访问 <http://localhost:8080/> |

源码版使用 ES Module 与 Web Worker，**不能**直接以 `file://` 打开 `index.html`（页面会给出提示）。
首次载入会在后台线程中生成地形与建筑体素网格，通常需要数秒。

**其他**：`H` 隐藏/显示界面，`?` 操作说明；右侧面板可切换画质（低/中/高）、名胜标注、云海与阴影。
漫游模式从云海中的登城石阶出发，经正阳门、御街、飞越宫城、瀑布水潭，环绕观瀑阁后沿山脊登上揽云亭，结束后自动环绕山顶缓缓旋转。

`cam=x,y,z&look=x,y,z` 自定义机位（米），`time=18.5` 初始时刻，`paused` 暂停时间，
`tour=0.3` 从漫游路线 30% 处开始，`nohud` 隐藏界面。手机竖屏时右侧面板收起在右上角“名胜 · 设置”按钮后。

## 作品构成

- **山水格局**：南北向悬谷台地，东西两侧山脊高出谷底 100–200 米；台地南缘断崖直落云海，四周石峰林立，远山层叠隐于雾中（青绿山水色调，海拔越高越偏石青）。
- **城池**：约 600 座民居、商铺、合院、茶楼沿等高线台地（每级 4 米挡土石墙）铺开，东西向石阶巷道逐级登高；南城墙与东西山脊城墙相连、如长城般攀上山脊，设正阳门、水门、垛口与十余座敌楼。
- **人间烟火**：约 260 位体素行人与卫兵（每人约 9 个体素高，1.8 米）散布在御街、市集、湖岸、码头、宫城、城墙与山顶，湖上与河中泊着乌篷船——人物的尺度正好衬出城墙、宫殿与百米瀑布的宏大。
- **水系**：瀑布潭 → 六级跌水河道（每级 12–24 米，带跌水水花与阶梯码头）→ 镜湖（湖心八角亭、九曲桥）→ 水门 → 断崖处坠入云海。拱桥与廊桥横跨河道。
- **宫城**：三级台地、汉白玉须弥座与大台阶，重檐庑殿正殿、歇山后殿、配殿与角楼，红墙黄瓦。
- **地标**：飞云瀑旁石柱上的五重檐观瀑阁；东山十三层八角凌霄塔；西岭楼阁；市集鼓楼；山顶揽云亭及半山小亭；城外云海中几座最高石峰顶上还有隐士小亭。
- **道路**：云梯石阶 → 正阳门 → 御街 → 宫城 → 河畔阶梯码头 → 潭边崖道 → 观瀑阁 → 绝壁石阶 → 盘山步道 → 揽云亭，全程相连。
- **昼夜**：按纬度约 29.5° 春末计算太阳高度与方位，月亮大致与日相对；天空、日光、天光、雾色、云海受光按太阳高度连续插值；黄昏起灯笼与窗棂按户陆续点亮，深夜部分熄灭；夜间有月光、星空与银河，城中陆续放飞孔明灯；白天有仙鹤群绕峰盘旋，清晨山谷起雾。

## 技术说明

- **0.2 米体素**：地形为逐列体素高度场（高度量化 0.2 米），建筑与树木为 0.2 米体素模型；近处以原始 0.2 米体素渲染，远处按距离使用 0.4/0.8/1.6/3.2 米聚合 LOD（仅为渲染优化，数据始终是 0.2 米体素）。
- **地形**：四叉树 LOD，每个节点 64×64 列，由 Web Worker 采样、剔除隐藏面、计算体素环境光遮蔽并贪婪合并，打包为 8 字节顶点；节点边缘带裙边避免裂缝；深埋云海之下的低地压平以节省面数。
- **建筑**：约 90 种预制体（程序化生成：庑殿/歇山/悬山/攒尖屋顶光栅化，举折曲线、起翘、飞檐、筒瓦、鸱吻、斗拱、隔扇、马头墙等），每种在 Worker 中生成 5 级 LOD，按实例距离分桶实例化绘制。
- **渲染**：自定义着色器；三级级联阴影（日/月）；半分辨率体积云海 + 山腰云带 + 瀑布水雾光线步进；HDR 管线、泛光、ACES 色调映射；灯火光照图与窗户/灯笼自发光；水面菲涅尔天空反射与日月高光。
- **自适应**：按显卡自动选择画质，帧率不足时自动降低渲染分辨率。

## 目录

```
index.html            入口（import map 指向 vendor/three.module.min.js）
server.mjs            零依赖静态服务器（npm start）
src/main.js           启动：规划、Worker 池、渲染循环
src/world/            地理（geo）、城市总体规划（plan）、高度/材质场（field）
src/voxel/            体素模型、屋顶/构件/建筑/地标/树木生成器、网格化（LOD+AO+贪婪合并）
src/render/           地形 LOD、实例化建筑、天空、阴影、云、后处理、着色器
src/sim/daynight.js   二十四小时昼夜模型
src/ui/               相机（环视/漫游/飞行）、界面
src/workers/          生成 Worker 与任务池
tools/                单文件构建、离线地图与预制体预览
vendor/               three.js r186（MIT）
```

开发辅助：`npm run map -- out.png` 输出俯视地形/规划图；`npm run prefab -- out.png pagoda,guanpu` 离线渲染预制体预览。
