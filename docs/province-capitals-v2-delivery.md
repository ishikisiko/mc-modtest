# 七州重设计与地图传送交付记录（0.102.0）

本轮重做东海、西漠、北原、灵岳、南疆、东荒、魔域七座城市的 authored 总图与真实方块建筑；中州沿用完整云山 v1。新建世界采用 V9，旧 V1–V8 继续读取原冻结资源，已有存档不会自动替换城体。

七城的住宅、店宅、曲尺院、深院、干栏屋、台地宅与公共建筑使用独立地块宽深、朝向和层数。建筑库包含15族、每族4种结构变体，各州按地貌和功能选取，不要求使用同一配比。客栈、药铺、铁匠、市场和向导服务各有实际主建筑与设施；本轮不追加交易细节验收。

玩家按 H → 天下 → 舆图，点击城标后确认传送；取消或 Esc 返回原视口。服务器验证冻结城市与计划指纹、玩家状态和实际安全落点，客户端不传目标坐标。协议55需客户端和服务器一致。

## 画面与证据边界

七城三维预览由最终方块记录生成，使用材质示意色，不是游戏纹理截图；每城提供全景和代表街景。中州使用未改变的v1最终NBT和高度场独立回读，不以旧概念模型替代已交付城体。已埋藏实心方块可仅为预览做遮挡剔除，不能修改正式资源。

画面用于观察城市轮廓、街区、高差和建筑组合。玩家外观、步行手感、音效、FPS、多人以及每栋内部与完整水流均保持 `not_verified`。数量、静态检查和开发者看图不能替代这些接受项。
