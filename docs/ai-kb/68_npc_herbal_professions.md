# NPC 药业职业（0.93.0）

技术边界见 [命簿权威](../contracts/world.md)、[炼丹和种植](../contracts/cultivation.md)。本次沿用命簿人物、生活执行器与唯一化身，不建立第二套人物身份。

## 分工

药童（`herb_child`）负责普通采药、普通药圃种植收获与交货；灵植师（`spirit_grower`）专注种植与养护；炼丹师（`alchemist`）消耗分类药材生产丹药。采集、种植、炼丹分别记录技艺经验，职业与修炼境界独立；解除登记、换岗保留技艺和随身药材、盘缠、疲劳，未任职期间由同一人物档案保管，再任职后移回生活记录。职业不是自动晋升链，炼丹师不会因称号自动获得高级种植能力。

原 `herbalist` 兼容 ID 保留，中文为药铺伙计，只收购、销售和营业当值。没有炼丹师时，有限成品卖完即止；没有伙计时，生产与柜台营业分别判断，不由炼丹师自动接管交易。

## 生产与兼容

六味现有药材按真实物品 ID 入库。指定种类的有限采集点供药童采药；交货后供药圃取种或炼丹。种植消耗对应种源，经过共同生活时钟记录的生长期，成熟后才可收获；灵植师可养护。丹药配方的材料、数量、时长和产量取自既有 `alchemy/rules.json`，只开放原药铺出售的基础丹药；游戏运行时与玩家丹炉读取同一内置来源，不允许数据包单独改变 NPC 一侧。药圃产量、经验门槛和成功经验在 `world_sim/herbal_profession_rules.json` 调整。启用商业后，NPC 交货、药圃收获与玩家售药共用草药报价定义的仓储上限，旧未分类药材同样占容量。

药圃和采集点为有界命簿模拟，NPC 到登记站位完成活动；本版不操作真实灵植方块、不新增药材或贴图，不模拟玩家丹炉的燃料槽和炉火界面。NPC 商品仍是原有下品，不生成高品质或高阶丹药。

近处仍需身体真正到达，远处使用同一活动记录；阻路、缺料、满仓和未完成的活动不发产出。职业技艺在成功生产后增长，不按离线时长自动晋升。成熟药圃不会自行收获或刷新库存。

旧人物、岗位和库存保留。旧未分类药材单独保留，不分摊成指定灵草，也不能替代新丹方；旧抽象药品不再用于自动补货。已有商店不会因更新重新初始化成品。

## 进入与检查

在已有生活地点为现有命簿人物分配职业，沿用 `/myvillage life assign`；职业所需的采集点、药圃和工作站须先显式登记。命令只登记现存空间，不替玩家建房、放作物或创造人物。使用步骤以 [README](../../README.md) 的“NPC 药业职业”段落为准。

人物近况显示当前职业及独立技艺，`life status` 提供管理员检查快照。涉及真实玩家交谈、交易、寻路观感、音效、FPS 和多人体验的结论，需与纯逻辑、构建和服务器存档探针分开记录。
