产品：断戈营垒的三段推进、伏妖残殿的三波挑战，以及整座遗迹共享的一次性封印宝箱。
重型 Gradle、服务器、真实客户端和双客户端检查只在 Modal 运行；没有本机游戏回退。

## 定向检查

- 本地 27 项生成、通路和相关 Modal 工具测试通过。
- 云端 `ruins.*` 共 10 项 Java 测试覆盖已有丹霞残阵、战斗阶段、绑定 UUID、和平重试、
  重复奖励拒绝、保存状态和两份规则；修正奖励上限后通过。
- 每次产品构建均先检查两座遗迹生成资源一致性，再打包已提交模板。
- 真实鼠标攻击与菜单操作和 RCON 场景准备、读回、远端死亡探针分开记录。
- 冻结守卫和增强玩家力量用于隔离状态转换，不作为战斗平衡、走位手感或难度证据。
