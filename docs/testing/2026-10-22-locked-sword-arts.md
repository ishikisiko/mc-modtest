# 0.80.0 太白剑脉锁定绝技交付

## 实现范围

- 庚金剑诀：前方广角取得目标，短暂凝聚后追击，命中后附加不叠层、会到期清理的护甲削弱。
- 天罡剑典：锁定初始区域，压低普通移动速度，七次剑罡独立结算，末次强化；身法可以避开部分段数或脱离区域。
- 太白剑经：延迟单体追斩，持续跟随普通移动；墙体、距离和目标有效性始终受服务器检查。

## 证据边界

原生客户端映射输入与服务器状态回读用于开发者验证；管理员命令只准备学习/境界/目标条件、控制测试时间及读取状态，不调用施放或闪避。测试 ticks 的冻结/步进用于确定窗口边界，不代表正常操作节奏。玩家外观、音效、手感、平衡、FPS 和广泛多人仍待玩家验收。

首次实机启动还发现 H 字体并行预加载问题：FreeType `0x14 (Loading glyph)` 导致资源重载，随后 NeoForge 报 `Duplicate cauldron registration`。原版源码显示引用字体集会共用 provider，而 TTF `getGlyph` 操作可变 face；H 标题原来引用正文字体集。修复将标题回退链展开为独立 providers，字体、字号和回退顺序相同，新增资源结构检查。失败客户端日志与 crash report 均保留，未将该次启动记为玩法通过。
