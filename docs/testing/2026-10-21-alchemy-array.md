# 青铜丹炉阵交付验证

对应 0.72.0；玩法与研究说明见[多方块炼丹炉](../features/multiblock-alchemy.md)。
重型编译、服务器和客户端均在 Modal，未使用玩家电脑运行 Minecraft，未更换用户存档。

## 检查边界

- 资源：六组件的模型、贴图、四向／亮炉状态、中文名称、配方、掉落和标签；同源三层蓝图。
- Java：现有炼丹逻辑与新增结构／事务测试；全资源 jar 保留世界规划生成任务。
- 实际运行：四向装配、中心堵塞、缺件、缓存句柄和模拟、映射放块／菜单／蓝图、
  原版漏斗连续生产与活动补料、堵口、拆坏、保存重启、运行画面和旧炉兼容。
- 整炉卸载使用 `Level.hasChunkAt` 的只读管理员查询。原版 `execute if loaded` 检查实体 ticking，
  不能代表检测代码使用的 full-loaded；普通 forced ticket 还会使相邻区块保持加载。
  局部活动组件区块不可用只有纯逻辑覆盖，不冒充实际世界卸载证据。
- 命令布置、原生诊断和服务器读回单独标记；玩家流程以实际键鼠映射输入为准。
  管理员 `stale` 诊断只接受空且未活动的炉阵，临时拆装后恢复原 NBT。
