## 保留的失败记录

1. 早期编译失败与修正前日志保留在构建证据中，最终编译和测试独立记录。
2. `quest-native-1`在冷启动规划完成前耗尽480秒启动预算，玩法completed为0。发现Gradle退出后仍有自有服务器子进程，按PID与启动时间确认后停止，并保存启动世界；服务器采集器增加了子进程清理及1200秒启动预算。
3. `quest-native-2`的1GiB客户端在资源加载期间内存不足，玩法completed为0；仅将本次采集客户端堆内存设为4GiB后重试。
4. `quest-native-3`把两个测试玩家放在相同读榜位置，射线被另一玩家遮住，未接取任务。修正夹具站位后继续使用真实右键和菜单点击。
5. `quest-native-4`完成14类中的11类，剩余兽巢单人通关、归属拒绝及救援三类未完成。山寨完成并回收后，第二实例生成触发`FlatLevelGeneratorSettings.adjustGenerationSettings`空指针：共用的空气层已被前一实例改为`null`。保留日志及失败世界，按归属停止失去响应的测试服务器；产品改为每个实例复制独立配置，并添加生成器回归。该次失败收据保持failed，没有计为整轮通过。

最后一轮从无远征记录的自建启动世界归档复制新的测试世界，保留原失败世界及其收据。归档来源、SHA-256与旧JAR身份记录在新收据中；仅复用主世界生成，全部玩法重新执行。

## 验收边界

使用高境界玩家、恢复效果及位置准备缩短战斗验证；重启测试包含明确记录的非致死7点生命夹具。结果用于证明真实攻击能推进有限名单，以及正常保存、结算和实例生命周期。关卡的完整连续步行、数值平衡、战斗手感、音效、FPS及玩家多人体验仍为`not_verified`。截图状态为`captured_for_review`，外观接受由玩家判断。
