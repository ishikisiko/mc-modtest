# 商人批量交易（0.64.2）

## 交付范围

药铺、铁匠铺和客栈所有现有命簿商人共用 `CommerceScreen`：买入／卖出分标签，统一数量输入框，两侧减／加按钮，每页三行。商品显示本次实际总数和总价；切换标签重置数量为 1，翻页保留数量并映射回原报价索引。客栈疗养属于买入服务，数量固定一次；无商品的标签显示空态。

数量上限沿用 `commerce_rules.json.stock_limit`，网络另有安全界限；客户端不传价格或物品。服务端先校验完整报价、公库、库存／收购容量，再规划完整背包替换，一次提交整笔交易。失败不部分成交，一次批量成交只增加一次交易计数。普通物品组件限制、执行租约、会话 token、序号及共享 revision 检查保留。

网络协议 34，客户端与服务端需同步更新；命簿存档仍为 v6，没有新增持久字段。
