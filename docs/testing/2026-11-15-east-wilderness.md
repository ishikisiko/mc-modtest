# 东荒生态与地区档位验收

本次版本为 0.132.0。地区强度按东荒、灵岳、北原、东海与西漠、南疆与魔域、中州分为六档。东荒为出生州；同档共用阶位和野怪境界范围。八城官道继续串联，千机阁和宗门等级按新档位取值。

东荒按种子规划十二处据点，每种三处：妖狼巢地、赤甲蜥岩地、灯孢菌地和劫修营地。成员有有限名单、留守、巡逻或夜间巡猎、同群支援、跨群体选敌和低血量撤退。默认每个修炼历法月恢复一轮；目前历法默认一月为两个 Minecraft 日，20 TPS 时约四十分钟。换月恢复会等待玩家离开近处并脱战，保留玩家建设，不重新施工据点。临时掉落为每名一至三枚下品灵石。

## 失败记录与修正

- 最初将全部生态方块及配置嵌入冻结规则时，超过已有字符串传输上限。随后改为冻结资源 SHA-256，并在运行时核对配置与模板的精确资源；保留原容量上限。
- 首轮九十项 Java 检查有三项使用旧预期：西漠最低境界、总舵地区数量、原版生物改为加法体质数表后的属性。按现有作者数据更新精确断言，并保留有效数值上限检查；复验九十项通过。
- 首次新世界启动触发十五分钟等待超时。该时刻道路和矿口规划持续推进。清理步骤又因 RCON 尚未开放报错，导致原始 result 未写入失败字段；原始日志和 result 均保留，另以 `startup-timeout-diagnostic.json` 记录失败及后续安全保存停机。后续等待预算调整为三十分钟，同一自建世界接续完成原有检查。
- 早期千机阁采集脚本要求站位所在方块必须为整块空气。中州总舵采用细分碰撞方块，失败位置的实际方块与作者输入完全一致。采集器增加四层方块状态精确读回，使用现有服务端碰撞探针检查全部三十一处站位，并按作者元数据核对任务板朝向。两次复验世界均通过，建筑资源未为消除测试失败而改动。

- 补拍首轮因日志接口的 `kind` 参数重名中止，已修正记录字段并仅重跑补拍。镜头按真实地表高度放置，在核对 SHA-256 后创建的基准存档副本中拍摄。首次相机落入岩壁的原图及中止日志均保留。
