# 0.77.1 物品栏两侧的技能图标

## 实现

移除原有右侧两行常驻技能文字面板。第一招 Z 在物品栏左侧，第二招 C 在右侧；每格 24 GUI 像素，物品栏外侧各预留 32 像素给副手与攻击指示。六招独立图标由 `tools/advanced_arts/icons.py` 维护，`tools/gen_advanced_art_icons.py` 生成六张 32×32 RGBA PNG。

图标角标读取实际绑定键。冷却显示纵向暗色遮罩和秒数；未学／境界不足显示锁；灵力不足显示红色和叹号，成本复用锻器减耗计算。这里只读客户端快照，原有键位意图、服务器资格／费用／冷却和动作状态保持原路径。
