# 0.77.2 统一主动战斗技能栏

## 范围与实现

沿用 0.77.1 的物品栏两侧图标风格，扩展为四格：左下 Z、右下 C 为当前武器两招；左上右键为当前武器可用的主动波技能；右上 Alt 为服务器选中的身法。每格 24 GUI 像素，上下间距 28，继续为副手与攻击指示留出 32 像素。

四格共用服务器只向本人发送的有界快照，统一处理锁定、灵力不足、动作受限、冷却、蓄力和收招。读取原有武技、剑气与身法的实际选择器、计时和锻器减耗；地面身法免费规则保持不变，空中使用仍由原有天命规则决定。客户端只插值显示，不结算费用、命中或冷却。网络协议升至 40。

覆盖现有已实现的主动战斗技能入口。被动功法、天命自动触发以及炼丹等非战斗功能不占技能格；没有把功法目录中的所有条目当成主动技。
