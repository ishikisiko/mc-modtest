# 阡镇《灯尽之前》：剧情与人物验收

本次内容为 MyVillage 0.86.0 的阡镇第一章，使用已有六处建筑、四名命簿人物、
JSON 剧情、原生对话与纯文字任务追踪。构建和原生游戏检查均在独立 Modal
环境进行；没有启动用户电脑，也没有替换已有存档。

## 交付范围

程砚引路、沈岚委托、周禾提供线索、陆衡解释护泉古阵。玩家主动了解并接受
委托，调查药圃，选择药庐检样或旧驿运药记录，核对新刻阵纹与旧阵用途，
恢复取灵限额、领取谢礼并辨认旧契签押。问灵小院既有测灵与传承不是强制前置。

章节正文、选项、目标、条件变体和奖励在 JSON 中编排。共享世界记录周禾
返回药庐与古阵处置；个人 Attachment 保存每人的进度、线索和领奖回执。
后来者按当前共享事实核实经过，不自动获得别人的进度或报酬。

周禾回镇是剧情安排送回，没有实机步行护送。检样是现场调查，没有新增
炼丹配方或小游戏；本章没有新增战斗关卡。古阵处置保存共享事实并播放粒子，
不声称已实现动态药田恢复或灯火模拟。场景由管理员在独立平坦世界显式部署，
不进入自然生成或冻结 worldplan。

## 必要检查

离线检查覆盖六栋生产模板和道路、153 个原有及剧情站位、保留人物占位后的
连通性、生成一致性、章节分支规划、物理输入日志解析及调度边界。Java 范围
为章节定义/状态/会话/奖励/网络与 UI 布局、命簿迁移、人物唯一身份与租约、
原有玩家宗门和生活/战斗相邻回归。

原生采集器选中十项：生产部署、第一章连续推进、救援后重启、满包领奖、
领奖后重启、后来第二玩家另一分支、死亡与跨维度、正常/窄界面、未接取世界
导出和最终世界导出。推进必须使用真实 W/A/S/D、右键和对话按钮；RCON 仅
准备独立 fixture 和读取服务器结果。旧 nonce 的恶意封包注入不属于本次原生输入验收。
