# 0.70.1 实体锻器台交付证据

## 改动与检查范围

锻器台增加石炉、木台、砧角、挂钳和支架锻锤；六类器物在砧面显示实际阶段，
热坯使用独立烧红材质，落锤按服务器接触 tick 同步。交互仍使用原生锻器界面。
同一实体锻台一次供一人使用，其他玩家可旁观；菜单仍保管真实物品，展示数据
不持有、掉落或保存另一份物品。关闭、死亡、拆台与重启的已有物品规则保持。

最小检查为工坊资源检查、受影响 Java 测试、云端双客户端旁观／工位交接、
生命周期和中文界面。没有选择无关采集、战斗、平衡或全量发布验收。
重型构建和游戏全部运行于 Modal，没有启动用户本机游戏。
