# Waystones 大境界与路程计价验证（0.114.2）

本次在已有灵石袋适配上增加报价变量。费用按基础下品灵石数、大境界倍率和有上下限的路程系数相乘，原有服务器库存事务和退款逻辑继续负责付款，不将袋余额转换成浮点数。

## 配置和范围

默认基础费用为 1；凡人、炼气倍率为 1，筑基为 3，金丹为 10。小阶段不影响费用。同维度按水平直线距离，每 1000 格向上取一档，路程系数限制在 1～10；跨维度固定使用系数 10。单程费用分别为 1～10、3～30、10～100 枚下品灵石。

参数唯一运行入口为世界的 `serverconfig/myvillage-waystones-server.toml`，由 NeoForge SERVER 配置同步给客户端；修改后重启世界或服务器。Waystones 的 `config/waystones-common.toml` 需要使用 `scaled_add_item_cost(myvillage:waystone_spirit_stone_cost, myvillage:low_grade_spirit_stone, 1)`。已有固定费用不会自动替换，示例仍只对从传送石出发的路线收费；原 XP 项需移除。

菜单从已有客户端档案快照读境界，服务器始终从 `CultivationService` 读实际玩家档案。两侧共用 `WaystonesPricingRules`，没有让客户端上报价格、倍率或余额。境界变化后重新打开菜单刷新报价。未知境界的备用倍率是显式配置项，默认 10；无免费降级。

Waystones 公开变量为 float，因此单次最坏费用必须处于连续整数可精确表示范围内，配置乘积超过 16777216 时拒绝使用。这个限制不影响灵石袋的大整数存储容量。
