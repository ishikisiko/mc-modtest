# 技术约束索引

这些文档合并了旧 OpenSpec 中仍有用的运行时、资源和几何约束。它们不携带提案/审批/全量验收流程；检查范围由 [工作流程](../WORKFLOW.md) 决定。

| 主题 | 内容 |
|---|---|
| [assets](assets.md) | 数据格式、资源、物品、匾额、指南 |
| [buildings](buildings.md) | 生成层次、风格、体量与屋顶 |
| [compounds](compounds.md) | 院落围合、路径、宅园与假山 |
| [towns](towns.md) | 分区、街面、地形适配与实现 |
| [world](world.md) | 区域、宗门、命簿、境界与野外 |
| [cultivation](cultivation.md) | 档案、入门、修炼、功法、天命与炼丹 |
| [combat-entities](combat-entities.md) | 战斗权威、武器模型、妖兽、NPC与飞剑 |
| [tooling](tooling.md) | 采集、预览、云端与可选工具 |

旧 capability 名称保留为链接锚点；详细 API/调参以代码和 authored 数据为准。历史原文与清理去向见 [清理记录](../maintenance/openspec-cleanup.md)。
