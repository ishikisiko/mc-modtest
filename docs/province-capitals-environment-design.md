# 八州地标与生活环境设计首版

本文件保留 `5719d17e` 设计阶段的范围与证据。用户已要求正式接入，后续实现见 [V10 接入说明](province-capitals-v10-integration.md)；不能把本页的设计截图算成原生验收。

本批是 0.102.0 七州城体之后的独立视觉设计。八州各有一个真正三维的非房屋主地标；灵岳、东海另有整城环境样板，覆盖庭园、门前陈设、公共节点、修仙小设施和城防。中州此阶段只提供浑仪核心物，尚未修改云山城体。

所有功能说明目前均为设计意图，未新增聚灵、镇潮、炼器或护城逻辑。纯观赏地标不要求附带交互。实际功能接入由下一阶段逐项定义和验证。

两座样板的房屋、地形与道路由未修改的 v2 生成器在内存中重建；新环境来自独立 authored 输入。样板在视图中移除灵岳旧主厅及一栋邻宅、东海旧书楼，为新构图预留空间。这里只表达设计取舍，不改变旧世界或现有居民记录。新铺地和接路与旧表面错开，避免共面闪烁；完整游戏碰撞和步行仍待后续正式施工验证。

## 源与生成

- `blueprints/province_capitals/environment_design/catalog.json`：唯一的材质、体素造型配方、八州设计说明和环境参数来源。
- 同目录 `lingyue.json`、`donghai.json`：逐项庭院范围、院门及接路、街边设施、城防折线、门关、台阶、视点与取舍记录。
- `tools/province_capitals/environment_design/geometry.py`：方体、椭球、连续环、回转体和实体连接梁的构造及无损行合并。
- `generate.py`：重建或按源码摘要复用设计底座，消费全部设计输入，导出独立几何、清单和自包含三维页。
- `viewer.js`、`template.html`：环绕、缩放、平移、固定视点、图层开关和物件点击。所有新界面为中文。
- `capture.cjs`：使用本地 HTML 采集设计画面，不启动 HTTP 服务、Minecraft 或云端。

```bash
python3 tools/province_capitals/environment_design/generate.py
```

默认输出到忽略目录 `out/preview/capital-environment-design-20261029/`。完整入口为 `index.html`，两城合集为 `cities.html`。前端分别展示 `lingyue_city.html`、`donghai_city.html` 和八州地标页 `landmarks.html`，满足每次内嵌 HTML 的大小上限。另有八个单地标 HTML、压缩几何和 `manifest.json`。Three.js、控制器、设计数据与显示代码全部内嵌，预览不依赖 CDN。浏览器需要支持 WebGL 和 gzip `DecompressionStream`。城体地形以有界高度场传输，采集时比较浏览器重建的全部顶点及三角面与源几何摘要。

设计底座缓存同时保存城市输入、建筑库及相关生成代码的逐文件摘要。摘要不匹配时重建；缓存不证明已经重跑正式资源导出或游戏生成。

本地截图使用环境中的 Playwright 与 Chromium，可通过 `PLAYWRIGHT_MODULE`、`CHROME_BIN` 指定已安装位置，然后运行：

```bash
node tools/province_capitals/environment_design/capture.cjs
```

## 审阅与后续边界

当前应确认地标选型、比例、两城环境密度与城防关系。数量检查不代替视觉判断；完整主体也不等于已满足玩家审美。

新场景未接入 Gradle、registry、NBT、世界预设或版本文件。本批不升 mod 版本，不构建 jar，不替换玩家模组，不启动玩家游戏。下一阶段按已约定的视觉确认结果接入正式生成器与独立布局版本，保留 V1–V9 原资源和旧存档引用。

纯设计中的院门接路、八州唯一配方、非空几何、合法材质和城防闭环有生成约束。原生碰撞、所有院落的真实步行、NPC岗位、功能、音效、FPS与多人均为 `not_verified`。自由相机不能当作映射输入或玩家行走证据。

原始失败画面和报告保留在输出目录的 `attempt01-loading-overlay/`、`attempt02-overexposure/`、`attempt03-before-paving-stairs/`。分别记录加载遮层、过曝/纹理采样和最终场景采集中断；不得将这些图片列作最终采集完成。正式采集结果以输出根目录的 `capture-report.json` 为准。
