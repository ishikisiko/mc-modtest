# 五境模型试穿

0.100.0 将十五套衣甲与十五种锭的已确认三维模型接入游戏。
每套衣甲包含头饰、胸衣、护腿和靴子，可单穿或混穿；旧装备保留。

- 炼气：墨青巡霄、青铜听雨、赤霞护道。
- 筑基：白青凌云、玉衡仪装、乌曜夜阙。
- 金丹：金乌曜阳、太阴霜华、紫霄雷宸。
- 元婴：星河天衣、九色琉光、青帝长生。
- 化神：太虚无相、玄极天尊、大日归墟。

本次只做模型接入。五境名称区分视觉主题，没有境界数值提升、获取配方、
器谱、炼器工序或套装技能。新护甲统一使用铁甲基础属性和铁锭修复。
新锭只提供立体物品表现，尚无生存获取或材料用途。

从模组创造栏取得装备，放入原版护甲槽试穿；也可使用命令，例如：

```mcfunction
/give @s myvillage:qi_moqing_chestplate
/give @s myvillage:yuanying_jiuse_ingot
```

支持宽／细臂玩家，头饰、袖臂、腿部和背部装饰随对应骨骼运动。
流光、局部发光和悬浮动作仅为装饰。客户端配置
`myvillage-immortal-client.toml` 提供动效开关、距离与数量限制。
当前不支持原版盔甲纹饰；附魔沿用原版护甲行为。

检查范围见[模型采集方案](../testing/immortal-equipment-plan.md)。
截图、脚本读回和编译结果不能代替玩家对外观、动作或性能的接受。
