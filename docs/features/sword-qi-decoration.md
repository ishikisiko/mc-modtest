# 剑意灵台

可独立摆放的剑气装饰，物品与方块 ID 均为 `myvillage:sword_qi_pedestal`。
创造模式在 MyVillage 主物品栏获取，或执行：

```mcfunction
/give @s myvillage:sword_qi_pedestal
```

灵台占一格，朝向随放置方向确定；上方约五格的青白剑气、回旋气流和金色符光只有视觉效果，不碰撞、不造成伤害、不消耗灵力。空手右键灵台开关剑气，开关存于服务器方块状态，拆除时效果随根方块消失。当前作为建筑装饰样品，仅从创造栏或命令获取，不设生存配方，不自动放入城主府。

整体剑形采用连续刃体和有厚度的四面轮廓；周围两道连续气流缓慢回旋。使用原版半透明渲染和全亮光照，软边纹理表现光晕，无需光影包。未接入后处理泛光、动态照明、战斗剑气或粒子实体；灵台自身发出普通方块光。

`assets/myvillage/sword_qi/appearance.json` 是比例、碰撞、颜色和动画参数来源。修改后运行 `python3 tools/gen_sword_qi_decoration.py`，用 `--check` 检查对应的模型、中文名、掉落表、贴图和物品图标。公共注册和开关归 `decoration/`，客户端效果归 `client/decoration/`。

构建、原生采集和玩家视觉认可分别记录；开发者采集画面不代表玩家已认可外观或性能。
