# 三汊潮滩与赤砾风槽

修仙大陆在东海生成三汊潮滩，在西漠生成赤砾风槽。世界种子和州域条件共同确定地貌，地表高度、群系与首领选址读取同一套地形。每只首领从合格地形中选一处，世界计划保存所用规则，同一种子会得到同一落点。城镇、宗门、官道和矿口先按大陆原有规则确定各自的地基。新地貌从这些地基外开始过渡，区块表面、群系和首领位置共同使用过渡后的高度。首领选址还会避开已有奇观。

| 生物 | 出现地点 | 战斗与掉落 |
|---|---|---|
| 泥甲潮蟹 | 三汊潮滩的近水泥滩 | 蟹钳横扫。掉落泥纹钳钙和潮蟹盐囊。 |
| 钩颚砂蝎 | 赤砾风槽的砂砾与坡肩 | 夹击和钩尾刺击。掉落钩颚黑壳和凝砂尾节。 |
| 回潮螭 | 三条潮沟汇向同一湾口，满潮时仍有高岸可走 | 以近身扫击和涨潮迫使玩家换位。触动旧闸可以提早回潮，回潮时鳃侧更容易受伤。掉落回潮鳞和潮峡石印。 |
| 背碑石猿 | 有宽谷与可从沟尾绕行的裂沟，关碑能搭到两岸 | 抡臂横扫和落碑。关碑临时形成过沟路径，落碑后石猿的背部榫窝暴露。掉落榫岩髓和旧关石印。 |

四只生物使用现有妖兽渲染、动作和伤害管线。方块造型与像素材质沿用三维预览的原稿。首领的遭遇归属、命中、潮水与关碑由服务器处理。首领在生存或冒险玩家进入遭遇范围后创建，已占用的落点在卸载后保留，世界记录击败结果。

群系、选址和数值配置见 `blueprints/worldplan/rules_v11.json` 与 `data/yuanxian/beast/`。生成文件由对应工具写入，世界适配以新开修仙大陆的实地结果为准。


## 在游戏中查找

新建修仙大陆世界后，管理员可以执行 `/yuanxian worldplan field_encounters`。在返回数据里，`home` 是首领活动区的入口坐标，`exits` 是可步行到达的高岸或谷地出口。`sluice` 标出峡口的旧水闸，`bridge_a` 和 `bridge_b` 标出西漠落碑的两端。用 `/locate biome yuanxian:three_tidal_flats` 或 `/locate biome yuanxian:red_gravel_windcuts` 可以找大片群系。

退潮会清除战斗临时水面。落碑在背部恢复后等桥上的玩家离开再收回。自然海水、断沟岩壁和玩家已摆放的方块保留。两只首领的首次击败结果归当前世界。
