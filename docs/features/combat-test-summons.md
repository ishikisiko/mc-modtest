# 取物器的测试单位召唤

品质取物器沿用 `myvillage:quality_picker`，右上角“召唤与战斗”进入配置页。当前版本为 0.124.0，网络协议为 71，客户端与服务器需要使用同版。

可以选择普通修士、模组敌对单位和原版敌怪。服务器在玩家视线前方寻找已加载、位于世界边界内且无碰撞的落脚空间；空间不足时返回原因。每个玩家最多保留 64 个已加载测试身体，操作范围为当前维度附近 64 格。召唤、修改、暂停和删除都要求操作玩家存活、处于非旁观模式，并且仍持有取物器。

## 配置

- 境界与阶段读取现有数表，属性编辑器读取所选实体的属性供应表。填写的值覆盖境界计算后的属性，装备和天赋继续叠加；空白按境界计算。服务器按实际属性范围校验，通过独立的永久修饰保存覆盖值，保留境界修饰的幂等更新。
- 修士支持筑基与金丹品质、五行灵根、兵器与技艺资质，以及起始灵力和容量。空白资质沿用本次出生值；空白容量采用境界值，空白起始灵力填满容量。起始灵力不能大于容量。
- 三个指定天赋必须各不相同且仍启用，全部清空时按正式出生池抽取。测试配置允许任意三个启用词条组合，便于检查效果；出生记录保存实际花费及可容纳该组合的测试预算，不改变自然出生的预算、资格和互斥规则。
- 修士默认持有现有 NPC 初始武器。攻击意图进入 `NpcCombatGoal` 与 `CombatSessionManager`，命中、伤害、消耗和冷却使用正式执行器。

## 功法与技能

选择修士后进入“功法技能”页，搜索功法名称或注册 ID，点击“添加到已学”。可以填写非负整数熟练度点数、选择运行心法和武器，并为绝技、身法及已获天赋能力设置自动施放。心法与炼体功法的效果由已学和运行状态决定。

优先级范围为 0～999，数值越小越先尝试；相同优先级按技能 ID 排序。高优先级技能处于冷却或不满足条件时，NPC 会继续检查后续技能。关闭自动保留学习和熟练度记录。NPC 自动充能剑气至满蓄力后释放；地面身法在敌人出招或自身达到撤退血线时尝试，沿用正式取消窗口、碰撞、无敌窗口和冷却。

现有主动剑气、多段剑／枪／拳武技、太白锁定剑诀、五行法术及已获天赋能力共用原施放执行器。实际施放会检查当前境界、灵根、所持武器、灵力、冷却、目标关系、视线和相应招式的距离。天赋能力必须拥有其来源词条，服务器才接受配置。主动命中按原成长数据增加熟练度。运行心法使用原心法恢复系数；定义了炼体属性效果的已学功法按资格提供属性修饰。

回锋御剑诀、分影步、伏火诀与镇岳诀依赖专属法器及对应玩家执行器，目前可记录已学和熟练度，界面关闭其自动开关并显示说明。普通测试 NPC 使用现有 NPC 模型与动画；本次没有新增枪、拳或法术专用 NPC 骨骼片段。

修改已召出的修士：进入“单位关系”，选择该 NPC，点击“技能”。服务器会读回该身体的当前配置，页首显示编辑对象；修改后点击“应用到该 NPC”。“用于新召唤”将当前配置切回召唤草稿。应用时取消旧动作并保留已产生的恢复时间与冷却，同一武器保留实际物品状态。

## 敌对关系

测试关系保存于身体的 `myvillage:test_unit` 数据中，包含召唤者 UUID、四选一阵营、敌对阵营集合、是否敌对召唤者、是否敌对妖兽及敌怪，以及指定单位的双向覆盖。

任一方将另一方阵营列为敌对，双方就互相敌对；指定单位的“互相中立”或“互相敌对”优先。清除指定覆盖后恢复阵营与种类规则。未列为对手的测试单位受友好伤害保护。不同玩家的测试单位互相隔离；单位只会把自身召唤者纳入“敌对本人”。

测试单位的高优先级选敌目标按实际感知距离和视线选择对手。正常 NPC 和敌怪的目标变更与伤害事件也会检查涉及测试身体的关系；双方都不是测试身体时继续使用原规则。原版队伍保护、玩家 PvP、创造模式无敌与命簿同宗保护保留。

## 保存和清理

普通测试修士保存自身修炼身份、天赋运行状态、资质、品质、灵力、属性、关系、已学功法、熟练度、运行心法、自动施放设置及技能冷却；不会创建命簿人物、居民岗位或化身租约。测试品质和容量存于普通 NPC 的测试配置字段，自然出生与命簿投影仍走原校验。普通技能冷却保存世界 tick 截止值，天赋能力沿用来源 UUID 的持久冷却。

默认召唤后暂停 AI，配置双方后可单独开始，或开始附近所有本人测试单位。暂停会取消修士动作和妖兽当前招式；清理使用实体移除，不记作命簿死亡。已有飞行弹体按正式生命周期消失。

未经过实际观察的玩家手感、音效、FPS 和多人体验保持 `not_verified`。开发者直接调用配置或战斗入口的检查只证明对应服务器行为。
