# 中州庄园购买

中州西坡中段的灰瓦庄园随当前修仙大陆的新世界生成，使用已选的分台地建筑。获准撤并的31栋民居固定在 `blueprints/player_estates/zhongzhou_placement.json`；其余建筑保留，原公共生活巷道通过外围三格退界带绕行。当前不提供向已生成的旧世界补建庄园的迁移。

玩家在庄园朝东的大门外与“庄园管家”交谈，选择“购买庄园”，再选择“确认购买”。价格、支付物品、管家与出口的地块锚点只由 `blueprints/player_estates/purchase.json` 管理；正式导出将实际巷道标高和私有范围共同写入城市清单，并纳入冻结摘要。

房价为100枚上品灵石。背包、灵石袋和已经接入灵石来源接口的饰品袋可以共同支付，其他品级不会自动折算。服务器在背包副本中计划全部扣款，复核物品来源后提交。余额不足、来源变化、已出售或重复点击时均不扣款。对话使用已有的一次性会话授权，同时复核距离、视线、NPC身份和房产状态。

每个世界只有这一座庄园，首次购买者取得整座房产。购买后仅房主可以进入；本次没有访客授权、转让和多人分别购买的规则。产权以玩家UUID记录于主世界的 `data/myvillage_estates.dat`，改名不影响归属，正常保存和重启保留房契及已支付物品状态。

私人范围为中州本地半开坐标 `[349,713,460,811]`，覆盖全部高度，包括屋顶上方和地下。外围公共巷道仍可通行。步行及坐骑的移动包、服务端物理移动、玩家传送和跨维度入口由服务器检查，登录、重生及逐tick检查补充处理已处于院内的玩家。创造和旁观模式沿用同一产权规则。外侧玩家对院内方块的左右键交互会被拒绝。

管家使用现有人形NPC及交谈界面，初始站在中州本地 `(461,148,760)`，位于私有范围之外。管家持久化、保持在岗并免疫普通伤害；其区块正常激活后服务器核对固定身份，缺失时恢复一名管家。不会为了管家长期强制加载庄园。运行 `/myvillage estate` 可以查询当前世界的实际管家坐标、价格和出售状态。

正式导出入口是 `tools/player_estates/runtime_export.py`，由 V11 聚合器调用。它消费与独立预览相同的 `TerraceEstate` 方块构造，重建坡地、替换既有稀疏切片，逐坐标回读并保留范围外原始方块实体。独立SCHEM含完整演示山体，正式生成使用稀疏施工切片。

必要检查包含离线楼层及完整路幅连通、保留建筑结构、生活岗位和入口、原始方块实体、切片回读、购房及范围单测，以及独立新世界中的原生服务端对话、扣款、禁入和重启探针。开发者探针没有映射客户端输入；玩家外观、操作手感、性能及真实双客户端验收仍需单独观察。
