# 资质点数与六类培养（0.122.0）

五行灵根、剑术／枪术／拳掌、炼丹／炼器／制符均以非负整数点数表示。五行总和没有固定值，100只作为部分培养材料的适用门槛。人物没有额外的“天资＋造诣”双层数值。

## 查看与实际作用

- 玩家在 H → 资质查看五行、兵器和技艺点数，输入 `/资质` 可读取自己的数值，`/资质 停止` 中止当前培养。
- 天下的人物详情显示 NPC 五行、兵器和技艺数值。命簿拥有这些数值，化身读取同一人物记录；普通非命簿修士按实体身份生成并保存一次。
- 元素与兵器资质参与对应伤害的配置曲线。技能伤害、原版防御及抗性仍经已有路径结算一次。
- 学习功法同时检查境界、前置功法和对应资质。兵器门槛从学校的 `weapon_family` 读取；原有五行条件改为点数，新元素功法使用统一品阶门槛。
- 技艺资质继续决定成品品质上限；丹方的 `minimum_aptitude` 同时用于学习资格。已冻结炉次与已有成品的品质按原有规则保留。
- 天命选择时检查初始灵根条件；确认后的天命继续生效，培养其他灵根不会取消已选效果。

## 培养方法

### 灵果和资质书

五行使用资质灵果，兵器和技艺使用资质通论；右键服用或研读。四档材料分别使用下品灵石、石英、钻石、下界之星作为培养资源。工作台配方将对应药材、兵器材料与已有灵果或书籍组合，成品提示对应资质、收益和适用点数范围。

原料与所有配方来自 `tools/aptitudes/content.json`，由 `tools/gen_aptitude_resources.py` 生成。果实沿用凝元果模型，书籍沿用原版模型。

### 灵地炼化

手持修炼指南，潜行右键点选灵地中心，支付灵石后在原地打坐。实际打坐时间足够且环境持续满足条件时，永久提高对应灵根。走远、死亡、退出或环境被破坏会中止本次炼化。

| 灵根 | 中心方块 | 中心附近的条件 |
|---|---|---|
| 火 | 岩浆块 | 岩浆 |
| 水 | 蓝冰 | 水 |
| 木 | 苔藓块 | 原木 |
| 金 | 粗铁块 | 铁矿石或深层铁矿石 |
| 土 | 滴水石块 | 钟乳石 |

条件支持玩家自行修整和搭建的灵地。同系炼化完成后有灵气恢复间隔。具体范围、消耗和时长以当前规则及运行时配置为准。

### 战意传承

使用剑术、枪术或拳掌战意残卷，在已加载且平坦的空地展开个人试炼。三类传承复用荒岭劫修、赤甲蜥和妖狼的现有战斗能力。使用对应兵器直接击败本次残影后，领取对应资质提升。

残影只接受本人的对应近战伤害，试炼不发放普通野怪战利品和经验。到期、死亡、离线或停止培养会结束本轮；残影根据所属课程清理。不会改写场地或创建独立维度。

### NPC 授业

手持修炼指南右键没有交战的修士，打开授业列表。列表显示老师及自己的各项资质；老师能够指导当前高于玩家的项目。选定项目并支付灵石后，在老师附近接受指导。老师离开、交战或玩家离线时，中止本次授业。

### 制作与修复研究

右键对应技艺的研究手记开启课题，再亲自完成一次满足品质要求的炼丹、炼器或制符。炼丹课题可复原尚未掌握且资质足够的实际丹方。

副手持受损模组兵器时使用炼器研究手记，可以绑定一项修复课题。将标记兵器拿到手中，潜行右键锻台，按原修复材料逐次修复；完全修复后完成研究；器物本身与原品质保留。

### 实践领悟

使用对应兵器或元素技能造成有效伤害、亲自完成炉次、组装兵器和绘符时，积累该项资质的实践进度。进度达到当前要求后提升一点，之后继续积累。NPC 日常修行和原有灵根奇遇也会增加相应点数。

## 配置与开发入口

`data/myvillage/aptitudes/rules.json` 维护类别、初始分布、伤害曲线、品阶门槛和培养参数；技艺成品品质档位继续由 `crafting/rules.json` 维护。生成器读取这些输入，数值不从界面推导。

管理员命令：

```text
/myvillage aptitude info <玩家>
/myvillage aptitude set <玩家> <metal|wood|water|fire|earth|sword|spear|fist|alchemy|forging|talisman> <点数>
/myvillage aptitude npc <命簿人物ID>
/myvillage aptitude npc <命簿人物ID> <资质名> <点数>
```

玩家培养使用正常物品、场地和人物交互；管理员命令用于读取与准备验证。当前开发版使用玩家格式6、命簿格式14、协议65；未观察的玩家外观、手感、平衡和多人体验保持 `not_verified`。
