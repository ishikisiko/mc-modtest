# 八州十六组群系

新建修仙大陆时，大、中、小地图都按世界种子在八州选择各州的两组特色群系。世界先确定城镇、宗门、官道、矿口和既有奇观，再从这些地基外评估海拔、起伏和可用地块。同州两组一起评分，优先选择能各自连成大片的落点。边缘随坡面和噪声渐变，原版森林、沙漠、海洋等继续从现有地区规则选出。

原版候选权重由 `blueprints/worldplan/provincial_biomes.json` 的 `vanilla_weight` 提供。当前值为 `0.58`。各位置的结果随地形条件和连续度变化，原版群系覆盖比例会随种子变化。三汊潮峡和沉碑台地按原有遭遇规则择址，第二片群系在遭遇范围外过渡。

| 州 | 群系与代表生物 |
|---|---|
| 东荒 | 赭溪兽道有赭爪獾，栎冠水洼有叶颈麂。 |
| 灵岳 | 悬根云谷有伞翼岩貂，层瀑石海有泉盏螺。 |
| 北原 | 风脊冻原有苔角雪羚，镜冰洼地有钻冰獭。 |
| 东海 | 三汊潮滩有泥甲潮蟹和回潮螭，礁冠海床有梳脊海马。 |
| 西漠 | 赤砾风槽有钩颚砂蝎和背碑石猿，盐镜荒盆有盐喙走禽。 |
| 南疆 | 板根雨林有青斑树蜥，浮毯苇沼有蒲伞沼蛙。 |
| 魔域 | 灰脊熔沟有余火甲虫，紫晶沉沟有裂晶耳蝠。 |
| 中州 | 曲水石洲有石汀鹭，云松台原有青翎锦鸡。 |

各组的代表生物使用本州野外境界规则和适合自己的出生条件。珊瑚静水、冰面开口、湿泥、树根和熔沟冷岸等地形条件由服务器读取实际区块。十四种新生物各有一种常见掉落和一种概率掉落，材料可自动拾入材料储物袋。三汊潮滩和赤砾风槽的战斗与掉落见[首领遭遇说明](biome-encounters.md)。

管理员可用 `/yuanxian worldplan provincial_biomes` 查看种子、权重及十六组的坐标，或用 `/locate biome` 搜索已注册的群系。`/yuanxian worldplan provincial_biomes sample <位置>` 显示已加载位置的群系、地表和代表生物的当前生成条件。

群系和生态以 `blueprints/worldplan/provincial_biomes.json` 为作者输入。`python3 -m tools.field_encounters.provincial` 生成原生群系、出生规则、物品、语言和战利品。已确认的三维原稿位于 `blueprints/beasts/field_encounters/`，由 `tools.beastgen` 写出像素贴图、材质、骨骼和动画。世界预设编译时冻结群系规则，三个预设共用生物与物品资源。
