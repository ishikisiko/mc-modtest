# 筑基丹与补基丹（0.75.0）

炼气九层修为、稳定度达到该阶段要求后，手持筑基丹长按右键服用，进入原有静止突破流程。普通 N 键／面板突破不能绕过筑基丹；其他阶段保持原有突破行为。

筑基丹只有下、中、上三品，名称与边框分别沿用绿、蓝、紫。成功率分别为 40%、75%、92%；成功分别记录 5%、12%、20% 筑基根基加成。成功进入筑基初期、修为归零、稳定度减半；失败留在炼气九层、保留修为、稳定度减半。丹药在服务器接受尝试时消耗，中断不返还，继续沿用原有移动、受伤和退出中断规则。结果在接受尝试时冻结，不因重复按键重抽。

根基提升境界基础生命、基础攻击与灵力上限，不增加修炼速度、灵根、寿命、抗性或移速。不直接回满生命或灵力；装备本身不再乘一次根基倍率。根基随档案保存、死亡保留，属性使用稳定标识替换而非累计。

补基丹只有中、上两品。已筑基者可以确定性补全到对应根基，后续境界同样可用，没有最高境界限制。只补差额，同档、降档或未筑基服用拒绝且不消耗；不增加修为或改变境界。旧档案缺少根基字段时保留原属性，仍可用补基丹补全。

## 丹炉配方

所有成丹配方都在青铜丹炉与青铜丹炉阵中炼制，不提供工作台合丹。先右键学习对应品级丹方，再在炉中翻页选择；悬停丹方查看全部材料、数量及资质门槛。炼丹资质是现有 0–100 技艺属性，非新增经验等级。

- 下品筑基丹：下品凝元果、聚灵叶、清心莲各一，8 下品灵石；资质至少 20。
- 中品筑基丹：下品凝元果、聚灵叶、清心莲各一，12 下品灵石；资质至少 50。
- 上品筑基丹：上品凝元果、聚灵叶、清心莲各一，16 下品灵石；资质至少 70。
- 中品补基丹：下品凝元果、聚灵叶、清心莲各四，32 下品灵石；资质至少 60。
- 上品补基丹：上品凝元果、聚灵叶、清心莲各四，48 下品灵石；资质至少 85。

每炉产出一枚，达到门槛后按所选丹方固定品质，不产生极品，不额外随机降品。旧三种丹药继续沿用原来的随机品质表。调参唯一来源为 `data/myvillage/alchemy/rules.json` 与 `foundation.json`；物品提示从这些数据读取。

## 凝元果与丹方获取

凝元果先提供实际配方需要的下品、上品两个品级；它是炼丹材料，不是食物，也没有新增果树或种植机制。

- 下品凝元果：苹果、聚灵叶、清心莲各一，加四枚下品灵石，无序灵气浸炼合成。
- 上品凝元果：下品凝元果、恶魂之泪、烈焰粉各一，加四枚中品灵石，无序合成。
- 筑基丹方用纸，补基丹方用书，均加对应品级凝元果、聚灵叶、清心莲各一。下品筑基丹方再加一枚下品灵石；中／上品筑基丹方与中品补基丹方加一枚中品灵石；上品补基丹方加一枚上品灵石。这样每张丹方都有独立的工作台材料组合。右键一次学会，同一张已学丹方不会再次消耗。

创造栏和品质选择器提供合法品级；凝元果品级由物品身份确定。上述配方资源归 `tools/gen_alchemy_assets.py` 生成。

## 兼容与验证入口

单炉保留旧 0–4 槽位，新增第 5 槽放第三味药；旧第 0 槽仍仅取回旧丹方。炉阵保留旧 0–6 槽位，新增第 7 槽作为第三味药，进药口增加第三通道。旧配方、旧批次和输出槽编号不变。新配方输入顺序由选方补料确定，旧双药配方保留交换次序支持。

档案 v4 增加有界可选 `foundation_quality`（缺省 0），所有不可变更新保留它；网络协议升级为 39。服丹、批次、扣料、品质和档案提交均由服务器决定。

检查入口：`tools/validate_alchemy.py`、`tools/gen_alchemy_assets.py --check`、相关 Java 单元测试、`tools/foundation_pills_evidence.py` 的远程映射输入验证。实机脚本使用独立临时世界，管理员命令仅准备条件和读回结果；加速 ticks 不代表自然修炼耗时或玩家手感验收。
