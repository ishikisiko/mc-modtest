# 筑基丹与补基丹（0.126.0）

炼气九层修为、稳定度达到该阶段要求后，手持筑基丹长按右键服用，进入静止突破流程。普通突破键和面板不能绕过服丹；天道筑基使用独立引劫流程。

筑基丹现可炼出下、中、上、极品。丹药品质到地道根基效果由 `alchemy/foundation.json` 的 `pill_foundation_quality` 定义，当前依次为 1、2、3、3。下、中、上对应成功率仍为 40%、75%、92%；极品采用地道上品效果和成功率。成功进入筑基初期、修为归零、稳定度减半；失败保留炼气九层与修为、稳定度减半。服务器接受尝试时消耗丹药并冻结突破结果，中断不返还。

根基添加固定生命、基础攻击、肉身防御与灵力容量，不直接回满生命或灵力。档案不可变替换继续由 CultivationService 完成，属性使用稳定标识替换。

补基丹同样允许四品，按同一映射补足已有地道根基，只补品质差额。已筑基者在后续境界也可服用；同效果、低效果、未筑基或已有天道根基时拒绝消耗。极品补基丹可以补到地道上品。

## 凝元果与学习

下品凝元果来自成熟普通果实；上品凝元果需要对花芽施用培元肥，再等本轮成熟。凝元果只作炼丹材料。树苗来自自然树叶掉落，果实和树苗没有工作台合成入口；见[凝元果树](ningyuan-tree.md)。

筑基丹方用纸，补基丹方用书，均加对应凝元果、聚灵叶与清心莲。不同版本原有工作台材料组合保持：最低成本筑基丹方另加下品灵石，其余分别使用原有中／上品灵石。右键永久学习，同一张已学丹方不会再次消耗。选择丹方后可从背包补料，悬停查看全部成本。

普通炉有三个药材槽、一个燃料槽、四个产物槽；炉阵保持专口及四格产物。开炉、每颗结果、完整扣料和档案均由服务器提交。普通炉采用当前库存格式 2，不迁移旧格式，更新前应先清空旧炉。

## 验证入口

定向检查为共用品质模型、AlchemyBatch／AlchemyRules、FoundationRules、原子多产物和相关炼器回归。专用服务器探针 `-PcraftingQualityEvidence` 覆盖实际工位事务及磁盘重启，禁止进入交付 JAR。它使用分支准备和加速 tick，映射玩家输入及自然随机频率另行观察。

旧 [0.75.0 验证](../testing/2026-10-22-foundation-pills.md)仅证明当时版本，不证明当前随机模型。属性加值见[修炼属性](additive-cultivation-stats.md)。
