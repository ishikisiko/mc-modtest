# 洲域和城镇入场报幕

0.131.1 按用户已选样式接入：洲域使用 A 款居中书法，城镇使用 C 款右侧竖排题签。标题沿用 `panel_title` 书法字体，纸色、墨色和朱砂小印与预览保持一致；不增加音效或黑边。

服务器使用现有 `RegionRuntimeService` 的主世界归属和正式 `WorldPlan` 位置查询。支持八座省城和湾口台地集。省城采用正式城市 X/Z 占地，湾口采用聚落原尺寸占地；查询不加载区块、不申请票据、不修改地形。当前阡镇位于个人秘境，主世界规则不生成阡镇，不从主世界坐标推断该地点。原版村庄没有本模组的正式地名和登记范围，本轮不自动命名。私有秘境、下界和末地不套用主世界地名。

首次登录会显示当前所在地。同一位置停留、城内传送和原地复活不会重新报幕。跨洲后进入城镇时先显示洲名，再显示城名；在同一洲内换城只显示城名。服务器按玩家 UUID 保存本次连接的提示状态，退出连接和关闭服务器时清理，不写入存档。

触发和动画数值只维护在 `data/myvillage/arrival/rules.json`。当前每 5 tick 查询，候选位置连续确认 15 tick；离开城域或洲域需持续 60 tick，同一地点重复提示冷却 600 tick。省名播放 80 tick，城名 72 tick，中间留 8 tick。冷却只影响报幕，不限制移动、战斗或探索。

`ArrivalPayload` 只向拥有玩家发送服务器确认的位置和播放标记；没有客户端报地名或要求重播的入口。协议为 76，地名和 ID 有长度限制，拒绝控制字符和格式码。

客户端只保留当前目的地的待播省名与城名。新目的地会取消失效提示，跨维度、死亡、旁观和断线清空画面。普通界面开启、F1 隐藏 HUD 或单人游戏暂停时，动画等待；关闭后继续。城镇题签播放期间暂时隐藏右侧任务追踪，播完恢复。游戏继续接收正常移动和战斗输入。

预览候选见 [作者文件](../../art/ui/region-entry/README.md)。[本轮检查记录](../testing/2026-11-14-region-entry.md)包含 15 项单元检查、7 项原生场景、实机截图和未观察的玩家体验。
