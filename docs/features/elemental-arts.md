# 五行法修基础（0.81.0）

金、木、水、火、土是五条各自完整的元素路线；混修可选，武器不决定元素归属。沿用修炼战斗模式、秘籍研读、H 功法/技能图标格、品阶色、六键分配与冷热遮罩。没有新增独立职业 UI，也没有替换旧六招专用图标。

## 基础招式与成长

| 元素 | 炼气一层常用技 | 炼气一层护体 | 炼气四层爆发 | 筑基初期范围技 |
|---|---|---|---|---|
| 金 | 金芒术 | 金罡障 | 破阵金轮 | 万刃界 |
| 木 | 灵种术 | 青木衣 | 枯荣引 | 青藤界 |
| 水 | 水刃术 | 流水障 | 沧浪冲 | 寒潮界 |
| 火 | 灵火术 | 回焰障 | 爆焰术 | 赤焰界 |
| 土 | 岩弹术 | 厚土障 | 镇岳印 | 流砂界 |

护体与爆发前置为本系常用技；范围技前置为本系爆发。全部通过绑定已有通用秘籍物品学习，有工作台生存配方。基础元素材料分别为铁锭、橡树树苗、雪球、木炭与黏土球；完整材料、研读点数、门槛与平衡参数只以 `tools/elemental_arts/arts.json` 为准，游戏指南从同源生成。没有最低元素亲和门槛；亲和只参与本系伤害收益。

常用技每次施放产生有效伤害最多积累一层本系势；护体/爆发在成功扣费后消耗本系势。各系积蓄独立、上限和失效时间受配置约束，空放不积蓄，多目标不重复积蓄。护体有全系共享冷却，且只保留一个效果。木系恢复必须消耗实际积蓄，不靠空放无限恢复。

金系贯穿/削甲；木系种植侵蚀并收割；水系迟滞、潮涌推移与护体加速；火系灼痕/引爆与近身推退；土系较强护体、范围震退与流砂。木火持续效果按施法者、目标及元素归属，有界、不叠层；收割只消耗自己的剩余伤害，合入本次命中减免一次。持续伤害不触发攻击天命递归。

范围技固定初始落点，需引导，玩家可以走出；施法者可身法取消后续段。基础法术与范围的目标/落点来自服务器视线与有限范围，不穿墙，不破坏或放置世界方块。水土控制为有限迟滞与遵守击退抗性的推移，不承诺对首领完全定身。

金丹继续使用共有境界成长；金丹专属大招、每系第二专精、五行相生相克反应表、新法器模型仍未实现。不要把基础四招当成全部长期规划已经交付。

## 技术边界

- `gen_elemental_arts.py` 拥有这二十门生成资源、伤害类型、配方、中文指南与命名键。学校定义经原 `technique_catalogue/schools.json`；原目录的保留列表声明资源归属。
- 执行器是 `CombatArtActions` 下属的 `ElementalActions`，由唯一 `CombatSessionManager` 调度并与近战/剑气互斥，没有第二套主动攻击 tick。绑定仍只有有界槽位意图，没有客户端目标/伤害。
- `ElementalEffects.base` 使用独立战技基础、一次境界倍率、根基与本元素亲和；不读取手持近战攻击力/附魔。最终仍经过 `CombatDamageService` / `StatsRuntime`，五系明确伤害类型分别选择原有抗性/穿透，原版减免一次。
- 施法前与逐 tick 验证学习、境界、存活、容器、模式、手持对象/槽位与维度；手持家族不限。切换手持会中断当前动作，之后任何物品均可再次施法。
- 积蓄、护体与持续伤害是服务器暂态，模式/死亡/离线/维度/停止清理。护体速度修饰不落盘、不叠加。冷却按玩家与战技保留，死亡、换槽、重连不刷新；服务器重启清空。
- 现有图标系统继续按主动功法大类提供共用图案、按品阶配色；没有二十张新原画。法术场景表现使用有限的金针、藤纹、水环、焰片、岩棱网格及原有音效，不是二十套新骨骼动画。

## 定向检查

本地运行生成器 `--check` 与 `tools.tests.test_elemental_arts`；Java 检查覆盖元素定义、积蓄/时间轴、绑定、原武技与战斗会话、属性伤害及客户端图标/快捷栏。用户本次指定复用 `sword-arts-highmem` Colab，重型工作不在本机运行。

实机脚本 `tools/elemental_arts_evidence.py` 用原生客户端映射输入施放；管理员命令仅准备和读取夹具。实际完成项目、失败重试及范围以交付记录为准。玩家外观/手感/音效/FPS 与未观察的多人情况保持 `not_verified`。
