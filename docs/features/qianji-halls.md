# 千机阁署区与固定州序

新修仙大陆按西漠、东海、南疆、北原、东荒、灵岳、魔域、中州推进。每对连续州共享边界并有直接官道；魔域分别通过正式关隘连接灵岳与中州。

前七州的千机阁在省城东侧生成，通过新增城南大道接入原公共道路。前四州采用三种紧凑变体，东荒、灵岳、魔域分别使用城中三院、水埠联楼、边关石院。紧凑版占地仍为60×67、62×70、64×66格，大版仍为104×116、108×120、108×118格。

中州总舵位于御街西侧、鼓楼西南的住宅坊，门阙朝东。城市平面的地块为159×170格，模型坐标为170×159格，撤并获准的73栋普通民居，保留药铺、客栈、鼓楼、庄园、水体及其功能点；城市继续使用原有1200×320×1440格城域。正式地块、撤并清单和各楼院位置由 `blueprints/qianji/zhongzhou_infill.json` 维护。

各栋楼体保持原有尺寸，按山坡分别设置台基，三格宽阶道和覆顶连廊接通原巷。门阙两侧办理公开委托与核验结算，通高总务大殿、万卷档库、玄枢机造院、器物库、秘境勘图楼、听雨来使院和五层天枢总阁沿坡布置。工坊新增靠山后门，听雨院通过池畔步廊接入，北缘陡坎设置有石支承和栏杆的高廊。自然地形的新增下挖最多三格；楼体、屋檐和三格路幅均核对地块边界。旧巷的既有切坡按正式地形列和路面核验，原有屋檐遮挡单独记录。新通路通过实际碰撞与净空检查，保留的原巷接点继续使用实际标高。

细分构件保留完整硬边主体、斗拱、窗格、青瓦和像素材质，实体碰撞由同一份几何生成。各层有楼梯、家具与独立吊灯，庭院树使用原版木材和树叶，听雨院水池设实体池底与池壁。

总舵常驻薄云、流光与少量光点。阵纹和山河异象按 `blueprints/qianji/atmosphere.json` 中的周期分时显现，玩家离开后重新进入仍按世界时间运行。每座总舵只设一个阵枢方块实体；客户端负责表现，远处渐隐，墙壁和屋顶参与遮挡。服务器保存相位偏移，并同步给正在观察的客户端。

任务榜迁入各署区办事厅，右键打开“千机阁委托”。原来的接取、进度、奖励与交付规则继续使用原城市身份。室内布置包含制图台、木桶和书架，各层用途为后续秘境及组织玩法预留了空间。

管理员可查询实际入口与任务操作位置：

```text
/myvillage worldplan qianji
/myvillage worldplan qianji zhongzhou
/myvillage qianji probe
/myvillage qianji phase 20
```

`probe` 读取已加载总舵的31个功能点，报告实际站立空间、方块光和阵枢绑定；它只读取这些点的状态。`phase` 设置周期内的秒数后继续正常播放，仅管理员可调用。

建筑方案、材质、层高、分档和署区布置的输入位于 `blueprints/qianji/`，生成器位于 `tools/qianji/`。`headquarters.py` 维护总舵作者几何，`infill.py` 平移各楼体、建立台基与阶廊，`components.py` 生成细分构件，`generate_assets.py` 导出模型、碰撞、语言与贴图，`generate_atmosphere.py` 导出阵纹、云纹和异象网格。正式 NBT 使用同一份构件模型。中州由 `infill_export.py` 在当前城域内施工，逐格回读切片，核对保留楼体、地块外原路及原始方块实体，迁移任务榜与阵枢。其余七州继续保留原城全部建筑和地形列。官道出口均从最终城市资源重新导出。

本次世界生成改动请使用新修仙世界。开发者的体素检查、原生读回与玩家外观接受度分别记录。
