# 千机阁署区与固定州序

新修仙大陆按西漠、东海、南疆、北原、东荒、灵岳、魔域、中州推进。每对连续州共享边界并有直接官道；魔域分别通过正式关隘连接灵岳与中州。

千机阁作为八座省城的东侧署区生成，通过新增城南大道接入原公共道路。前四州采用三种紧凑变体，东荒、灵岳、魔域分别使用城中三院、水埠联楼、边关石院，中州设置独立总舵。紧凑版占地仍为60×67、62×70、64×66格，大版仍为104×116、108×120、108×118格。

中州总舵占地240×256格。三阙门、总令大殿、天枢总阁、万卷档库、玄枢器物库和巡州使院分别承担公开委托、行动统筹、机要与内务。天枢总阁设三层，层高24、20、22格；总令大殿保留通高中庭与议事回廊。各层有完整楼板、楼梯和可达目标。屋顶大型天机仪、前院校准仪台、八州分阁铜铭碑、门阙和高处铜字匾额是实体构造。

任务榜迁入各署区办事厅，右键打开“千机阁委托”。原来的接取、进度、奖励与交付规则继续使用原城市身份。室内布置包含制图台、木桶和书架，各层用途为后续秘境及组织玩法预留了空间。

管理员可查询实际入口与任务操作位置：

```text
/myvillage worldplan qianji
/myvillage worldplan qianji zhongzhou
```

建筑方案、材质、层高、分档和署区布置的输入位于 `blueprints/qianji/`，生成器位于 `tools/qianji/`。预览与正式 NBT 使用同一个完整方块模型。署区加入城市冻结摘要，原城只撤下已归属的旧任务榜，保留其他建筑、地形列和原始方块实体。城市扩大后，官道出口从最终城市资源重新导出。
