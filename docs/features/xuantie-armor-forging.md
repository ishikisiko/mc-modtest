# 玄铁甲炼器（0.99.4）

护甲原功能记录见 [固定源证据](../testing/2026-10-27-armor-forging.md)，当前放坯／锤击见 [实体交互验证](../testing/2026-10-27-physical-forging.md)。中间态已按同源立体模型方向重做；资源与实机记录见 [立体炼器模型证据](../testing/2026-10-27-forging-models.md)。玩家外观与手感仍待实际验收。

玄铁盔、玄铁甲、玄铁腿甲、玄铁靴可通过锻器工坊制作。整套仍是原版铁甲的 15 点护甲；炼灵和锻炼增加耐久，不增加护甲值，也没有套装技能。

## 获取与制作

四本器谱改由药铺中原本出售丹药的商人出售，工作台配方已移除。白天商人在岗位时，与其交谈并选择交易，在买入页翻页找到对应器谱。每本 12 枚下品灵石，每家药铺每种初始 4 本，库存共享且售完不因重载补回。右键研读一次后永久学会；已有器谱和已学记录继续有效。

| 器谱 | 起坯耗材 |
|---|---|
| 玄铁盔 | 玄铁锭 ×5、皮革 ×1 |
| 玄铁甲 | 玄铁锭 ×8、皮革 ×2 |
| 玄铁腿甲 | 玄铁锭 ×7、皮革 ×2 |
| 玄铁靴 | 玄铁锭 ×4、皮革 ×1 |

旧存档商店在加载时只补入尚无记录的新商品；已有数量（包括零库存）、商人身份、账款和交易次数保持原值。价格与库存以 `world_sim/commerce_rules.json` 为准，不消耗药材或丹药补货。

潜行右键锻器台打开面板，点器谱列表下方翻页并选择护甲，起坯、入火后关闭面板。手持锻锤右键台上器坯完成锻打，再潜行右键通过面板完成淬火、回火、修整甲片、铆合衬垫。淬火需要同层紧邻的有水淬火槽；入火／回火用煤炭或木炭，修整用燧石。关面板后器物仍留在台上；空手右键取回，手持右键放回续作。护甲热处理固定为韧性。

## 炼灵、历练和维修

将成品放入普通炼器鼎，切换“炼灵”并使用坚韧专长；玄枢多方块炼器鼎同样支持。每件耗玄铁锭 ×1、下品灵石 ×2，兼容对应材料标签和灵石袋。需要觉醒，品质受炼器资质限制；已有品质不能重抽。

穿戴护甲主动攻击敌对生物，按实际伤害获得器物历练。背包携带、挨打和空挥不计入；单个目标的额度有限，治疗不重置。将成品右键放回锻器台，潜行右键入火并选择“耐用”，关闭面板后持锻锤右键锻炼；每锤消耗历练和铁粒，最多 40 锤。不提供精工攻击、采掘加速或导灵加成。

受损护甲可在锻器台或普通炼器鼎修补，保留名字、附魔、品质和已付费锻炼记录。已有 0.97.0 玄铁甲无需转换，可直接炼灵、穿戴历练和维修。材料、次数和倍率以打包的炼器配置为准。

客户端与服务器均应更新到 0.99.4（协议仍为 52）。自定义 UV 护甲仍不支持原版盔甲纹饰。
