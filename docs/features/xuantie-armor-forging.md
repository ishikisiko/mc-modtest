# 玄铁甲炼器（0.98.0）

玄铁盔、玄铁甲、玄铁腿甲、玄铁靴可通过锻器工坊制作。整套仍是原版铁甲的 15 点护甲；炼灵和锻炼增加耐久，不增加护甲值，也没有套装技能。

## 获取与制作

工作台用一本书和铁锭合成对应器谱。下图中 `I` 为铁锭，`B` 为书，空格不放物品；头盔为两行，其余为三行或两行。右键研读一次后永久学会。

| 器谱 | 从上到下的配方行 | 起坯耗材 |
|---|---|---|
| 玄铁盔 | `III` / `IBI` | 玄铁锭 ×5、皮革 ×1 |
| 玄铁甲 | `IBI` / `III` / `III` | 玄铁锭 ×8、皮革 ×2 |
| 玄铁腿甲 | `III` / `IBI` / `I I` | 玄铁锭 ×7、皮革 ×2 |
| 玄铁靴 | `I I` / `IBI` | 玄铁锭 ×4、皮革 ×1 |

在锻器台或普通炼器鼎点器谱列表下方翻页，选择护甲，依次起坯、入火、按住锻打、淬火、回火、修整甲片、铆合衬垫。淬火需要同层紧邻的有水淬火槽；入火／回火用煤炭或木炭，修整用燧石。关闭菜单可带走器坯，之后放回续作。护甲热处理固定为韧性。

## 炼灵、历练和维修

将成品放入普通炼器鼎，切换“炼灵”并使用坚韧专长；玄枢多方块炼器鼎同样支持。每件耗玄铁锭 ×1、下品灵石 ×2，兼容对应材料标签和灵石袋。需要觉醒，品质受炼器资质限制；已有品质不能重抽。

穿戴护甲主动攻击敌对生物，按实际伤害获得器物历练。背包携带、挨打和空挥不计入；单个目标的额度有限，治疗不重置。回锻器台入火并选择“耐用”锻炼，每锤消耗历练和铁粒，最多 40 锤。不提供精工攻击、采掘加速或导灵加成。

受损护甲可在锻器台或普通炼器鼎修补，保留名字、附魔、品质和已付费锻炼记录。已有 0.97.0 玄铁甲无需转换，可直接炼灵、穿戴历练和维修。材料、次数和倍率以打包的炼器配置为准。

客户端与服务器均需 0.98.0（协议 49）。自定义 UV 护甲仍不支持原版盔甲纹饰。
