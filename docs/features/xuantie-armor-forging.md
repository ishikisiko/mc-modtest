# 玄铁甲炼器（0.112.0）

护甲原功能记录见 [固定源证据](../testing/2026-10-27-armor-forging.md)，当前放坯／锤击见 [实体交互验证](../testing/2026-10-27-physical-forging.md)。中间态已按同源立体模型方向重做；资源与实机记录见 [立体炼器模型证据](../testing/2026-10-27-forging-models.md)。玩家外观与手感仍待实际验收。

玄铁盔、玄铁甲、玄铁腿甲、玄铁靴可通过锻器工坊制作。自动标准甲以原版铁甲防护为基准；手工成形和辅助火可改善基础防护与耐久，耐用再锻继续增加耐久，不新增套装技能。

四本玄铁甲器谱现在以卷轴显示，中央分别为轻盔、衣甲、腿甲和靴子；与剑、枪、工具器谱共用纸卷底板。现有器谱均为凡品边饰，不改变炼成装备的品质。

## 获取与制作

四本器谱改由药铺中原本出售丹药的商人出售，工作台配方已移除。白天商人在岗位时，与其交谈并选择交易，在买入页翻页找到对应器谱。每本 12 枚下品灵石，库存不限。可反复购买，仍按每次选择的份数付费，受余额、背包空间与单次交易安全上限约束。右键研读一次后永久学会；已有器谱和已学记录继续有效。

| 器谱 | 起坯耗材 |
|---|---|
| 玄铁盔 | 玄铁锭 ×5、皮革 ×1 |
| 玄铁甲 | 玄铁锭 ×8、皮革 ×2 |
| 玄铁腿甲 | 玄铁锭 ×7、皮革 ×2 |
| 玄铁靴 | 玄铁锭 ×4、皮革 ×1 |

旧存档中器谱曾经售罄也可继续购买，旧库存记录保留但不再参与器谱扣货；丹药等有限货物仍按原库存交易。价格与供货方式以 `world_sim/commerce_rules.json` 为准，器谱不消耗药材或丹药补货。

普通鼎选择器谱后起坯，窑中加热，持锤在锻台按点数成形并淬火，再回窑回火、锻台精磨，最后在组装台消耗皮革装配。也可由普通鼎预付完整材料后自动完成标准甲。护甲不装武器柄。完整操作见[游戏内炼器章](../../guidebook/getting_started/forging.md)。

## 炼灵、历练和维修

将成品放入完整玄枢多方块炼器鼎，使用坚韧专长，也可以加入辅助火首次精炼。每件耗玄铁锭 ×1、下品灵石 ×2，兼容对应材料标签和灵石袋。需要觉醒，品质受炼器资质限制；已有品质不能重抽。

当前穿戴护甲主要通过承受敌对生物的真实最终伤害积累器物历练；生物本人直接攻击或归属明确的敌对投射命中均可计入。主动近战打怪仍有少量收益，初值降为原来的四分之一，武器和工具收益保持原样。背包携带、空挥、零伤、环境、自伤、友伤、玩家互打及创造／旁观不计入。主动攻击的目标额度和承伤的攻击者额度分别持久保存，治疗不重置；每件正确穿戴的玄铁甲独立获得本次收益，计数与防重复策略见 [KB54 当前规则](../ai-kb/54_forging.md#护甲承伤历练)，本轮实现尚未验证。

将成品在窑中加热后右键放回锻器台，潜行右键选择“耐用”，关闭面板后持锻锤右键锻炼；每锤消耗历练和铁粒，最多 40 锤。不提供精工攻击、采掘加速或导灵加成。

受损护甲可在锻器台修补，保留名字、附魔、品质和已付费锻炼记录。已有 0.97.0 玄铁甲无需转换，可直接炼灵、穿戴历练和维修。材料、次数和倍率以打包的炼器配置为准。

客户端与服务器均应更新到 0.112.0（协议 58）。自定义 UV 护甲仍不支持原版盔甲纹饰。
