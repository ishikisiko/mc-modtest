# 玩家住宅模板选型

状态：`design_preview`。在[七城宅田区域规划](player-land-plan.md)之后，先提供可选择的独立建筑蓝图，地块中的摆放、通路和种植位置都可调整。

[住宅模板与三维预览](https://assets.ishiki333hhh.win/previews/player-house-doors-20261117/index.html)可切换全貌、院内、去顶、俯视及“放进宅田地块”。每套可下载SCHEM、NBT和同源占地图，当前选择只影响预览，不写入游戏。

三套新宅共10处门已换用[木格双开大门](player-house-doors.md)，净开口3×4格，预览可切换开合。游戏导入需要源仙0.135.1；[原设计页](player-house-door-study.md)保留开度滑条和尺寸说明。

## 已找回的旧庭院

用户确认旧蓝图为“月洞水院”，包含白墙灰瓦、月洞门、木桥、水池、门亭和连续回廊。当前作者源仍在 `tools/reference_courtyard/assemblies.json` 与 `assembly_scene.py`，原版结构为 `data/yuanxian/structure/reference_courtyard.nbt`。

本轮按当前源重新导出，包围盒保持48×28×40格，10,437个非空气方块与项目现有模板逐坐标、逐状态一致。预览保留旧展示世界的历史游戏照片供认图；新导出的原版水院使用当前namespace和构件，历史截图不作为本轮游戏验证。

## 可选模板

|模板|占地宽×深|用途|64×72地块中住宅范围外剩余面积|
|---|---|---|---:|
|小院住宅|36×38|起居卧房、厨房储物和一处院子|3240格|
|三面合院|50×48|正房、两侧厢房，安排卧房、书房和厨房|2208格|
|双院工坊宅|54×48|月洞墙分开居住院和作业院，保留加工房、储物房及作业空坪|2016格|
|月洞水院原版|48×40|恢复的旧庭院，保留临水门亭及回廊|2688格|

表中剩余面积尚未扣除通路。俯视图中的浅绿种植框只说明可留田的位置；蓝图不会预先生成农田或灵土。房间只安排基本床铺和工作家具，继续布置设备和调整房间的空间保留给玩家。三套新增住宅均复用既有完整构件，主屋和厢房的体量、院落关系与用途各有区别；原版水院保持原尺寸；三套新宅在既有构件之外增加一款可开合的双开门。

小院配置两处有石边的花池和坐凳，合院增加水井及对称花池；工坊居住院保留浅水池，作业院继续留出连续空坪。花池使用原版土壤与杜鹃，保留原版生长能力，不使用树叶拼成装饰树。

## 检查与交付边界

四套NBT与SCHEM逐坐标回读、地块尺寸及完整构件检查通过。新增三套的入口、房间和作业空坪通过离线动线检查，负例保留堵入口、拆台阶和隔墙切窗的失败要求。恢复原版水院的历史游戏检查见[原专项记录](reference-courtyard-minecraft.md)，本轮未重跑其实机通行。

同源三维使用当前方块模型和像素材质，床为简化显示；全貌、去顶与宅田摆放用于开发者检查，保留玩家外观接受。SCHEM导入、玩家映射输入、NPC、性能与多人均未作为本轮通过项。

住宅蓝图仍独立下载，尚未进入正式城镇或模组内选房菜单。0.135.1将双开门本体打入JAR，住宅导入与门体交互的检查见[双开门说明](player-house-doors.md)。本轮没有修改玩家存档。游戏中的模板选择、材料消耗、旋转放置和自动施工属于后续接入范围。生成、下载文件语义和离线画面导出命令见[工具说明](../../tools/player_homes/README.md)。
