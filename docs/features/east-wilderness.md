# 东荒生态群落与按月恢复

0.132.0 起，新修仙大陆的地区强度分为六档：东荒、灵岳、北原、东海与西漠、南疆与魔域、中州。东荒是出生州；并列地区共用阶位与野怪境界范围，下一档查询返回整组地区。地理上同档地区相邻，官道串联全部八城。魔域经南疆和中州两处关隘通行。千机阁前三档使用紧凑署区，随后两档使用大署区，中州保留总舵。宗门总舵地区按强度档位选择，并列地区不因名称排序得到不同档位；魔域保持原自然宗门排除规则。

## 东荒群落

0.132.1 起，东荒妖兽与劫修的出生境界均为炼气一层至九层，群落首领取此范围上限。

群落只规划在东荒核心地区，每种目标三处，共十二处。规划结合已冻结的地形与建设范围，避开出生点、城市、宗门、聚落、官道、矿场和支路。遇到候选耗尽的点位，世界继续使用其余已合规的点位。依赖狼巢的劫修营地会同时记录缺位，管理指令可以查看。小型地形与建筑仅在本区块第一次生成时施工。

- 妖狼巢地有首领、留守者和巡猎成员。巡猎成员夜间外出，白天回巢；发现威胁或受袭时，附近同群成员会受嚎叫招呼支援。
- 赤甲蜥盘踞低矮岩地，围绕岩地留守，沿用正面护甲与尾扫。
- 灯孢菌地有菌木和聚集成员，受到干扰后附近成员加入战斗，沿用原有孢区攻击。
- 劫修营地有木棚、篝火、望风位置和空置物资桶；部分成员留守，部分外出巡逻。受袭后有限同伴支援，低血量成员沿实际地面撤离和返回。

劫修营地优先安排在妖狼巢地附近，两类群体可以在视线和感知范围内自然选敌。玩家可以跟随外出者找到据点，也可以引导追兵进入另一群体的活动范围。所有成员继续使用已有战斗执行器、碰撞、伤害和装备规则。

## 月度恢复与玩家建设

恢复使用自然修炼历法的月份，默认每月一轮。当前历法默认一月为 2 个 Minecraft 日，20 TPS 时约 40 分钟，实际长度随历法配置变化。清理掉某处的成员后，本月内保持有限名单；离开、卸载、重登或重启均不补充已经击败的成员。进入下一月，附近无人且已脱战时恢复下一批成员。跨过多个月只恢复一轮，日历回拨不会额外刷出成员。生物名单、UUID、死亡回执、月份和玩家施工记录均保存在主世界 SavedData。

刷新只恢复生物，不重建或回滚营地。玩家放置的方块进入局部避让记录；新一轮成员在周边安全空地恢复，避开施工点，建筑和容器内物品不被覆盖。没有可用位置时保留待生成槽位，等待安全条件满足。和平难度暂停生成。

每名成员本轮只有一个身份，区块未加载或暂时找不到实体不算死亡。新月份淘汰的旧实体在再次加载时按旧轮身份清理，防止重复成员。首领取当前地区境界上限，其余成员按地区范围稳定抽取。临时掉落默认为1–3枚下品灵石；0.133.0起由[独立掉落配置](monster-drops.md)管理，可以热重载，后续再调整正式材料与奖励。

## 作者入口和检查

- 地区分组：`blueprints/worldplan/rules_v11.json`；地区阶位：`data/yuanxian/worldgen/region_profile/`；出生境界：`data/yuanxian/wilderness/rules.json`。
- 生态作者输入：`blueprints/wilderness/habitats.json`；`python3 -m tools.wilderness_habitats.generate` 导出规则和据点方块，`--check` 核对输出。
- 当前世界冻结的规则拥有地形、规划与刷新参数。仅新建修仙大陆使用本次布局，不追加旧世界迁移或回填。
- 管理员 `/yuanxian habitat` 只读查看月份、据点、有限名单、活动与已加载实体；不会加载区块或重置进度。
- 状态测试覆盖同月有限名单、月度恢复、月份回拨、跳月、施工保留、保存往返及旧身份拒绝；原生检查另外验证真实生成、攻击、卸载、重启与双玩家共享名单。

开发者检查、映射输入证据和玩家外观、手感、FPS 的验收分别记录。原生场景结果见 [0.132.0 验收与下载](../testing/2026-11-15-east-wilderness.md)；九层上限和当前蓝图展示见 [0.132.1 局部检查与下载](../testing/2026-11-15-east-qi9.md)。
