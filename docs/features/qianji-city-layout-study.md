## 本轮方向

保留千机阁各栋楼房的尺寸和层数，把公开办事厅放到城内公共街道旁，内部楼院按街坊地块组织，以街巷与短廊连接。中州现有总舵的位置保留。七座分阁共22栋楼房全部位于原城市本地范围内；这次平面研究不扩大原城域。

城市主街已有各州铺装；现状中许多街道以外的空地继续使用统一默认地表，缺少门前、院场及绿地的用途划分。新方案分别安排公共石坪、门前铺装、住宅巷道、庭院绿地和保留荒地。东荒用暖灰石，灵岳用青石台阶，北原保留城缘积雪，东海保留港岸水面，西漠保留绿洲及成片城边沙地，南疆保留河岸植被，魔域保留裂隙及岩坡。

[庭院绿地方块示意](https://assets.ishiki333hhh.win/previews/qianji-city-plan-20261116/courtyard.html)以17×15格东荒小院说明石路、草地、树池、墙边灌木和坐凳的关系。它使用程序纹理表达方块布置，属于待讨论的设计例子，未写入正式庭院作者输入；实际院子大小和材料随城市地块调整。

## 后续施工前需要完成

- 选定围院或街坊组织方向，再把楼房、门口、院路及完整铺装写入正式作者输入。
- 西漠北驿商街仍有一处绕行要细化；预览用虚线显示原路线，不把它记为已完成通路。
- 受新地块影响的公共院场需按原用途重新安排；私院归属随住宅迁排更新。
- 核对传送亭、城门、生活岗位、照明、道路完整路幅、实际标高及地形施工边界。
- 用正式导出方块重做预览，再进行独立新世界检查。

当前只检查楼房尺寸、层数、地块边界、不侵入城主府/地标/经营建筑，以及撤并身份。平面检查不能代替实际碰撞、地形、完整道路和玩家外观接受。
