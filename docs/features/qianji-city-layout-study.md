# 千机阁入城与街区地面草案

状态：`design_preview`。用户已否定第一版地面处理：它仍把房屋之间大小不一的剩余空地划为草地。第二稿改为连续铺地和有边界的树院；最新的[七城宅田区域规划](player-land-plan.md)在此基础上调整街区与城墙，逐城留出64×72格净用地。两稿均尚未接入正式城镇生成。现有屋顶缺口在0.135.0-fix1独立修复。

## 地面重排第二稿

[第二稿三维预览](https://assets.ishiki333hhh.win/previews/qianji-ground-r2-20261116/index.html)保留整城旋转、缩放和省城切换，可在同一视角切换“上一版地面”和“本次地面”，也可单独查看集中树院。

- 建成街坊的空地默认安排为连续铺地院场和巷道，按道路、建筑和既有公共院场分出用途，不再按离房屋的距离推断绿地。
- 新种植地只取明确地块：六城各设一处有石边、入口、通路与坐凳的树院；西漠保留绿洲，不在密集街坊里另设零碎草坪。
- 东荒北关的空场分为树院、候行前坪和通路。各城既有公共院场按原用途收边，保留原入口方向。
- 城墙外、灵岳沟谷、东海岸线、西漠绿洲、南疆河岸和魔域裂隙单独保留。三维直接切换地形表面，移除旧绿色底面与新地面叠画的问题。

作者输入为 `blueprints/province_capitals/blueprint_plan/studies/qianji_ground_r2.json`；`qianji_infill_r1.json` 保留楼房落位及上一版地面，供同视角比较。它们都是独立研究输入，未进入正式城镇目录。七城逐格检查地面覆盖、用途归属、树院边界、建筑及庭院避让；种植地落在指定地块以外的格数为0，未分配用途的格数为0。

```bash
python3 tools/province_capitals/blueprint_plan/ground_study.py \
  --out reports/qianji-ground-study \
  --cache reports/qianji-ground-cache
```

生成器复用现有整城构件和三维查看器；缓存只在源提交匹配且相关正式输入未修改时复用。桌面东荒、新旧地面对照、树院近景和窄屏魔域均已查看，控制台无错误；软件WebGL与截图读回警告保留。它们只证明开发者预览可显示，未证明新布局的游戏施工或玩家接受。本轮未构建JAR，也未启动Minecraft。

[当前生成清单](https://assets.ishiki333hhh.win/previews/qianji-ground-r2-20261116/manifest.json)记录固定源与逐页摘要；[本轮作者输入和预览脚本](https://assets.ishiki333hhh.win/previews/qianji-ground-r2-20261116/study-source.zip)可独立下载。最后一次固定源生成的七页HTML与已经查看的页面逐字节一致。

## 本轮方向

保留千机阁各栋楼房的尺寸和层数，把公开办事厅放到城内公共街道旁，内部楼院按街坊地块组织，以街巷与短廊连接。中州现有总舵的位置保留。七座分阁共22栋楼房全部位于原城市本地范围内；这次平面研究不扩大原城域。

城市主街已有各州铺装；现状中许多街道以外的空地继续使用统一默认地表，缺少门前、院场及绿地的用途划分。新方案分别安排公共石坪、门前铺装、住宅巷道、庭院绿地和保留荒地。东荒用暖灰石，灵岳用青石台阶，北原保留城缘积雪，东海保留港岸水面，西漠保留绿洲及成片城边沙地，南疆保留河岸植被，魔域保留裂隙及岩坡。

[庭院绿地方块示意](https://assets.ishiki333hhh.win/previews/qianji-city-plan-20261116/courtyard.html)以17×15格东荒小院说明石路、草地、树池、墙边灌木和坐凳的关系。它使用程序纹理表达方块布置，属于待讨论的设计例子，未写入正式庭院作者输入；实际院子大小和材料随城市地块调整。

## 后续施工前需要完成

- 选定围院或街坊组织方向，再把楼房、门口、院路及完整铺装写入正式作者输入。
- 西漠北驿商街仍有一处绕行要细化；预览用虚线显示原路线，不把它记为已完成通路。
- 受新地块影响的公共院场需按原用途重新安排；私院归属随住宅迁排更新。
- 核对传送亭、城门、生活岗位、照明、道路完整路幅、实际标高及地形施工边界。
- 用正式导出方块重做预览，再进行独立新世界检查。

当前只检查楼房尺寸、层数、地块边界、不侵入城主府/地标/经营建筑，以及撤并身份。平面检查不能代替实际碰撞、地形、完整道路和玩家外观接受。
