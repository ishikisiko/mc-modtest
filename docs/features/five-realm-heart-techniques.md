# 五境心法

玩家可从炼气修到化神后期。金丹后期进入元婴，以及元婴后期进入化神，沿用普通突破。两次突破与新小阶段的修为、稳固、耗石和持续时间写在各自的境界定义中。元婴和化神使用现有的肉身与灵力数表。化神后期仍可普通打坐固本，供继续研读秘籍时补回稳定度。

## 查看与学习

H → 功法 → 点击「已学功法」切到图鉴。境界筛选使用功法的最低学习境界，心法还可以按攻、防守或灵力与修炼筛选。悬停可查看固定加值、适用条件、传承和秘籍价格。外框与角标取功法品阶，同品阶在不同境界使用相同配色。绝技、身法和炼体也可在图鉴查看已登记条目。

《基础吐纳诀》从启蒙传承获得。其余 201 门心法的秘籍可在图鉴用下品灵石换取，保留现有合成、藏经阁和掉落来源。换取时检查境界、资质、传承前置及背包容量。右键秘籍进入原有研读流程，研读完成后学会。价格和逐门资料由 `tools/technique_catalogue/catalogue.json` 维护，经生成器写入同步功法定义。

## 装备与结算

- 攻心法在匹配的普攻、绝技或法术命中计算时加入伤害基数。同一绝技的各段沿用原有伤害分配，法术衍生的独立持续伤害沿用原基数。
- 防守心法加入现有肉身防御。满足指定受击条件时使用该次防御加值。原版护甲仍在原有步骤结算一次。
- 灵力与修炼栏沿用主修入口。扩容保留原有当前灵力，最高受新容量约束。自然回灵的固定加值在扣灵后的正常恢复间隔入账，普通和灵石打坐分别加入自己的固定修为点数。三门旧成长样例的修习和参悟也采用固定加值。跨传承更换主修沿用原有散功规则。

装备随角色档案保存；攻防栏更换须结束当前出招和修炼。生成目录、语言资源和修炼链的离线检查与实际客户端操作分别记录。
