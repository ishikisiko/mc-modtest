# 七城玩家宅田区域规划

状态：`design_preview`。本轮按用户“先规划区域，所有东西都可灵活调整”的要求安排位置、边界和公共入口，尚未写入正式城市生成。中州已有庄园，本轮范围为其余七城。

后续已准备[三套可选住宅及找回的月洞水院](player-house-templates.md)，可按本页地块查看摆放；模板和城镇规划均仍为独立选型。

[三维规划](https://assets.ishiki333hhh.win/previews/player-land-plan-20261116/index.html)默认聚焦玩家用地，可切换七城、整城和千机阁街区。地块坐标使用各城预览内的本地坐标，XZ范围为前闭后开；不表示世界坐标。

## 区域安排

每城净用地为64×72格，允许旋转为72×64格，面积均为4608格。最小千机阁院区为60×67格，本次净面积约大15%。净用地外另留3格公共退界带，用于接路和边界标记，不计入玩家面积。初始地面是完整空地，住宅位置、田地比例及后续选用的房屋蓝图均可调整。

五处外扩区域纳入闭合的新城墙。旧城门与公共路保留，宅田入口接往现有公共道路；新接路预留3格路幅。东海、西漠为了容纳西侧扩区，预览中的原城整体向东平移80格，原城内部相对位置保持一致。西漠、南疆、魔域的局部墙线同时外移，使千机阁屋檐完整处于城内。

本轮新增迁排共14栋住宅、1座药铺、1栋千机阁办事楼和1处公共前坪；私院随所属住宅移动。此前千机阁入城草案中的35栋住宅迁排及8栋普通住宅拟撤并仍沿用原记录，本轮没有增加拟撤并住宅。所有这些变动目前都只存在于独立预览。

建成街坊继续采用连续铺地，有边界的树院另行安排，河海、沟谷、绿洲与裂隙保留自然用途。宅田范围单独划为可建造、可耕作的空地；本轮没有预设房屋、农田、水渠或灵土，也没有增加购地、领地和访问权限规则。

## 作者输入与生成

本轮输入为 `blueprints/province_capitals/blueprint_plan/studies/player_land_r3.json`。它复用上一稿地面规则与千机阁入城平面，在 `player_land` 内记录净地块、城墙、坐标平移、迁排和公共退界规则。正式城市目录、运行时切片和中州输入均未修改。

```bash
python3 tools/province_capitals/blueprint_plan/ground_study.py \
  --input blueprints/province_capitals/blueprint_plan/studies/player_land_r3.json \
  --cache reports/player-land-plan/cache \
  --out reports/player-land-plan/site
```

输出目录必须尚不存在。工具逐城记录 `selected/completed/failed/unrun`；每城的 `*-ground.json` 包含地面用途、净用地、入口折线、城墙和检查结果。[生成清单](https://assets.ishiki333hhh.win/previews/player-land-plan-20261116/manifest.json)记录固定源及产物摘要；[本轮输入与脚本](https://assets.ishiki333hhh.win/previews/player-land-plan-20261116/study-source.zip)提供对应作者文件，复现时仍需同提交的项目依赖。

## 已检查与待施工项

七城均完成以下离线检查：净面积4608格；净地面上无建筑、装饰或旧路构件；用地与千机阁构件均处于城墙内；入口在平面上以完整路幅连到公共道路；地面用途全覆盖，种植地不超出指定树院。选定地块的天然高度范围为0～2格，净用地整平最大改动为0～1格。

新增迁排构件另行与其他房屋、千机阁及庭院做三维包围范围核对。东荒、灵岳、东海的桌面预览及魔域的窄屏整城预览已显示，控制台无错误；软件WebGL和截图读回性能警告保留。对原第二稿的东荒邻接回归中，规划数据、场景、渲染依赖和查看器内容均与原页面一致，仅省城导航列表因单城检查而不同。

公共接路标高、所有新旧院路衔接、城墙施工、传送亭、NPC生活岗位及实际游戏通行仍待正式接入时核验。未构建JAR、未启动Minecraft，也未将开发者预览记为玩家外观接受。
