# 观察技能

玩家达到炼气后自动获得「观察」，不需要学习功法。打开 H → 技能，选中槽位后分配观察；槽位原有按键可以在游戏的按键设置中调整。系统不自动分配槽位，也不新增默认快捷键。观察可在普通模式或修炼模式使用，不要求持有武器。

施放时，服务器选择准星所指、距离内且没有实体碰撞方块遮挡的生物。姓名、观察精度、距离和冷却规则从 `data/myvillage/cultivation/observation.json` 读取；界面读取相同配置。观察不消耗灵力，不造成伤害。

境界比较采用属性规则中按顺序排列的小境界。相差不超过配置允许的层级时显示具体修为；超过时显示目标所属大境界内的固定区间。例如炼气一层观察炼气四、五、六层，均得到“炼气四层至炼气六层”。炼气九层与筑基初期属于相邻层级。未赋予修为的原版生物显示“未感知到修为”；境界数据非法时显示无法判断。

服务器重新检查玩家资格、冷却、当前动作、距离和视线。客户端只提交已有的槽位与方向意图，不提交目标或境界。观察结果只包含姓名和允许公开的区间端点，不附带模糊区间内的真实层级。隐藏修为的功法尚未实现。

命簿 NPC 的常驻名字显示姓名、宗门及已有身份或活动信息，不再包含境界。NPC 主动交谈时自述修为和管理用命簿页面不在此次隐藏范围内。技能绑定沿用服务器角色保存及死亡复制，观察冷却属于随玩家生命周期清理的短时状态。

实现入口：`cultivation/observation/ObservationRules`、`ObservationRuntime`、`combat/runtime/SkillBindingService`；客户端入口为 `SkillBindingsPage`。规则、授权、名字参数和原生按键施放需分别验证；开发者采集不能代替玩家手感、视觉和多人验收。
