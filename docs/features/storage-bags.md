# 储物袋

玩家入口见[游戏内指南](../../guidebook/getting_started/storage_bags.md)。三种袋子各有五档，容量和炼制材料由 `data/yuanxian/storage_bags/tiers.json` 决定。五张 16×16 手绘原稿在 `art/storage-bags/`，同境界的三种袋共用图标，由 `python3 -m tools.gen_storage_bags` 导出。

## 材料标签

自动拾取和材料袋手动存入都读取 `#yuanxian:storage_bag_materials`。生成器引用妖兽材料、炼器材料、矿材标签以及野外、遗迹、炼丹、装备的实际原料目录。这些来源增加材料后，重新生成资源即可进入拾取范围，妖兽材料的分类标签自动覆盖新增境界和稀有度。灵石由灵石袋收纳，原版物品沿用普通拾取。

其他玩法新增材料时，可由该玩法的数据包追加 `data/yuanxian/tags/item/storage_bag_materials/extra.json`。数据包重载后，材料袋立即采用新的标签。已入袋的物品仍可取出。

```json
{"replace": false, "values": ["yuanxian:example_material"]}
```

这里用物品的实际注册 ID 替换示例。正式开发目录新增材料时，在原料所属目录或该玩法的材料标签声明一次即可。

## 存取和炼制

容量内物品跟随袋子的原版容器组件保存。打开袋子时锁定手中的那一只，背包和副手里的材料袋都能自动收纳。服务器只处理正常能拾取的掉落实体，已取消拾取、拾取延迟和物品归属继续生效。箱子卸料使用当前箱内已有的物品类型选材，堆叠仍按准确组件匹配。

普通鼎和玄枢鼎的「储物袋」窗口使用操作者的修为和实际鼎状态。按下开炉后先核对原袋、容量档位和全部材料，再一起提交消耗和成品，右槽取出。元婴和化神配方由玩家境界注册表控制。现有玩家境界上限为金丹，两个高档袋可以从创造栏取得。
