# 六座委托秘境的地图设计

当前状态为 `design_preview`。六张地图已完成作者输入与离线三维候选，等待地图外观方向确认。正式 NBT、远征实例、机关战斗、委托签发与结算、续玩和离场回收尚未接入游戏。千机阁正式版继续使用原三类城镇事务。

完整玩法深化见[六座委托秘境的玩法设计](quest-realms-gameplay.md)：五关含必需战斗，藏书天井为纯解谜。新设计说明敌群、机关、失败与奖励；当前地图JSON和网页阶段仍是原地图示意，尚未按新规则改造。

## 本轮改动依据

旧版每图只有五个关键点、一条主要路线和一条返程线。回水古祠与藏书天井的实际预览呈现出平台上疏散摆放建筑的问题。新布局分别以峡谷旧寨、三层水库、双竖井、错层书院、三炉工坊和折返峡谷组织空间，地形与建筑参与路线遮挡和高差。

## 六张地图

- **断崖旧寨**：山口驿棚进入溪谷，先在断桥下穿过下寨，再登上钟楼和高寨。首领岩庭在山脊背后，踪迹核对与钟声共同决定追猎阶段。后寨绞盘打开桥面回程。
- **回水古祠**：前庭、低池与上池祭殿处在不同标高。西闸降低前庭水位，东闸接通井壁回水，山腰水轮控制封存室。井底和检修洞形成地下路线。
- **赤石矿井**：矿口营地在上方，主井中桥、副井边廊、工人避难室与深层矿厅在不同高度交叉。木撑标记与排水卷扬为取核条件，主井升降台承担回程。
- **藏书天井**：前庭、东西藏楼、洗砚院、后库、高阁和地库按不同标高布局。书架、院墙、跨院廊与内楼梯提供不同的搜索尺度，三类记录共同决定真卷位置。
- **沉炉工坊**：料轨和铸模间在上层，两座旁炉分设冷热两侧。主炉采用有内腔的铜壳吊架构造，冷却渠和上层检修廊围绕炉体。先检查阀门与冷却支路，再取匣撤离。
- **风隙渡口**：折返河谷与山脊遮住远端，两名探路人分别位于高低不同的两岸营地。跨峡大桥、贴壁栈廊、瀑后石廊和回水洞提供不同的接应路线。

各图均有可选支路与多个回环；同一地图可承接宗门与城镇不同来源的委托，具体任务与奖励仍需在玩法实现阶段配置。

## 实例规则的设计范围

每次单人或组队远征使用独立实例，完成后先结算、返回，最后一人离开再回收。中途退出保留24小时。外层山体和边界固定；内部的破拆、搬运、放置与飞行范围按关卡声明。以上是待实现规则。

## 作者输入与检查

权威输入为 `blueprints/quest_realms/catalog.json` 与六张地图 JSON。构造及预览位于 `tools/quest_realms/`，使用项目现有像素材质和已固定版本的 Three.js。

生成时检查机关依赖和分阶段可达性、路线端点与高差、全部关键点的站立体积、固定玩家镜头是否落入实体几何。检查不覆盖连续路线的全部碰撞，也不证明 Minecraft 实机体验、外观接受或 FPS。

生成方法见[工具说明](../../tools/quest_realms/README.md)。检查及浏览器截图写入忽略的 `reports/`，不进入模组 JAR。
