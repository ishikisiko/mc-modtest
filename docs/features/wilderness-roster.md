# 野外敌人与战利品（0.84.2）

新增六种普通敌对野怪，按群系低权重生成；没有首领血条或阶段锁血。每种有一种稳定主材，可选择炼成战备丹药，或用于青锋剑、凌霄枪的一次性炼灵。原有锋锐、导灵、坚韧及已经炼灵的旧装备保留。

| 野怪 | 战斗角色 | 主材 | 丹药 | 炼器专长 |
|---|---|---|---|---|
| 荒岭劫修 | 共用剑招连击、短时正面守势 | 掠锋砂 | 破障丹：短时物理穿甲 | 破锋：有效连段末击蓄势，强化下一次基础近战的穿甲 |
| 灰符术士 | 符弹、固定落点符阵、有限后退 | 符纹灵灰 | 定神丹：短时元素抗性 | 护符：成功施放主动五行法术后短时元素防护 |
| 荆背獾 | 刨地预兆、锁向冲撞、收招空隙 | 荆骨 | 护脉丹：物理抗性与抗击退 | 荆棘：正面护罡收到有效伤害后强化下一次基础近战 |
| 赤甲蜥 | 正面护甲、侧后惩罚、尾扫 | 赤甲片 | 御炎丹：火属性抗性 | 赤甲：持续持握且一段时间未受伤后，减轻下一次直接受击 |
| 寒翎雉 | 地面游走、短跳、羽矢与啄击 | 寒翎 | 轻身丹：移速与坠落缓冲 | 寒锋：基础近战造成有效伤害后短暂迟滞，品质影响持续时间 |
| 灯孢妖 | 抬伞预警、固定短时孢区、根扫 | 灯孢囊 | 清瘴丹：清除中毒并短时抗瘴 | 归息：击杀同等或更高境界的敌对怪物后有限回灵 |

丹方用纸、主材、对应第一味草药和下品灵石合成，右键永久学会。三味投入与燃料在单炉／炉阵里结算；没有工作台合丹。药效服用、品质、共享间隔及不可叠加规则继续走原 `MedicineRuntime`，持续效果保存剩余在线 ticks，死亡清除收益但保留间隔。

炼器专长是互斥选择，不新增六个叠加槽。普通炼器鼎和多方块炼器鼎的专长列表都有分页；选择新专长后，材料经现有完整事务扣除，输出保留 `forge_mark` 的字符串身份与原品质。已有成品不自动洗炼。创造品质选择器也支持专长分页。

0.84.1 将四种非人形野怪的长宽高统一放大至原来的 1.5 倍，人形比例保持原样。`body_scale` 是统一来源：模型和阴影由生成器读取，运行时碰撞与眼高对新旧实体一致应用，近战命中盒及起手距离同比调整；血量、伤害、移速与投射／孢区射程不随体形增加。注册尺寸作为基础尺寸保持兼容。

0.84.2 清瘴丹以持续时间体现品质：下／中／上／极品分别为 30／37.5／45／60 秒，清毒能力一致。时间由基础时长和已有品质倍率计算，物品说明、服用与存档读取使用同一规则。

## 作者与权威边界

- `tools/wilderness_roster/catalogue.json` 拥有本批参数、获取与配方关系；`python3 -m tools.gen_wilderness_roster` 导出规则、战利品、生成配对、物品资源与中文指南。原炼丹／炼器规则中的旧条目保留原有作者归属。
- `beastgen/roster.py` 拥有四种非人形；`npcgen/wilderness.py` 拥有两种人形的几何和材质。劫修由 npcgen 输出并复用玩家剑招重定向；术士通过 beastgen 适配到同一客户端骨架格式与妖兽施法时序。没有新增 GeckoLib 依赖。
- `art/entities/<id>/` 保存可编辑模型、UV 真相、二值遮罩、内置 imagegen 材质候选的归一化结果与 provenance。材质候选只在遮罩内、按最近邻缩放进入受限明暗处理；面部／眼睛和关键边界由原生像素绘制保留。概念图不能代替实机证据。
- 人形劫修是独立普通实体，不是命簿化身，也不改变城镇居民敌友。其 AI 提交基础攻击意图，共用 `CombatSessionManager` 的时间轴、碰撞、伤害和装备损耗。
- 其余五种复用 `BeastEntity` 招式、锁向、硬直和冷却；`RosterBeastEntity` 加有界符弹／羽矢和孢区。投射轨迹逐段与方块、实体相交，区域查询有目标数、频率和寿命上限。所有伤害经 `StatsRuntime` 和原版减免一次。
- 自然生成同时声明 biome modifier、群系标签和 Java placement。出生境界取当地范围并持久化，不按玩家境界缩放，不因搬迁或重载重抽；原世界规划和原个体不迁移。
- 新专长暂态收益绑定当前主手堆叠、槽位与维度；换物品清除收益。逐人专长冷却保存剩余在线 ticks，不因换槽、死亡、离线或重连刷新。穿甲只进入物理伤害的原护甲计算；反击不产生递归命中。
- 网络版本 42，旧专长 ID 与旧药效字段继续兼容。只读管理员入口：`/myvillage expedition status <player>`。

## 检查与验收

轻量入口：`python3 -m tools.check_wilderness_roster`、六种资产生成器的 `--check`、`tools.tests.test_wilderness_roster` 与受影响资源验证器。重型编译与客户端工作使用本次用户指定的 high-mem Colab。

`tools/wilderness_roster_evidence.py` 分场景记录正常 AI、真实映射输入、管理员夹具和读取结果。实际完成范围、失败及复验以 [专项交付记录](../testing/2026-10-23-wilderness-roster.md) 为准。玩家外观、手感、声音、FPS、长期密度与平衡在实际人工验收前均为 `not_verified`。用户要求测试后保留 Colab；不套用默认自动关闭规则。0.84.1 的局部证据另见 [体形放大记录](../testing/2026-10-23-wilderness-size.md)。
