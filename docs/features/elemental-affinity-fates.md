# 五行亲和天命（0.122.1）

亲金、亲木、亲水、亲土已加入稀有天命池，每项消耗2点，与亲火采用同一品阶。完整目录共36项，其中23项已实现、7项池内占位、6项仅设计。

| 天命 | 实际效果 |
|---|---|
| 亲金 | 金伤提高15%；金系有效直接命中使目标护甲降低10%，持续4秒，同强度再次命中刷新期限。 |
| 亲木 | 木伤提高15%，受到的治疗提高20%，覆盖丹药、技能回复和吸血；具体治疗来源的回复上限继续生效。 |
| 亲水 | 水伤提高15%；水系有效直接命中使目标减速20%，持续3秒；同一玩家对同一目标每8秒可触发一次。 |
| 亲土 | 土伤提高15%；站在地面时，受到的击退减少50%。 |

测灵碑按现有六选三、预算及互斥规则抽取和确认。H → 先天查看已确认词条。确认后使用对应元素招式即可生效，四项均为被动天命。

## 伤害与叠加

四项增伤按服务器判定的伤害类别读取。元素法术在施法时冻结亲和加成，主命中、后续侵蚀和收割共用该基数。其他直接元素来源在原有入伤入口计入加成，保持一次原版防御结算。

金系削甲与招式削甲取仍有效的较强值，各强度分别计时。例如20%招式削甲到期后，若10%亲金削甲仍在期限内，就保留10%；较弱命中只刷新自身强度的期限。

亲水减速复用服务器控制服务，与原版迟缓取较强值；原版药水效果继续按原期限存在。冷却按施法者UUID与目标UUID保存到主世界，死亡、退出和重启不刷新冷却。命中特性只由造成正数伤害的合法直接命中触发，友方、禁止的玩家对战及衍生伤害不触发。

伤害加成、比例、时长和触发间隔由 `data/myvillage/myvillage/innate_fate/*_affinity.json` 定义；运行代码不按具体天命ID分派数值。网络协议为66。

本轮采用局部数值、编解码和叠加检查及编译打包，实机手感、长期平衡及多人观察保持 `not_verified`。
