# 宗门贡献与江湖声望（0.125.0）

本版接入任务奖励、贡献兑换、江湖任务与声望商铺。奖励范围、经书费用、琳琅阁商品和声望门槛均为当前测试配置，后续可独立调整。请使用新建的修仙大陆世界检查建筑和任务入口；当前开发版使用命簿格式17、网络协议72。

## 玩家入口

| 玩法 | 位置与操作 |
|---|---|
| 宗门事务 | 与本宗守山执事交谈，在宗门事务页接取和交付；沿用每年一项的现有资格规则。页面显示当前贡献与本次完整奖励。 |
| 藏经阁 | 右键本宗经架，查看免费经书或所需贡献，点击领取。身份、传承权限及每本限领一次的规则继续生效。 |
| 琳琅阁 | 沿本宗内部道路进入新增琳琅阁，右键柜台，以贡献兑换丹药、药材和器谱。部分商品要求内门身份。 |
| 江湖事务 | 八座主城的客栈公共区域及四处规划聚落设有江湖榜，右键接取。完成后返回原榜交付，无须入宗。 |
| 声望商铺 | 白天到已营业的药铺与店主交易。界面显示当前声望、各商品所需声望和锁定原因，满足条件后仍须支付灵石。 |

江湖榜提供城郊巡查、行粮和征药三类测试任务。巡查要求在该城所在地区击败妖兽或敌对怪物；供给任务只收普通面包或普通灵叶，保留物品组件检查。每人同时持有一项江湖任务，每座城镇每个自然历法日可接一项，跨日可继续完成已接任务。领取资格从接取日记账，重登、重启或回拨日期不重置。宗门事务和江湖事务可以同时进行。

贡献在宗门事务结算时增加，在琳琅阁和付费经书领取时扣除。江湖声望随江湖任务累积，用于购买权限检查，购物不会扣除声望。原有贡献余额及江湖声望随玩家命簿记录保留；退宗后本宗设施的身份检查继续生效。

## 当前测试内容

藏经阁支持按经书品阶设置费用，也支持逐本覆盖；《剑气诀》是免费的覆盖样例。琳琅阁当前提供回灵丹、养元丹、凝神丹、灵叶、中品回灵丹和玄铁甲衣器谱。六套蓝图各有真实柜台和可达操作位置。

| 宗门蓝图 | 琳琅阁形制 |
|---|---|
| 云阙·三崖问道 | 双层重檐殿阁 |
| 松崖·独峰别院 | 低矮单层木构 |
| 听泉·双岸群院 | 纵向双层四坡屋顶 |
| 听泉·谷中别院 | 单层庭园建筑 |
| 照月·连岛水殿 | 双层收分岛阁，三侧廊道 |
| 照月·湖心小筑 | 单层四坡屋顶，四面环廊 |

药铺的下、中、上、极品基础丹药分别使用配置中的四档声望门槛；筑基丹另外使用具体报价门槛，并保留有限库存。声望不足时，客户端禁用购买，服务器报价及提交阶段再次检查。玩家出售商品沿用现有收购规则。

## 结算与保存

`PlayerMember` 保存贡献、声望、已接宗务的冻结奖励、江湖任务及各城接取日期。领域变更只经 `WorldSim` 门面；`PlayerEconomy` 与 `PlayerAffairs` 复核归属、身份、进度和余额，运行时先在背包副本规划扣料与产出，再提交整笔替换。空间不足、库存提交失败或资格失效时不扣贡献、不清任务、不记借阅。奖励灵石优先入可用灵石袋，其余放入背包。

柜台和江湖榜的服务归属来自当前蓝图与已登记场所，手动在其他坐标放置同类方块不会建立宗门或城镇服务。菜单请求绑定玩家、设施、随机会话标记与一次性序号，并复核存活、维度、已加载状态、距离及视线；拆榜、离开或归属失效后停止结算。交易继续使用同一个命簿和原商铺库存。

局部单元检查覆盖奖励范围和冻结、贡献扣付、免费经书、资格拒绝、原榜交付、日限与日期回退、任务及余额保存、品质门槛和具体报价门槛。原生检查通过 `-PplayerEconomyEvidence` 单独加载，启用时禁止打包；正式 JAR 不包含探针。原生开发者调用与玩家映射操作分别记录，玩家界面、手感和真实双客户端操作需独立观察。
