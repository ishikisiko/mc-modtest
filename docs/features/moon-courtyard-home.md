# 月洞水院宅居改版

状态：`design_preview`，用户外观接受为`pending`。用户否定了此前三套住宅的总体设计，本轮先以已认可的原版水院制作一套宅居草案。

[三维与试放蓝图](https://assets.ishiki333hhh.win/previews/moon-courtyard-home-20261117/index.html)可查看临水全貌、桥头、敞亭、卧房、厨房与低回廊，也可去顶看房间。取消“显示宅居改动”即可在同一机位查看原版，新增标注和路线仅供审阅。

## 空间与用途

水池、长桥、敞亭、月洞墙、低回廊和高台主厅保持原来的位置、形状与高度。主厅面水的敞开部分和中间通路保留，卧房放在后部西侧，前隔断开一樘木格双开门，侧隔断结合原柱梁；后窗和床侧通路保留。

茶席放在主厅通道旁，侧房沿用原木案并补炉台、工作台和柜面储物。低回廊的储物柜靠后墙摆放，月洞门之间的穿行和终端花窗对景保留。卧房与主厅的灯挂在原梁承口下方，厨房灯放在柜面上，储物廊灯通过连接后墙木枋的灯托支承。

水院占地仍为48×40格，可放入64×72格宅田；院外剩余2688格尚未扣除通路。地块视图的种植、自建色块仅作示意，可继续调整，未生成实际农田或灵土。

## 实现与检查

作者输入为`blueprints/player_homes/moon_courtyard_home.json`，工具见[生成与检查说明](../../tools/moon_courtyard_home/README.md)。从原组合源生成基础，增补时禁止覆盖原版非空气格；所有原版整件保留。新门和家具均使用现有构件或原版方块，住宅仅独立导出，未加入选房菜单或正式城镇生成。

检查原版每格状态、整件归属、灯具支承、脚下支撑、人物净空、步行中段碰撞和工作站位。开门后卧床侧、主厅、敞亭、厨房与储物均可达；关门后卧房与主厅分隔。NBT与SCHEM逐坐标回读一致。

预览里的床使用带木框、床脚和枕部的近似模型，其占地、高度、朝向与配色对应床方块；屋顶、门窗、梁柱等读取实际资源。浏览器画面为`captured_for_review`，原生游戏操作、最终外观、声音、FPS与多人为`not_verified`。本轮没有构建新JAR或写入玩家世界，试放沿用源仙0.135.1。
