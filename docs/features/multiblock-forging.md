# 玄枢炼器鼎

0.83.0 新增独立多方块设备。旧 `forging_table`、实体锻台、淬火槽及武器 ID 保留。

## 搭建和操作

五类部件均在“玄枢炼器鼎”创造栏，可生存合成。先放阵枢，右键查看五层蓝图。蓝图顶部为阵枢所在正面，底层为阵基；悬停格子查看世界坐标。实际坐标、角色、数量唯一来源为 `data/myvillage/forging/array.json`，只有阵枢朝向影响旋转；标记留空的位置必须为空气。手持方块优先正常搭建/修补，空手或持其他物品右键阵枢打开界面。

界面放入已有成品，选择该器物支持的专长后引火炼灵。资质决定品质，材料沿用 `WorkshopRules.infusionCosts`；无随机重抽，也不新增器谱或历练要求。材料从当前玩家背包及已支持的灵石袋来源转入真实暂存库存，原始物品与冻结的结果分别保存，完成时一次清输入、消费暂存并填入输出。每次需手动开启。

正常器物的名字、附魔、损伤、淬火处理和锻炼经验均保留；已炼灵器物不再接受。仅炼灵，不替代起坯、锻打、淬火、装柄流程。

## 生命周期与共享边界

- 阵枢唯一拥有两个公开槽和隐藏材料暂存；部件不拥有或复制物品，不开放自动化端口。
- 服务器复查菜单身份、玩家存活/非旁观、维度、距离、结构及完整扣料事务；重复开炉不能再次扣取材料，正在炼制的输入不能取走或替换。
- 服务器每 tick 只在结构完整、全部需要区块加载、输入身份相符、输出空闲时推进。结构损坏和输出占用暂停原进度。退出菜单或操作者下线不清除已授权炉次；不补算区块卸载或世界停止的时间。
- 开炉者（或管理员）可撤炉：原件留槽，精确材料退回其背包，满背包由原版回退掉落；其他玩家不能撤销该炉次。完成产物属于共享炉内库存，可由近处玩家取走。
- 拆掉阵枢仅掉落现存输入、输出和实际暂存材料，不掉落尚未完成的冻结成品。错误存档暂停并允许撤炉回收，不自动重抽。

## 资源与接口

`tools/forging_array/formed_model.py`、`visual.json` 经 `tools/gen_forging_array_assets.py` 生成模型、贴图、部件配方/掉落及名称。`formed_mesh.json` 同时供客户端和离线预览；粗碰撞盒也来自此网格，不另手抄轮廓。冷态暗炉，运行态亮炉与法环，炉心绘制实际 ItemStack。中文界面与方块客户端只提交有界意图。

`EquipmentInfusion.prepare` 与旧工坊共享成品处理。`ForgingCosts.reserve` 在原统一分配器上返回背包替换和实际消耗身份，不按标签造退款。管理员只读检查：`/myvillage forgingarray inspect <x> <y> <z>`。
