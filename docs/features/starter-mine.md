# 开局矿场与各州天然矿口

修仙大陆的新世界从可作为出生地的开放地区中，按境界和稳定地区 ID 选择初始城。东海由 `blueprints/worldplan/rules_v11.json` 的出生排除名单移出候选，仍保留完整城市和官道。

城郊矿场沿初始城已经规划好的出城官道选址，配套一条短支路。矿场必须位于陆地、留在出生州内，并避开城镇、宗门和已有道路；候选耗尽时报告具体失败，不生成孤立矿口或在水面上放置假平台。0.124.1 将固定尝试预算分配到整个允许距离内，保留各锚点完整的方向与长度组合；接路以既有官道列及矿场入口为硬标高，在原土方上限内联合拟合半格台阶，所有原有道路与护栏继续只读。

## 玩家可以做什么

玩家空手即可采伐矿场附近的原版橡树，制作工具后采掘矿口石料、浅层煤铁与更深处的铜矿。作业棚内的工作台和熔炉可以正常使用。矿场没有额外 NPC、接取条件或自动发装备的箱子。

入口通过短坡道接入按世界种子生成的洞窟。地下不再携带固定洞室或左右支洞模板。运行时直接复用 Minecraft `CaveWorldCarver` 的 `createRoom`、`createTunnel` 和递归分叉，强制生成有最小体积要求的核心洞体；分支参数随种子变化，生成出的形状会与原有干燥洞穴连通。

短入洞通道采用连续半格坡道，并保证有支撑的落脚面和头部净空。通道岩壁中的开局煤铁铜由种子分布，仍是可正常采掘的原版矿石；其余岩层继续参与普通矿脉和洞穴装饰。只有接触新增空腔的流体边界会被岩石封隔，不为整个洞窟铺设固定岩壳。更深的分支保留洞穴地形，不保证全部平坦或无风险。

人工下行通道的两侧沿岩壁成对布置原版火把，间距和高度来自 `underground.lighting`。火把朝向通道内部，随矿口旋转，保留中间通行空间和原有矿石。照明止于人工衬砌段，之后进入天然或按种子雕刻的洞体；玩家继续深入时仍需自备火把。

## 作者与运行时归属

- `blueprints/starter_mine/layout.json` 拥有地面尺寸、地形、树木、设施、选址预算，以及地下生成算法的有界参数。
- `tools/starter_mine/generate.py` 经 `starter_mine` 家族导出资源；棚架屋顶使用注册形制，材料使用原版方块。树叶连接距离由真实原木计算，保持正常消退、掉落与再种植。
- `generateStarterMineAssets` 生成独立资源。当前世界规则仅保存资源引用与摘要；V11 聚合器同步更新默认预设，不能手改冻结 JSON 或导出方块文件。
- `StarterMinePlanner` 只查询已经完成的道路布局，不改变官道。`StarterMineLayout` 保存位置、旋转和完整接路列，并绑定世界、道路和蓝图摘要；再次加载使用同一位置。
- `StarterMinePlacement.surface` 在地表阶段完成地面与支路基础，避免装饰阶段填回已经雕刻的洞体。`StarterMineCaveCarver` 在原版洞穴雕刻之后处理当前区块；装饰结束仅重申短通道、落脚面和地面设施。
- 洞穴种子保存到 `StarterMineLayout`，并与世界种子、位置及配置摘要核对。同一种子按任意区块顺序生成时结果一致；已生成的完整区块拒绝再次雕刻，重进不会恢复已采掉的矿石或树木。
- 城市、宗门、已有官道及其他保留区域仍由矿场选址约束避开。洞体范围避让结构，短通道和落脚面保护精确的三维写入体积；普通矿脉不因处在洞窟附近而全部被屏蔽。

管理员可以用 `/myvillage worldplan mine` 读取选址、入口、树木、地面接路列、洞穴种子、形状参数及实际入洞通道坐标。该命令不会生成或修改区块。

## 定向检查

本地检查使用 `python3 -m unittest tools.tests.test_starter_spawn_policy tools.tests.test_starter_mine`，从正式导出回读地面材料、树叶支撑，并拒绝携带固定地下洞室。Java 检查覆盖出生候选、选址与接路，以及多种子洞体体积、实际雕刻、区块顺序一致性、空洞和含水层夹具、连续通行面、开局矿物、存档身份和完整区块拒绝回填。

编译、原生新世界生成与采掘验证放在 Colab；实际执行结果以本次交付记录为准。离线布局检查不能代替真实通行、玩家外观、长期平衡、音效、FPS 和多人验收。

## 各州的普通矿口

每州的普通矿口数量、相互间距、候选预算和天然洞体筛选阈值由同一作者输入的 `regional_entries` 配置。包括东海在内的各州独立搜索，复用地面矿棚、矿口支护、树木、工作台和熔炉，不增加额外矿石，不调用开局洞穴雕刻器。

选址读取世界生成器实际使用的噪声地形列，并应用相同的地表整形规则。找到有支撑、两格净空的干燥落脚点后，只把能步行互通的天然落脚点计入洞体规模；小空洞、积水、熔岩、断开的空腔都不能通过。入口只修到已确认的天然洞体，之后保留自然地形。高地的天然洞层较深时，地下坡道可以延长，地面设施和整形范围保持原尺寸；延长部分逐列检查覆盖层、世界高度、州域、道路及建筑避让。地下人工连接段的中段采用连续岩石侧壁和顶板，衬砌也进入装饰保护范围，阻止后续洞穴雕刻和流体更新从侧面或顶部灌入通道；与天然洞体的交接处保留开放出口，天然洞体本身不铺岩壳。地面设施和通道避开城镇、宗门、官道及其他矿口。普通矿口无需接城郊官道，玩家在野外探索时发现。

普通矿口复用开局矿场的双侧火把规则，照明沿实际人工坡道延伸，天然洞体内不自动放置火把。

已经选择的天然洞体坐标与勘探证据随生成器存档，读取时核对世界、道路与资源身份。搜索耗尽会记录该州的实际数量及拒绝原因，不用人工洞室冒充天然洞窟。`/myvillage worldplan mine` 的 `regional_entries` 返回真实选址及入洞路线；其中坐标表示规划位置，不表示该区块已被玩家探索或生成。
