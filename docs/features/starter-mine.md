# 初始城附近的矿场

修仙大陆的新世界从可作为出生地的开放地区中，按境界和稳定地区 ID 选择初始城。东海由 `blueprints/worldplan/rules_v11.json` 的出生排除名单移出候选，仍保留完整城市和官道。

城郊矿场沿初始城已经规划好的出城官道选址，配套一条短支路。矿场必须位于陆地、留在出生州内，并避开城镇、宗门和已有道路；候选耗尽时报告具体失败，不生成孤立矿口或在水面上放置假平台。

## 玩家可以做什么

玩家空手即可采伐矿场附近的原版橡树，制作工具后采掘矿口石料、浅层煤铁与更深处的铜矿。作业棚内的工作台和熔炉可以正常使用。矿场没有额外 NPC、接取条件或自动发装备的箱子。

入口通过石阶下降，主矿道连接左右支洞和三个不规则洞室。矿道、洞室地板、岩壳、支护和矿石均为实际方块；主要路线可以返回地面。洞窟由矿场资源保证生成，不依赖所在种子恰好出现原版洞穴。岩壳外仍保留世界原有地下内容，玩家可以继续自由开采。

## 作者与运行时归属

- `blueprints/starter_mine/layout.json` 拥有尺寸、地形、路线、洞室、树木、矿物、设施及选址预算。
- `tools/starter_mine/generate.py` 经 `starter_mine` 家族导出资源；棚架屋顶使用注册形制，材料使用原版方块。树叶连接距离由真实原木计算，保持正常消退、掉落与再种植。
- `generateStarterMineAssets` 生成独立资源。当前世界规则仅保存资源引用与摘要；V11 聚合器同步更新默认预设，不能手改冻结 JSON 或导出方块文件。
- `StarterMinePlanner` 只查询已经完成的道路布局，不改变官道。`StarterMineLayout` 保存位置、旋转和完整接路列，并绑定世界、道路和蓝图摘要；再次加载使用同一位置。
- `StarterMinePlacement` 仅在当前区块生成阶段放置。装饰和结构避让矿场，矿场支路保留原官道列；不回填已生成区块，不恢复玩家采掉的矿石或树木。

管理员可以用 `/myvillage worldplan mine` 读取选址、入口、地下目标、树木和接路列。该命令不会生成或修改区块。

## 定向检查

本地检查使用 `python3 -m unittest tools.tests.test_starter_spawn_policy tools.tests.test_starter_mine`，从正式导出回读材料、树叶支撑和主要目标的往返路线。Java 检查覆盖出生候选、不同方向的矿场选址、完整接路、保护区、存档身份及失败拒绝。

编译、原生新世界生成与采掘验证放在 Colab；实际执行结果以本次交付记录为准。离线布局检查不能代替真实通行、玩家外观、长期平衡、音效、FPS 和多人验收。
