# 长生道胎

`myvillage:everlasting_embryo` 是红色六点天命，与其他灵体互斥。确认后寿元上限增加 50%，已耗寿元不退还。默认凡人、炼气、筑基、金丹分别为 120、180、360、750 年。

年度数表、延寿比例和半点结算单位只由 `data/myvillage/fates/everlasting.json` 维护：

| 当前大境界 | 每年生命上限 | 每年肉身防御 | 每年自身攻击 |
|---|---:|---:|---:|
| 凡人 | 0 | 0 | 0 |
| 炼气 | 4 | 0.5 | 0.5 |
| 筑基 | 6 | 1 | 0.5 |
| 金丹 | 8 | 1.5 | 1 |

默认一年仍为十二个月、每月两天，正常 20 TPS 下对应八小时有效在线时间。生命、防御、攻击分别攒满 0.5 点就入账，不必等整岁；实际加值均为整数或半点。未完成进度按整数分子保存，不依赖浮点反复相加。

只有存活且处于生存或冒险模式的自然寿元 tick 可以积累。采矿、建造、探索、打坐、挂机均使用同一规则；睡觉、修改世界时间、离线和停机不补算。凡人不积累可追补进度。寿元耗尽后停止新增成长，已有加值保留。

大境界只改变之后的成长速度；小境界及筑基、金丹品质不再抬高这份成长。换境界保留已得属性和未满半点的进度，不按新档位重算过去岁月。改日历速度时保留已经积累的半点比例，后续按新年长计时。未来额外燃烧寿元不经过自然 tick 入口，不能购买长生成长。

三项贡献独立累加，不按整个面板乘算，也不因装备、功法或其他天命的百分比修饰而再次放大。刷新幂等，增加生命上限不治疗当前生命。H「先天」页列出已入账加值和当前年度档位。

`EverlastingState` 独立附件保存累计半点份数、未完成分子及对应年长，唯一写入口为 `CultivationService.replaceEverlasting`。附件依赖 `copyOnDeath`，不额外手工复制 Clone。普通死亡、重登和正常重启保留累计结果；没有离线墙钟或客户端计数入口。协议 64 的修炼快照只向本人传输这份状态，客户端只读。

当前寿元耗尽只阻止修炼和突破，尚无寿尽死亡；本功能沿用该规则，不额外引入轮回或复活机制。

本轮必要检查及包内身份见[0.121.0 定向检查](../testing/2026-11-08-everlasting-embryo.md)。
