# 凝元果树（0.76.0）

凝元果树是一种可种植、砍伐和加工的完整木种。灰褐树皮、浅色木材、青绿树冠，挂果沿用现有下品青果和上品紫果；人工装饰采用青玉与暗铜。

## 获取与培育

- 新生成的森林、繁花森林、桦木森林、古老桦木森林和草甸有机会出现凝元果树，野生树带有混合生长阶段的下品果。自己种出的树从花芽开始。已有区块不补树，不改写旧存档。
- 自然树叶腐烂或普通破坏可掉树苗，剪刀／精准采集获得树叶。树苗也可由下品凝元果、橡树树苗和下品灵石合成，保留旧果实合成路径。
- 树苗可种普通土壤或灵土；灵土提高自然长成机会。骨粉可催长。长成前检查整个树冠和枝干占位，空间不足保留树苗，不覆盖建筑，不主动加载邻区块。
- 枝下挂果依次为花芽、生长、成熟。右键成熟果实收获，枝条回到普通花芽。自然树叶下的空位可重新长出挂果枝；手放树叶不会自动扩产，可另行制作挂果枝。
- 挂果枝必须依附于连接原木、未浸水的凝元树叶；不论剪取还是拆枝，都不能带走本轮施肥状态。拆成熟果只掉对应果实，拆未成熟枝没有收成。
- 培元肥使用两枚中品灵石、恶魂之泪、烈焰粉和骨粉合成。仅能对未施肥的花芽使用，一份只供一轮上品果；生长中、成熟或已施肥时拒绝且不消耗。骨粉只推进生长阶段，不改变品级。
- 生长阶段及是否施肥保存在方块状态中，正常重启不丢失；未加载区域不会补算生长。聚灵阵仍只负责原有修炼用途。

所有生长、产量、材料和自然生成参数以 `data/myvillage/orchard/rules.json` 为唯一来源；本页说明初始版本规则，不作为第二份配置。

## 方块与装饰

完整家族包括原木、木头、去皮原木、去皮木头、木板、楼梯、台阶、栅栏、栅栏门、花格门、花格活板门、按钮、压力板、树苗、盆栽、树叶、挂果枝、两种告示牌、船和运输船。告示牌保留编辑／染色／发光／封蜡，船沿用原版划行、乘坐和存储。

特色装饰包括可连接的凝元木嵌玉花格、可上下放置及叠成双层的青玉树池边石、可落地或悬挂的凝元果灯。树池边石由玩家自由围出尺寸，不要求固定阵型。

创造栏入口为「凝元灵木」。普通木材配方接入原版木材标签，原木可烧木炭，木材可作为燃料；树叶、树苗可堆肥。

## 资源与验证

- Java：`orchard/` 注册、树形、整树放置检查、果实周期；客户端仅为原版告示牌注册木种材质。
- 生成入口：`python3 tools/gen_ningyuan_tree.py`，`--check` 检查资源，`--preview` 渲染实际模型。生成器拥有本家族模型、贴图、配方、掉落、标签、世界生成资源及几何数据；不手改输出。
- `tools/ningyuan_tree/vanilla_templates.json`、`flower_pot_template.json` 保存 Minecraft 1.21.1 的基础模型／状态模板，仅复用原版几何；凝元材质由生成器单独绘制。
- 船使用 NeoForge 的官方枚举扩展，延迟供应木板与物品；告示牌通过 `BlockEntityTypeAddBlocksEvent` 扩展原版有效方块集合。
- 精细果灯碰撞和挂果选取边界从模型元素导出；自然树形用方块组合，不是不可拆的整体模型。

局部检查覆盖果实周期、树形连通／距离／边界、资源闭合、配方和原灵植回归。云端交互结果及未观察范围在本次交付记录中单独报告，离线预览不等于玩家手感、长期平衡、音效、FPS 或多人验收。
