# 七城住宅与玩家宅田

创建使用修仙大陆预设的新世界后，东荒、北原、灵岳、东海、西漠、南疆和魔域的州城会生成宅田、分布在街坊里的 NPC 院宅，以及城内千机阁围院。各城铺装、树庭、码头和店面按街区用途布置。中州的玩家入口为庄园管家。

## 领取宅地和选房

在各城与宅地执事交谈可查看宅地和费用。`/yuanxian housing` 显示各城执事的坐标及宅地状态。每城设一块 64×72 格宅田，进场退界带留作公共街面。领地后可直接搭建或种植，也可从执事菜单中选一套住宅，旋转并移动到宅田内的合适位置。

可选住宅包括双院水廊宅、叠台书楼宅、曲院作坊宅、杉廊双院宅、赤陶桥院楼和岩台水庭居。服务器会核对房契、模板、位置、已有方块与玩家土地改动后开始施工。施工按完整构件分批写入并保存进度。建成后可在宅地内自由改建。

开发阶段领取和建房默认免费。服主可在存档的 `serverconfig/yuanxian-housing-server.toml` 设置灵石物品、领取价、施工费和每 tick 的建造预算。报价与扣费使用服务端配置，可读取背包及灵石袋。

## NPC 院宅

七城共排入 29 座院宅。模板包含竹庭廊宅、坡台石木宅、临溪工坊宅、松廊小院、赤陶长屋和石阶露台居。街坊生成器根据本地风格施工台基、墙材、窗格和入口附属构件。

住处由真实床位和床边站立点生成。每座院宅优先分配一名符合条件的本州居民，其余床位可由生活系统分配。居民使用服务端寻路及整门开合，路经木格双开门时先开门，退出后按整件构造关门。

## 生成入口

`generateHousingAssets` 读取 `blueprints/housing/` 和两批房屋的作者几何，导出住宅目录、模型与完整门构造相关数据。V11 构建通过 `tools/province_capitals/inner_neighborhoods/runtime.py` 输出正式城镇地形、NBT、官道路口、传送亭坐标、千机阁定位、执事位置与床位。构建环境的 Python 需要 NumPy、SciPy 和 Pillow。
