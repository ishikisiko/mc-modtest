# 玩家选房与 NPC 住宅的接入安排

本页记录2026年11月17日确认的用途，以及核对当前实现后提出的接入方案。本次只确认用途和实施边界，未接入游戏或修改城市资源。

七城院宅、宅田和街区地面已形成方块布局。最新一稿把每城千机阁的全部楼房放回同一座围院，正门与公共街道相接。[七城围院与结构切片](qianji-walled-wards.md)

## 已确认的两批房屋

| 用途 | 六套设计 | 作者输入 |
|---|---|---|
| 玩家可选住宅，建在城镇留白宅田内 | 双院水廊宅、叠台书楼宅、曲院作坊宅、杉廊双院宅、赤陶桥院楼、岩台水庭居 | `tools/complex_houses/` |
| NPC 住宅多样性扩展 | 竹庭廊宅、坡台石木宅、临溪工坊宅、松廊小院、赤陶长屋、石阶露台居 | `tools/house_choices/` |

用户已确认这两批设计的用途。真实方块落地后的外观、NPC 通行和玩家建造操作仍需核对。

## 当前已有的接口

- 七城宅田输入为 `blueprints/province_capitals/blueprint_plan/studies/player_land_r3.json`，每城净用地64×72格或旋转后的72×64格，外侧另有3格公共退界。目前仅进入独立规划预览，正式生成尚未消费该留白配置。千机阁入城和街区地面重排也处于这一规划阶段。
- 中州已有 `EstateRuntime`、`EstateTitles` 和庄园管家，可复用房契、对话、支付事务和出售状态的处理。当前购买的是已经生成的整座庄园，`EstateDefinition` 没有选模板和施工字段。
- 主代理的六套设计已经有实际方块状态及完整构件定义，可复用现有结构导出器。Astra 的六套是网页几何与程序像素材质，需要先落实为实际方块和构件。
- 正式七府由 `tools/province_capitals/blueprint_plan/runtime.py` 导出城市切片、入口及 `life.places`，再经 V11 聚合器进入世界生成。NPC 的住处绑定到 `rest` 生活点，运行时会检查脚下支承、身体净空、床位设施和容量。
- `NpcEntity` 当前使用原版 `OpenDoorGoal`，`NpcLifeNavigation` 只把原版可手开木门作为可开门处理。大号双开门属于 `CourtyardDoorBlock`，接入 NPC 住宅时需要新增对应识别和开门通行处理。

## 建议共用的房屋目录

把12套整理为同一份作者目录，由玩家施工和 NPC 城镇生成分别消费。目录中的用途字段明确区分玩家与 NPC，选择规则不从名字或路径前缀推断。

每套记录：实际方块模板、建筑与院落占地、地面基准、门口位置和朝向、允许旋转、完整构件、施工与清理范围，以及可选的休息、社交和修炼站位。预览网格、文字标注、宅田留白和演示地形不写入房屋模板。

Astra 的方块化先保持原有比例、主次屋顶和院落尺度，门窗、栏杆、植物与家具使用实际可用方块；缺少的构件再按现有注册表补齐。导出后先做与当前设计对照的实方块预览，再安排城镇落位。

## 玩家住宅流程

建议入口设在宅田旁的管家：查看宅地 → 选择六套之一或暂不建房 → 旋转和平移落位 → 查看占地与入口 → 确认施工。先支持四向旋转和地块内平移，房屋按公共入口方向接路。

六套宅院为52～56格宽、48～52格深，均可放入现有宅田。住宅院区之外剩余1696～2112格，尚未扣除接路；预设院子包含在住宅占地内。余下空地继续供玩家自建和种植。

正式城市先生成空宅田和公共接路，玩家选择后才放置房屋。施工由服务器核对地块、房契、模板、位置和实际占用，只写入房屋及必要地基范围。已有玩家建筑和田地纳入占用检查。建成后作为普通方块自由改建，不在读取区块时反复套回模板。

建房状态保存所选模板、位置、朝向和施工进度。分批写入时保留整件构件的完整性；重复提交和重启使用同一施工记录。玩家住宅不登记为 NPC 可分配住处。

中州继续沿用现有庄园入口。七城新增宅田的地价、施工费和建材消耗尚未确定，后续由独立配置提供金额；这次用途确认不代表已经选定收费方案。

## NPC 住宅流程

上批六套带院住宅纳入城镇住宅候选，与现有小住宅共同使用。按地区风格和实际地块尺寸稳定选择，保留院落、回廊和自身台阶。

这六套约36～52格宽、40～48格深。当前东荒普通住宅样本有9×11、17×11和19×17格等地块，因此新宅需要在规划层安排完整大院地块，并同步调整周边院路。不能只改一个住宅模板引用后沿用原小地块。

建筑、入口和生活点从同一份落位数据导出。每个真实床位旁安排有效站立点，容量按实际床位设置；居民沿用当前命簿分配与作息。新院落须连上公共道路，并检查夜间回家、上下楼和进入卧房的完整路线。

NPC 过门复用大号双开门的服务端开关规则，规划通行时使用开门后的实际碰撞，门框仍保持阻挡。该适配应与这批 NPC 房屋一起交付。

## 建议实施顺序

1. 完成12套共同目录、Astra 方块化及结构导出，核对实方块外观与原设计。
2. 把七城宅田、千机阁入城和地面分区落实到正式城市输入，同时为 NPC 六套安排合适地块。此阶段提供整城落位预览。
3. 接入玩家管家的选房、落位和施工；NPC 住宅同步接入生活点、大门和作息通路。
4. 做受影响的独立新世界检查：地块和公共路、玩家施工及重启、NPC 入住和夜间回家。游戏内外观、操作手感及多人体验按实际观察记录。

当前交付边界仍为用途确认和接入安排，未选择收费数值，未构建JAR，未启动游戏。
