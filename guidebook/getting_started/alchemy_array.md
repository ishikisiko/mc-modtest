# 青铜丹炉阵

青铜丹炉阵是手动搭建的三乘三乘三炼丹设施。原来的 <ItemLink id="myvillage:alchemy_furnace" /> 仍可逐次手动炼丹；新炉阵适合由漏斗补料并连续开炉。它们共用已学丹方、药材、下品灵石和丹药品质规则。

新增的[筑基丹与补基丹](./foundation_pills.md)也在此炉炼制，使用凝元果与两味辅料。进药口可以补入第三味药材，已学丹方列表支持翻页。

## 先做齐组件

需要二十一块 <ItemLink id="myvillage:alchemy_array_casing" />，以及各一块炉心、进药口、出丹口、灵石口、排气盖。炉壁用铜锭和砖块制作，炉心以原青铜丹炉为核心；两个物料口用漏斗，灵石口用下品灵石，排气盖用铁栏杆。均可通过生存合成取得。

炉心带有火窗与状态灯，进药口有青绿药叶标志，出丹口是浅色承丹嘴；背面菱形灵石印是灵石口，铜绿阶式炉盖放在顶部。

## 三层逐块搭建

每层均为三乘三。以下从上方俯看，上方为炉后，下方为炉前；站在炉前面向炉心时，进药口在右侧中层，出丹口在左侧底层。所有组件均需逐块放置，炉壁不依赖朝向。端口带装饰的一面必须朝向炉体外侧。

底层左侧中格放出丹口，面向左；其余八格放炉壁。出丹口下方留给抽取丹药的漏斗。中层排列如下：

| 炉后左 | 炉后中 | 炉后右 |
|---|---|---|
| 炉壁 | 灵石口，面向后 | 炉壁 |
| 炉壁 | **空气，保持空心** | 进药口，面向右 |
| 炉壁 | 炉心，面向前 | 炉壁 |

顶层八块炉壁围住正中央的排气盖。排气盖的水平朝向不影响成型。整个炉阵可以水平转向，端口位置随炉心一起旋转。打开炉心界面可查看三层蓝图、当前缺件和相对坐标。

## 选择丹方，授权连续开炉

先觉醒灵根，手持丹方右键永久学习。靠近炉心打开界面，选择已学丹方，补足所需药材与下品灵石，再明确启动连续炼制。启动时保存授权者当时的炼丹资质上限，每批开炉分别保存本批品质决定，旁人不能靠接手界面提高已开始批次的品质。

进药口只接收当前丹方的两种药材；灵石口只接收下品灵石标签中的物品；出丹口只允许取出成品。把漏斗从炉体外侧指向进药口和灵石口，在出丹口下方用漏斗取丹。进药口和灵石口从朝外的一面接收物品，出丹口从朝外面或下方提取。所有物品都归炉心保管，端口没有第二份库存。

输出满时当前批次暂停，腾出空间后继续。停止连续炼制只阻止下一批，已经投入的当前批次继续。拆坏炉阵会暂停当前批次，按蓝图修复后可恢复；拆掉炉心会掉落实存物品，未完成产物作废。机器区块卸载或世界关闭时停止计时，不补算离线产量；授权玩家退出但机器仍加载时可以继续生产。

## 不能开炉时

检查中层中心是否被堵、端口是否朝外、组件是否缺失，以及周围区块是否已加载。一个端口同时对应多个合法炉阵时也不能传输。看见炉火亮起或排气盖反馈，只代表服务器当前报告的运行状态；以界面中的结构、材料、进度和阻塞提示判断原因。
