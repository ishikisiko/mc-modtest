# 锻造、组装与辅助火

普通炼器鼎负责起坯，也能自动制作标准成品。手工路线还需要加热窑、锻器台、淬火水槽和组装台。玄枢多方块炼器鼎负责成品炼灵和辅助火精炼。

目前支持青锋剑、凌霄枪、精铁镐斧铲锄及玄铁甲四件。其他高阶衣甲的物品和外观不代表已有生存器谱。

## 查询材料并学习器谱

安装 JEI 后，对成品使用「查看配方」，选择「炼器」。页面显示起坯主材和最终成品，材料标签轮换显示同类材料。器谱是一次性学习条件，不会每次消耗；燃料、用水、燧石、柄材和炼灵耗材另算。

没有 JEI 也能制作。在普通鼎选择器谱后，悬停「只起坯」或「自动制作」查看本次完整消耗。材料不足不会扣半份。

四种精铁工具入门即可制作。青锋剑和凌霄枪先研读对应器谱。四本玄铁甲器谱由药铺中出售丹药的商人售卖，白天到其岗位交易，在买入页翻页寻找。右键研读一次即可永久学习。

玄铁主材来自玄铁矿。粗玄铁在熔炉或高炉加工成玄铁锭，普通铁锭不能代替。

## 普通鼎起坯或自动制作

<Recipe id="myvillage:forging_table" />

「只起坯」消耗主材，把器坯留在输入槽，取出后可手工加工。「自动制作」预付主材、普通燃料、用水、燧石及普通木柄用料，产出可用标准器物，用水后返还空桶。已有手工器坯也能自动续作，保留已完成部分的手工贡献。

关闭界面后自动炉次继续。开炉者或管理员可以撤炉退料；拆鼎退出现有器物和实际暂存材料，不提前掉落未完成的成品。自动成品可以换柄，也能送入多方块鼎炼灵。

## 手工加热和成形

1. 手持器坯右键窑放入，潜行右键打开燃料槽。放好煤炭或木炭后自动加热和保温，热好时有声音提示。
2. 空手右键取出热坯，再右键放到锻台。窑与锻台同层相邻时，持锤右键空锻台可接过热坯；持锤右键窑可把台上器物送回。
3. 手持锻锤右键台面实际锻打。不同配方需要不同成形点数，好锤、熟练度和充足火候同时提高每锤进度与该部分加工的工艺成效。
4. 成形完成后潜行右键锻台淬火，同层相邻水槽必须已注水且空闲。
5. 把淬火坯送回窑中回火，再放回锻台精磨。精磨消耗燧石，完成后取走器坯送到组装台。

热量和进度跟随实际器物保存，搬运和关界面不会清空。锻打消耗热量，闲置缓慢冷却，冷却不丢进度。成品再锻前也在窑中加热。

锻铁锤之后可制作玄铁锻锤、赤铜灵锤和下界合金锻锤。熟练度按有效完成点数增长，空敲、补敲和反复加热没有经验；好锤敲得少也不会少拿经验。低难度配方在熟练后提供较少练习收益。

手工成形同时改善器物适用的伤害、速度、耐久、防护和耗灵，不需要逐锤评分或选一种属性。自动路线是标准基准，手工、柄材、炼灵与再锻受对应属性的合计上限限制。

## 组装和换柄

<Recipe id="myvillage:assembly_table" />

精磨器坯与一个柄材放入组装台，核对预览后装配。护甲使用皮革，不装武器柄。开始装配时按操作者的炼器资质随机判定失败或四种品质，未觉醒的入门工具按资质 0 计算。普通鼎自动成器同样判定；只起坯不判定品质。失败在工序完成时消耗已投入的器坯和材料，暂停或重启保留原结果。

六种柄均由两个对应原料合成：

| 柄材 | 用途 |
|---|---|
| 普通木柄 | 木棍制成，作为自动路线的标准柄，无额外特性。 |
| 竹柄 | 动作较快、耐久较低，手持时小幅提高移动速度。 |
| 凝元木柄 | 耐久较高，脱离战斗后消耗少量灵力修复耐久。 |
| 荆骨柄 | 伤害较高、耐久较低，重击有效命中后强化下一次轻击。 |
| 玄铁柄 | 耐久较高、动作稍慢，手持时提高抗击退能力。 |
| 赤铜柄 | 降低耗灵，灵力技能有效命中后强化下一次普通攻击。 |

成品可更换柄，原柄从返还槽取回。换柄保留品质、手工贡献、炼灵、历练、附魔、名字和损伤比例；反复更换不会叠加属性或修复器物。右侧预览显示属性变化，悬停可看完整说明。

## 多方块鼎炼灵和辅助火

放置玄枢阵枢，按其分层蓝图搭好完整多方块鼎。放入成品，选择支持的专长后开炉，另付灵石和专长辅材。炼灵保留已有品质，不按炼灵者重新定品。

辅助火只在完整多方块鼎使用。火种放入专用槽，自动和手工成品均能精炼，每件器物只接受一次辅助火。已炼灵成品可补做首次辅助火精炼，原专长不变，仍付该专长的完整炼制耗材。

<Recipe id="myvillage:fire_capture_bottle" />

| 火种 | 获取与适性 |
|---|---|
| 地脉灵火 | 新探索地下区域的地火泉眼，用收火瓶收取；须在原泉眼附近使用，适合金属。 |
| 兽火 | 削弱烈焰人后收火，或击败未收火的烈焰人时偶尔获得；适合兽材。 |
| 雷火 | 从遭雷击激活的避雷针收取，随有效炉内进度自动额外精炼。 |
| 玄阴寒焰 | 寒冷群系地下的寒焰凝晶，用收火瓶收取；适合晶石。 |
| 三昧真火 | 达到熟练度要求后，在完整鼎内消耗烈焰棒、灵石和自身灵力凝火；炼制期间持续消耗开炉者灵力。 |

火种成熟度独立于种类。地火用岩浆膏温养，兽火用荆骨，雷火用紫水晶碎片，寒焰用海晶砂粒，三昧真火用烈焰粉。材料放入温养槽后核对提示再温养，完成炼制也有少量成长。

关闭界面不取消炉次。结构缺失、输出受阻、地火位置不符或三昧真火缺灵力时暂停，条件恢复后续炼，不补算离线时间。

## 历练、再锻和修补

兵器通过有效近战、工具通过采掘或耕作获得器物历练。穿戴玄铁甲主要通过承受敌对生物的实际伤害成长，主动近战也有少量收益；背包携带、环境伤害、自伤和空挥不算。

成品在窑中加热后放回锻台，潜行右键选再锻方向，关面板后持锤右键。每锤消耗历练和辅材，保留累计次数上限，本次只有制作成形改为点数制。玄铁甲只支持耐用再锻，工具不会因此越级开采。

受损器物在锻台修补，保留品质、附魔和已付记录。材料及数值以当前界面和物品说明为准。
