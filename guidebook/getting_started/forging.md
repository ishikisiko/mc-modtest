# 锻造、组装与辅助火

普通炼器鼎负责起坯，也能自动制作标准成品。手工路线还需要加热窑、锻器台、淬火水槽和组装台。玄枢多方块炼器鼎负责成品炼灵和辅助火精炼。

起坯、加热窑、锻器台、组装、装备炼灵和赤铜灌灵的界面都有旋转的工位模型。需要放料或取物时，使用界面里的物品槽。手工锻打仍在世界里的锻器台台面进行。

目前支持青锋剑、凌霄枪、精铁、白青灵金和日魄乌金的镐斧铲锄、玄铁甲四件，以及[玄铁飞剑](./flying_swords.md)等器物。

## 查询材料并学习器谱

安装 JEI 后，对成品使用「查看配方」，选择「炼器」。页面显示起坯主材和最终成品，材料标签轮换显示同类材料。器谱是一次性学习条件，不会每次消耗；燃料、用水、燧石、柄材和炼灵耗材另算。

没有 JEI 也能制作。在普通鼎选择器谱后，悬停「只起坯」或「自动制作」查看本次完整消耗。材料不足不会扣半份。

四种精铁工具入门即可制作。青锋剑和凌霄枪先研读对应器谱。玄铁甲和玄铁飞剑器谱由药铺中出售丹药的商人售卖，白天到其岗位交易，在买入页翻页寻找。右键研读一次即可永久学习。

白青灵金和日魄乌金工具先用书、对应金锭和下品灵石合成器谱，再右键研读。起坯使用对应材料锭。三套工具的手工工序均依次经过粗坯、成形坯、淬火坯、回火坯和精磨坯，之后在组装台装柄。

粗玄铁可以手挖玄铁矿，也可以用[采掘站](./mine_station.md)从天然玄铁矿眼自动获取。用熔炉或高炉把粗玄铁加工成玄铁锭，供炼器使用。

## 普通鼎起坯或自动制作

<Recipe id="yuanxian:forging_table" />

「只起坯」消耗主材，把器坯留在输入槽，取出后可手工加工。「自动制作」预付主材、普通燃料、用水、燧石及普通木柄用料，产出可用标准器物，用水后返还空桶。已有手工器坯也能自动续作，保留已完成部分的手工贡献。

关闭界面后自动炉次继续。开炉者或管理员可以撤炉退料；拆鼎退出现有器物和实际暂存材料，不提前掉落未完成的成品。支持换柄或炼灵的器物可继续加工。玄铁飞剑在装配后即可御剑。

普通炼器鼎还可以打开「炼制阵石」和「赤铜灌灵」。阵石的材料和修为要求见[扩展附魔台](./seal_array.md)。做赤铜时，把普通铜锭放进输入槽，点「开始 / 继续」，再从输出槽取走赤铜锭。界面左边是炼器鼎的展示模型，批次、灵力和进度显示在物品槽附近。

<Recipe id="yuanxian:forging_hammer" />

1. 手持器坯右键窑放入，潜行右键打开燃料槽。放好煤炭或木炭后自动加热和保温，热好时有声音提示。
2. 空手右键取出热坯，再右键放到锻台。窑与锻台同层相邻时，持锤右键空锻台可接过热坯；持锤右键窑可把台上器物送回。
3. 手持锻锤右键台面实际锻打。不同配方需要不同成形点数，好锤、熟练度和充足火候同时提高每锤进度与该部分加工的工艺成效。
4. 成形完成后潜行右键锻台淬火，同层相邻水槽必须已注水且空闲。
5. 把淬火坯送回窑中回火，再放回锻台精磨。精磨消耗燧石，完成后取走器坯送到组装台。

热量和进度跟随实际器物保存，搬运和关界面不会清空。锻打消耗热量，闲置缓慢冷却，冷却不丢进度。成品再锻前也在窑中加热。

锻锤之后可制作玄铁锻锤、赤铜灵锤和下界合金锻锤。熟练度按有效完成点数增长，空敲、补敲和反复加热没有经验；好锤敲得少也不会少拿经验。低难度配方在熟练后提供较少练习收益。

## 组装和换柄

<Recipe id="yuanxian:assembly_table" />

精磨器坯与一个柄材放入组装台，核对预览后装配。护甲使用皮革。玄铁飞剑使用普通木柄。开始装配时按操作者的炼器资质随机判定失败或四种品质，未觉醒的入门工具按资质 0 计算。普通鼎自动成器同样判定；只起坯不判定品质。失败在工序完成时消耗已投入的器坯和材料，暂停或重启保留原结果。

中品、上品和极品的炼器工具在挖掘擅长的方块时，基础速度系数都增加 0.5。品质加成在成器时即可使用。精铁、白青灵金、日魄乌金工具的起始系数依次为 6.0、7.0 和 8.5。

## 连锁采矿和整树采伐

挖掉第一块矿石后，炼器镐会连着采掉相邻的同种矿石。普通矿石和深层变体按矿种标签归在一起。默认练气镐从首块向外搜 3 格，一次最多采 8 块，首块算在其中。每升一个工具大境界，半径加 3 格、数量翻倍。

炼器斧砍断一棵树的第一根原木后，会继续沿这棵树的树干和枝条逐根砍伐。练气、筑基、金丹、元婴和化神的间隔依次为 10、6、4、2、1 刻。放置的建筑原木留在原处，叶片照常衰减。

矿石和原木逐个结算掉落与工具耐久。换下当前工具或工具损坏后停止连锁。镐的半径、数量、矿种标签和各境界的斧子间隔可在游戏实例的 `config/yuanxian-workshop-harvest-server.toml` 调整。

## 多方块鼎炼灵和辅助火

放置玄枢阵枢，按其分层蓝图搭好完整多方块鼎。放入成品，选择支持的专长后开炉，投入器谱所用的一份主材和对应灵石。锋锐等专长还要投入各自的辅材。例如白青灵金镐炼出坚韧时，需要一枚相同的白青灵金锭和两枚下品灵石。炼灵保留已有品质。

### 工具专长

- **镐 · 寻脉。** 正常挖矿时记住最近的矿种。潜行右键敲击洞壁消耗 3 点灵力，岩壁上的光点会指向附近同种矿石。下品到极品的搜索距离依次为 4、5、6、8 格。
- **斧 · 补种。** 潜行右键砍伐一棵树，完整伐完后直接在原根位补种同种树苗。普通树补一株，四格粗干按原来的四个根位补种。树苗照常生长。
- **铲 · 挖高补低。** 第一次潜行右键地面记下高度，第二次选施工区域。下品和中品处理 3×3 格，上品和极品处理 5×5 格。挖出的土可以直接填低处，剩余的土留在地上。
- **锄 · 留茬采药。** 右键收获成熟灵植，扣掉一份药材用来留根，植株回到生长期。下品到极品有 15%、25%、35%、50% 的机会额外掉落两份药材。

辅助火只在完整多方块鼎使用。火种放入专用槽，自动和手工成品均能精炼，每件器物只接受一次辅助火。已炼灵成品可补做首次辅助火精炼，原专长不变，仍付该专长的完整炼制耗材。

| 火种 | 获取与适性 |
|---|---|
| 地脉灵火 | 新探索地下区域的地火泉眼，用收火瓶收取；须在原泉眼附近使用，适合金属。 |
| 兽火 | 削弱烈焰人后收火，或击败未收火的烈焰人时偶尔获得；适合兽材。 |
| 雷火 | 从遭雷击激活的避雷针收取，随有效炉内进度自动额外精炼。 |
| 玄阴寒焰 | 寒冷群系地下的寒焰凝晶，用收火瓶收取；适合晶石。 |
| 三昧真火 | 达到熟练度要求后，在完整鼎内消耗烈焰棒、灵石和自身灵力凝火；炼制期间持续消耗开炉者灵力。 |

火种成熟度独立于种类。地火用岩浆膏温养，兽火用荆骨，雷火用紫水晶碎片，寒焰用海晶砂粒，三昧真火用烈焰粉。材料放入温养槽后核对提示再温养，完成炼制也有少量成长。

关闭界面不取消炉次。结构缺失、输出受阻、地火位置不符或三昧真火缺灵力时暂停，条件恢复后续炼，不补算离线时间。

## 历练、再锻和修补

兵器通过有效近战、工具通过采掘或耕作获得器物历练。穿戴玄铁甲主要通过承受敌对生物的实际伤害成长，主动近战也有少量收益；背包携带、环境伤害、自伤和空挥不算。

成品在窑中加热后放回锻台，潜行右键选再锻方向，关面板后持锤右键。每锤消耗历练和辅材，保留累计次数上限，本次只有制作成形改为点数制。玄铁甲只支持耐用再锻，工具不会因此越级开采。

受损器物在锻台修补，保留品质、附魔和已付记录。材料及数值以当前界面和物品说明为准。


## 用取物器调试阵法

创造模式下把品质取物器放在主手，右键打开「快捷搭建」，可选青铜丹炉阵、玄枢炼器鼎、篆纹阵或仙纹图书馆。潜行右键地面的上表面，阵法正面会朝向站在地面前方的玩家。橙色边框标出将清空的整个区域，半透明的方块显示搭建后的位置。脚下用来定位的地面保留。

查看预览后，普通右键打开确认框。确认框会显示清空尺寸和现有方块数量。点「清空并搭建」会清掉区域内的方块和容器内容，再摆好阵体。想换位置，可以关闭确认框后潜行右键重选。区域内的方块有变化时，需要确认更新后的预览。
