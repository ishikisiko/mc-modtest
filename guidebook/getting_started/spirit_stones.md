# 灵石、灵石袋与兑换

下品灵石来自主世界新生成区块中的灵石矿；需要铁级或更高镐。已有区块不会补矿。矿物外观、精准采集和时运表现见[打坐与冲关](./cultivation_loop.md)。中品和上品不通过新增高阶灵石矿取得。

## 随身灵石袋

<Recipe id="myvillage:spirit_stone_bag" />

把灵石袋放在背包或副手，可自动收纳支持品级的灵石。悬停查看各品级余额；对空右键切换自动收纳，潜行右键暂停本袋并取出一叠。

暂停收纳不影响已有余额用于支付。修炼、交易、供奉、炼丹和炼器会按各自规则读取散装与袋内灵石；普通工作台合成应先从袋中取出原料。袋子不能套袋，不能用改名或特殊组件灵石绕过兑换限制。

## 主动兑换

输入 `/灵石` 查看当前可用兑换帮助。可以主动升阶或拆分，不会在支付下品灵石时自动把中品或上品拆掉。兑换前检查品级、数量和背包空间，余额不足或空间不足时整笔拒绝。

不同用途需要不同品级：丹炉等原有消费仍按其具体下品要求；[高阶聚灵阵](./cultivation_loop.md)可使用兼容品级并保留余能。只持有高阶灵石时，先主动拆分，再进行要求下品的操作。
