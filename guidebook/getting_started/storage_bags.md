# 储物袋

手持储物袋右键打开。材料袋、通用储物袋和秘籍袋在同品阶有相同容量，取放方式和箱子类似。

- **材料袋**装灵草、矿材和妖兽材料等本模组原料。它在背包或副手时，会收下你正常走近拾取的合格掉落。袋满后继续走普通拾取。打开袋子可以切换拾取开关。
- **通用储物袋**手动存放普通物品，适合出门装工具、食物和战利品。所有储物袋都不能在袋内套放其他储物容器。
- **秘籍袋**存放功法秘籍。把鼠标移到秘籍上可以看参悟进度和当前研读条件，取出后照常手持右键研读。

回家卸材料时，先在箱子里放入你希望归到这里的物品。手持材料袋潜行右键箱子，袋子会把箱中已有的同种材料转进去。箱子装不下的部分留在袋里。

## 炼制和扩容

打开普通炼器鼎，点「储物袋」，选袋子类型。炼气档使用皮革、线、铜锭和下品灵石。窗口会列出确切数量，开炉后从右槽取袋。

扩容时把旧袋放在左槽。筑基档继续用普通鼎，金丹以上要用完整的玄枢炼器鼎。开炉的人须达到成品对应的大境界。达到炼气一层、筑基初期、金丹初期就能炼对应档。炼制时会一并保留袋内的物品、名字和拾取开关。
