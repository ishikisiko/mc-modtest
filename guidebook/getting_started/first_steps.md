# 开局与阡镇学徒

新角色首次加入时留在主世界。你可以先采木、做工具、准备食物和住处；阡镇故事由你选择进入，不会在登录时自动接取。

## 进入与返回

打开修仙面板：<KeyBind id="key.myvillage.open_cultivation_profile" />，选择「行迹」，点击「进入阡镇秘境」。首次进入需要等待场景准备，准备结束后才会传送。秘境属于当前角色，不是公共城市或可任意传送到其他玩家所在地的入口。

在秘境内再次打开「行迹」，可以返回进入前的世界。再次进入继续原进度，不会重新发种苗或重置药圃。秘境中的床不会更改主世界重生点。

## 药庐学徒怎么做

1. 向程砚问路，或跟随目标标记到药庐找沈岚。先询问工作内容，再自行接受学徒约定。
2. 在院内右键测灵碑，觉醒灵根并确认天命，再右键传承碑学习《基础吐纳诀》。操作见[入门仪式](./initiation.md)。
3. 找平地站稳，开始一次[普通修炼](./cultivation_loop.md)，等到实际获得一批修为后收功。已经做过的测灵、传功和修炼会按真实进度确认，不要求重做。
4. 找沈岚领取种苗，在学徒药圃的三个不同灵土格上亲手补种灵叶。灵叶本身就是种苗，不需要另找种子。
5. 补种完成后找沈岚领取约定报酬。背包满时先整理空间，再回来领取；报酬不会因为一次领取失败而消失。

测灵、传功、首次吐纳和第三格播种完成后，目标会自动推进，不需要每一步回药庐报告。目标标记显示方向与距离；当前步骤和提示都能在「行迹」查看。

## 药圃没有空位怎么办

成熟灵叶可以收获后补种。若都是幼苗，先等成熟，不要拔除还在生长的药材。任务要求在指定药圃亲手种下三个不同格子，重复同一格或在别处放置不能替代。种苗只领取一次，应妥善保存。

完成学徒工作后，可以继续普通生存和修炼，也可随时离开秘境。下一步可阅读[灵土与六味药材](./spirit_farming.md)、[丹炉与丹药](./alchemy.md)和[锻造、玄铁甲与炼灵](./forging.md)。
