# 金丹绝技


东海或西漠州城的天衡殿琳琅阁常备这十六本秘籍。每本价格依照金丹档的州城报价。达到金丹、对应兵器或灵根资质达到 100 点并学会前置功法后，右键秘籍研读。

学成后在 H → 技能分配快捷键。三种武技要求手持对应兵器，五行绝技可以空手使用。按 R 进入修炼战斗模式。
