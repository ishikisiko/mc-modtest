# 打坐与冲关

下列按键由你的当前键位设置动态显示，不应把默认字母当作固定操作：

- 打开“内视 / 修炼 / 功法”修仙面板：<KeyBind id="key.myvillage.open_cultivation_profile" />
- 开始普通打坐：<KeyBind id="key.myvillage.start_normal_meditation" />
- 开始灵石修炼：<KeyBind id="key.myvillage.start_spirit_meditation" />
- 停止当前修炼：<KeyBind id="key.myvillage.stop_meditation" />
- 修为与稳定度圆满后开始晋层：<KeyBind id="key.myvillage.start_advancement" />

## 开始与打断

开始打坐或冲关需要已觉醒灵根、已学《基础吐纳诀》、处于生存或冒险模式、寿元未尽并站在稳定地面上。你还必须存活，未骑乘、游泳、飞行、睡眠或使用物品，并且过去 `100` tick 内没有受到实际伤害。打坐先经过 `40` 个连续合格 tick 的准备期。

任一轴移动超过 `0.01` 格、跳跃、受伤、攻击或挥动、挖掘、方块/实体/物品交互、骑乘、游泳、飞行、睡眠、切换模式或维度、死亡、退出或主动停止都会打断。使用本手册也是物品交互，打坐时再次使用会中断。转动视角、打开档案界面、切换页签或关闭界面不会中断。

## 普通与灵石结算

进入打坐后，每 `10` 个连续合格 tick 结算一批：

- **普通打坐**增加当前“灵气亲和”数值的修为；新档案默认是 `10`，但实际值以服务端档案为准。
- **灵石修炼**固定增加 `50` 修为，并从普通背包直接扣除当前阶段所需的 <ItemLink id="myvillage:low_grade_spirit_stone" />。

| 当前阶段 | 每批灵石 | 每批修为 |
|---|---:|---:|
| 已感气 | 1 | 50 |
| 炼气一层 | 1 | 50 |
| 炼气二层 | 2 | 50 |
| 炼气三层 | 3 | 50 |
| 炼气四层 | 4 | 50 |
| 炼气五层 | 5 | 50 |
| 炼气六层 | 6 | 50 |
| 炼气七层 | 7 | 50 |
| 炼气八层 | 8 | 50 |
| 炼气九层 | 9 | 50 |

最后一批只要产生了修为，就按上表当前阶段的完整费用扣除，再将修为截到上限；已经圆满时不扣灵石。灵石不足时不会扣除任何灵石，而是按普通打坐的亲和收益结算，并直接降级为普通模式，无需重新准备。

## 寿元门槛

默认时间尺度为每日 `24000` 有效 tick、每周 `6` 日、每年 `24` 日。凡人寿元上限为 `80` 年，炼气境为 `120` 年，筑基境为 `240` 年，金丹境为 `500` 年。突破不会重置已经消耗的寿元。个人寿元只在玩家在线、存活且处于生存或冒险模式时增长；寿元耗尽会阻止打坐与冲关，但不会杀死玩家、清空档案或触发转世。

## 确定性晋升

只有当前修为与稳定度同时达到上限，才能开始一次晋升。晋升复用上面的合格与打断边界；完成时服务端再次检查条件，只推进一个阶段，修为归零，并保留“实际稳定度除以二后向下取整”的稳定度。

| 晋升 | 持续 tick | 满稳定度成功后保留 | 玩家/世界打断损失 |
|---|---:|---:|---:|
| 已感气 -> 炼气一层 | 100 | 250 | 0 |
| 炼气一层 -> 炼气二层 | 100 | 275 | 0 |
| 炼气二层 -> 炼气三层 | 120 | 300 | 0 |
| 炼气三层 -> 炼气四层 | 200 | 325 | 5 |
| 炼气四层 -> 炼气五层 | 140 | 350 | 0 |
| 炼气五层 -> 炼气六层 | 160 | 375 | 0 |
| 炼气六层 -> 炼气七层 | 240 | 400 | 5 |
| 炼气七层 -> 炼气八层 | 180 | 425 | 0 |
| 炼气八层 -> 炼气九层 | 200 | 450 | 0 |
| 炼气九层 -> 筑基初期 | 400 | 475 | 10 |
| 筑基初期 -> 筑基中期 | 200 | 750 | 0 |
| 筑基中期 -> 筑基后期 | 240 | 900 | 0 |
| 筑基后期 -> 金丹初期 | 600 | 1050 | 20 |
| 金丹初期 -> 金丹中期 | 300 | 1500 | 0 |
| 金丹中期 -> 金丹后期 | 360 | 1800 | 0 |

晋升没有随机失败，也不会连续跳过多个阶段。炼气三层与六层的瓶颈被打断时损失 `5` 稳定度；炼气九层突破筑基损失 `10`，筑基后期突破金丹损失 `20`。普通晋升中断无损失；正常关闭服务器与注册表重载取消无惩罚。

**金丹后期是当前版本的可玩上限。**炼气一至九层、筑基初中后期、金丹初中后期均可逐级到达；金丹后期不能继续增长修为或突破元婴。丹药、修炼设施、天劫、寿尽死亡与转世尚未实现。

灵力上限：筑基初/中/后期为 `200 / 250 / 300`，金丹初/中/后期为 `400 / 500 / 600`。突破扩大容量不会自动回满灵力或生命。
