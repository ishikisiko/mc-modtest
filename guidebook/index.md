# 修行入门录

这本手册介绍当前已经可以使用的玩法。初来时先读[开局与阡镇学徒](./getting_started/first_steps.md)：你会留在主世界，可以自行生存，也可以从修仙面板的「行迹」进入个人阡镇秘境。

修行从[入门仪式](./getting_started/initiation.md)开始：测灵并确认天命，传承《基础吐纳诀》，随后[打坐积累修为与稳定度，再冲关](./getting_started/cultivation_loop.md)。本书中的按键组件显示你的当前设置；设置过自定义键位后，应以组件显示为准。

## 当前版本边界

- 测灵与传功是两个独立步骤，学习功法不会自动增加修为或稳定度。
- 普通打坐与灵石修炼都由服务端结算；修为未满时先增加修为，修为圆满后的下一批次才开始增加稳定度。
- 修为和稳定度都达到当前阶段上限后才能冲关。炼气九层需要服用[筑基丹](./getting_started/foundation_pills.md)；筑基后期需要主动引发[金丹雷劫](./getting_started/tribulation.md)。其余已开放阶段按普通晋升规则处理。
- **金丹后期是当前版本的可玩上限。** 炼气九层、筑基初中后期、金丹初中后期已开放；元婴玩家突破、寿尽死亡与转世尚未实现。高阶装备的外观存在，不代表对应境界或制作路线已经开放。
