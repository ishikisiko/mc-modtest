# 修行入门录

当前可玩的修行顺序是：先在[入门仪式](./getting_started/initiation.md)中完成测灵，觉醒灵根；再传承《基础吐纳诀》；随后按[打坐与冲关](./getting_started/cultivation_loop.md)的规则先积累修为，再巩固稳定度，最后按阶段要求晋升境界。

[探索、境界与城镇向导](./getting_started/exploration.md)介绍主世界与下界探索建议、修炼收益，以及按个人进度提供下一步目标的客栈向导。

[青铜丹炉阵](./getting_started/alchemy_array.md)介绍可逐块搭建的三层炼丹设施、漏斗补料与连续开炉。

[凝元果树与灵木](./getting_started/ningyuan_tree.md)介绍树苗、采果、单轮培元肥和完整木材／庭院装饰。

## 当前版本边界

- 测灵与传功是两个独立步骤，学习功法不会自动增加修为或稳定度。
- 普通打坐与灵石修炼都由服务端结算；修为未满时先增加修为，修为圆满后的下一批次才开始增加稳定度。
- 修为和稳定度都达到当前阶段上限后才能冲关。炼气九层需要服用[筑基丹](./getting_started/foundation_pills.md)，成功率取决于丹药品级；其他阶段保持原有晋升规则。
- **金丹后期是当前版本的可玩上限。** 可逐级修炼到炼气九层、筑基初中后期、金丹初中后期。元婴玩家突破、天劫、寿尽死亡与转世尚未实现。

先阅读[入门仪式](./getting_started/initiation.md)，再阅读[打坐与冲关](./getting_started/cultivation_loop.md)。
