# 16套防具的四槽GUI图标

`armor.json` 是48张头部、胸部、下装原创像素图稿的作者输入，同时为16张靴图指定原作者来源。
靴图的像素行仍归 `equipment/boots/styles.json`，没有复制成第二份图稿。
`tools/equipment/armor_icons.py` 统一读取两类输入，并使用对应套装的实际材质调色。
两条原装备导出链负责写入PNG和 `neoforge:separate_transforms`，仅替换GUI分支。
手持、地面与展示框继续读取原拥有者导出的真实OBJ。

用户已确认这版离线外观并授权接入，资源随0.111.3发布。游戏内显示与离线外观确认分别记录。

## 图标规范

- 画布固定16×16，硬边、不抗锯齿；左上方受光。主要材料使用暗、基色、亮三个色阶，
  饰边和小块嵌色只在对应模型存在时出现。颜色读取已有材质，不另造一套装备配色。
- 轮廓为主材质暗色的0.72倍，孔内阴影为0.9倍，避免把整套都围成粗黑边。
  亮面留在左侧和上缘，右侧保留暗面；金属与织物靠色块组织区分，不画塑料渐变。
- 大件一般占10—14像素宽、11—14像素高；低冠允许更矮，不把所有部件拉成同一高度。
  预览在固定格内显示，禁止按每件包围框自动放大。
- 冠、盔使用能读出开面和真实冠峰的正面或略斜视角；胸部优先显示袖型与领襟；
  下装必须包含腰口、前后衣裾关系或独立裤腿；靴子保留能读出前伸鞋头的错位侧视。
- 每套分别起稿。方山框、桥玉冠、缺月冠、枝冠、悬衡冕和阶形日莲冠均按各自器型绘制；
  宽袖衣、窄袖礼甲、异袖战仪和长裳不共用换色模板。

`materials` 为每幅图的主材质、辅材质、饰边、内衬与嵌色绑定。
九色主晶的 `palette_samples` 直接采样实际九色色表中的紫青主面和浅色切缘，不把多色材质误读为普通三阶。
像素行中的 `b/s/l` 是主材质三阶，`v/w/h` 是辅材质三阶，`e/g` 是饰边，
`c/d` 是内衬，`a/t` 是嵌色，`o/i` 是轮廓和孔内阴影，`.` 为透明。
靴图保留原来的语义字符，但由同一调色函数输出；本轮减弱轮廓和饰边亮度、统一鞋底暗部。

## 参考与交接

本轮没有追加外部参考。沿用前轮实际查看的官方图标和模型记录，见
[靴子参考URL](../boots/REFERENCES.md)。参考用于小尺寸器型辨识、开孔和鞋头构图，
48张新图稿与既有靴图均是本项目作者输入，没有复制参考像素。

生成命令为原来的 `tools.equipment build` 和 `tools.immortal_equipment build`。
局部资源检查使用两条导出链的 `check`、装备资源验证及相关几何回归；构建与原生运行分别记录。
整套离线预览工具为 `tools.equipment.suite_preview`，按实际物品模型GUI分支读取16/32格，
按实际穿戴JSON和部件骨骼绘制整套。透明材质以静态轮廓和色面预览，未复现原生透明排序和动效。
原生加载、GUI光照、穿戴动作、透明混合、性能及多人组合的结论以对应运行证据为准；离线预览不替代这些检查。
